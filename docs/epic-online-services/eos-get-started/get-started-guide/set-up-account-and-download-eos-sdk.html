Guide: Get Started With Epic Online Services — 1. Set Up Your Account and Download the EOS SDK

Step-by-step guide on how to set up your Epic Games account and download the EOS SDK, so you can use EOS in your game.

5 mins to read

Previous section: Introduction

To use EOS, you must set up both an Epic Games account and an organization in the Developer Portal at dev.epicgames.com/portal. (If you have an Epic Games account already, you can sign into your existing account through the Developer Portal. You don't need to create a new account.)

After you have set up your Epic Games account and organization, you can use the Developer Portal to set up your game to use EOS services, to configure how your game uses EOS services, and to access the EOS SDK download.

Unreal Engine EOS plugins and EOS Plugin for Unity
Do not use this guide if you use one of the Unreal Engine EOS plugins or the EOS Plugin for Unity to integrate the EOS SDK into your game. This guide does not apply to these plugins.

This guide shows how to manually integrate the EOS SDK into your game, which is an alternative to using the plugins. For more information on the available options you have to integrate the EOS SDK into your game, including the plugins, see the documentation: EOS SDK and Game Engines Introduction.

Before You Start

Before you start, check that you meet the following prerequisites:

  • Your development environment meets the System Requirements.
  • You can access the host addresses on the Firewall Considerations page.

Complete the following steps to access the EOS SDK:

About the Developer Portal
You will use the Developer Portal to complete this section of the guide. The Developer Portal is a browser-based tool which you use to set up and configure EOS for your game.

You can also use the Developer Portal to set up and configure other Epic services and tools. You do not need to set up or configure any other Epic services or tools to complete this or any other section of the guide, or to integrate any EOS services into your game.

In addition to setting up your game to use EOS, you can use the Developer Portal for the following purposes:

  • Epic Games Store
    Set up and manage your game’s distribution.
    • Documentation: Epic Games Store > Get Started Steps > Introduction.
  • Kids Web Services (KWS)
    Set up age gating and parent verification.
    • Documentation: Kids Web Services (KWS)
  • Epic tools: Unreal Engine, Twinmotion, RealityScan
    Configure seat allocation and royalty reporting, for example.
    • Documentation: Developer Portal Introduction – information on the Developer Portal and links to Epic Tools documentation.

You do not need to set up or configure any of the Epic services or tools listed above to complete this guide or use EOS.

Step A: Create Your Account, Organization, and Product

  1. Go to the Developer Portal (dev.epicgames.com/portal) and click Sign in.

    • a. If you already have an Epic Games account, sign in to your existing account. Otherwise, click Create an account and follow the onscreen instructions to create and sign in to your new account.
    • b. When you first sign in or create an account, the Developer Portal prompts you to create an organization. This is a group (usually a business) that creates and owns games that use Epic services and tools.

    For guidance on organizations, see the documentation: Developer Portal > Organizations.

  2. (Optional) Add team members to your organization.
    When you set up the organization, you become the owner of it. You can add additional team members in the Developer Portal’s Organization page.
    To do this:

    • a. In the Developer Portal’s left navigation, click Organization. The Organization page defaults to the Members tab.
    • b. In the Members tab, follow the onscreen instructions to invite new members to your organization and set their roles.
      For further guidance, see the documentation: Developer Portal > Organizations > Members.

  3. In the Developer Portal, your game is known as a “product”. You add your game to the Developer Portal by creating a product.
    To do this:

    • a. In the Developer Portal’s left navigation, under Your products, click Create Product.
    • b. Follow the onscreen instructions.

    Note: To create a product, you must have the Owner or Admin role in your organization. Members with other roles, including custom roles, cannot create products. For information on roles, see the documentation: Available Roles in the Developer Portal.

Step B: Create Your Client and Client Policy

A client is software that accesses any Epic Online Services (EOS) service. Players download and run a client to play a game that uses EOS services.

A client policy defines what EOS services and other EOS features a client can access, such as Achievements, Stats, Leaderboards, and more.

You set up both clients and client policies in the Developer Portal. You also assign a client policy to a client in the Developer Portal.

For more information, see the documentation: Guide: Manage Your Clients and Client Policies.

Step C: Download the EOS SDK

Note: If you use Unreal Engine, you do not need to download the EOS SDK. The EOS SDK is included with Unreal Engine by default.

Select a version of the EOS SDK for the platform your game client runs on. The EOS SDK is available for the following platforms:

  • Windows, macOS, Linux
    The EOS SDK in C and the EOS SDK in C#.

  • Mobile
    The EOS SDK for iOS and the EOS SDK for Android.

  • Consoles
    To download the EOS SDK for game consoles, you must be a developer approved by both the platform holders and by Epic Games. The SDK is available in C and C#.
    The platform holders are Microsoft (Xbox One, Xbox Series), Sony (PlayStation 4, PlayStation 5), and Nintendo (Switch, Switch 2).

For information about requesting approval, see the documentation: Get Started Reference > Access to the EOS SDK for Consoles.

You download the EOS SDK from the Developer Portal on the Dashboard page. To do this:

  1. Sign in to the Developer Portal at (dev.epicgames.com/portal).

  2. In the left navigation, click Dashboard if it isn’t already selected.

  3. On the Dashboard page, under the Your products heading, click Downloads & Release notes.

  4. Select the EOS SDK tab.

    Note: You can only access the EOS SDK for consoles if you have the appropriate permissions. To request access, scroll down and click Request access. (Documentation: Get Started Reference > Access to the EOS SDK for Consoles.)

  5. For SDK Type, select C, C#, or the EOS SDK for the platform that you want to download the EOS SDK for.

  6. For SDK Version, select the version with (Latest) next to the version number.

  7. Click Download EOS SDK.

  8. On your computer, move the download to a directory your project can access and unzip it.
