Guide: Access EOS Epic Account Services With the Auth Interface — Introduction

Overview of how to access EOS Epic Account Services in your game.

1 min to read

Epic Account Services use the Auth Interface to authenticate players. To use Epic Account Services, players of your game must have an Epic Games account (or a proxy account).

The following services and their interfaces are EOS Epic Account Services:

  • EOS Group of Services

    • Accounts and Social

  • Epic Games Store Service

    • Epic Games Store in-app purchases (known as “Ecom” and “Ecommerce”) Documentation: Epic Games Store > Epic Games Store Services > Ecommerce

Note: The Auth service is also available as a web API. See the Auth Web APIs documentation for more information. This guide does not cover how to use the Auth Web APIs.

The Auth Interface lets players sign in to your game (or other software application) to access EOS Epic Account Services. Through the Auth service, you can authenticate players, get authorization credentials (access tokens), and handle other interactions between players’ Epic Games accounts and Epic Online Services (EOS).

Note: If your game requires players to use both type of service (both EOS Game Services and EOS Epic Account Services), they must log in to EOS Game Services with their Epic Games account or a proxy account. If players use EOS Epic Account Services in your game, they cannot log in to EOS Game Services with a supported external identity provider.

This guide consists of the following sections:

    1. Set Up Epic Account Services
    1. Sign In With the Dev Auth Tool
    1. Sign In With the Account Portal

Note: This guide follows an order. However, only section 1. Set Up Epic Account Services is a pre-requisite to access Epic Account Services in your game. You can follow any section of this guide from section 2 onwards independently of each other and in any order.

For more information on the Auth Interface, see the Auth Interface Reference documentation.
