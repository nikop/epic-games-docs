View the Details of a Variable Definition (Localized Rich Presence)

How to view the details of a localized rich presence variable definition.

1 min to read

Use localized rich presence variables to display dynamic content in your rich presence messages, such as the map that a player is currently on. Create variable definitions to ensure that only valid content can appear in your presence messages. For more information, see Variable Definitions for Localized Rich Presence Messages — Introduction.

ENUM Variable Definitions

For ENUM variable definitions you can view the following details:

  • The set of accepted values. Accepted values are the possible values that your game can send to the template when it calls setOnlinePresence. For more information, see documentation: Display Localized Presence in Your Game.
  • The localized text for each accepted value.

Number Variable Definitions

For number variable definitions, you can view the minimum value and maximum allowed values.

View the Details of a Variable Definition

To view the details of a variable definition:

  1. In the Developer Portal, go to the Localized Presence page. To do this:
    a. Sign in to the Developer Portal (dev.epicgames.com/portal).
    b. Select the correct organization for your product.
    c. In the left navigation, under Your products, click the name of your product.
    d. In the left navigation, click Epic Online Services.
    e. In the left navigation, under Accounts and Social, click Localized Presence.
  2. Click the Variable Definitions tab:

  1. In Deployment, select the appropriate deployment.

  2. In the list of variable definitions, locate the variable definition you want to view.

    • You can search the list. See Find a Specific Variable Definition.

  3. Click the downwards arrow to expand the variable details:

  4. For ENUM variable definitions, you can click the downwards arrow next to an accepted value to view the localized text for that value.
