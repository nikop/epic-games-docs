Guide: Add Stats to Your Game — 1. Set Up Stats

Step-by-step guide on how to set up player stats for your game in the Developer Portal.

4 mins to read

Previous section: Introduction

To use the EOS SDK API to interact with your game's stats, you must first set up stats in the Developer Portal.

Before You Start

Before you start, you must integrate the EOS SDK into your code. (Documentation: Guide: Get Started With EOS.)

Note: We recommend that you set up the Logging Interface to receive useful messages that can help you diagnose technical issues with the EOS SDK. (Documentation: Logging Interface.)

Configure Your Game in the Developer Portal

Complete the following steps in the Developer Portal to set up the available stats for your game:

  • Step 1: Configure Your Game's Client Policy
  • Step 2: Configure Your Game's Stats

Step 1: Configure Your Game's Client Policy

Note: This guide uses a preset client policy type, but for your game in a production environment we recommend that you create your own custom client policy to ensure your game is secure. For more information on client policies, see the following documentation: Guide: Manage Your Clients and Client Policies.

You configure your game's client policy in the Developer Portal, on the Product Settings page's Clients tab. To do this, follow the steps below. (Note that in the Developer Portal, your game is usually known as a "product".)

To go to the Clients tab:

A. Go to your game's product page in the Developer Portal.

  • To do this:
    a. Sign in to the Developer Portal at (dev.epicgames.com/portal).
    b. In the left navigation, under Your Products, click the name of your game (or software application).
    • Note: You might have to click Back to organization before you can do this.

B. In the left navigation, click Product Settings.
C. From the default tab (SDK Download & Credentials), click Clients.

Note that the Clients tab might show new agreements to accept.

On the Clients tab:

A. Scroll down to the Client policies section. (This is below the Clients section.)
B. Either create a new client policy or enable the Stats feature for an existing client policy.

  • To create a new client policy:
    a. Click Add new client policy. (Do not click “Add new client”.)
    b. For Client policy name, enter a name of your choice.
    c. For Client policy type, select GameClient w/ Unlock Achievements.

    • You can choose GameClient but we recommend GameClient w/ Unlock Achievements so you can unlock achievements later (note this guide does not cover achievements).
    • Note: Both client policy types listed above already include the permissions you need to retrieve stats for the local player (a player's own stats on their device).

    d. Leave the default options and click Add new client policy. The default options include the Stats feature enabled.

  • To enable the Stats feature for an existing client policy:
    a. Locate the client policy and click the three dots (...) next to it, then select Edit.
    b. In the Edit client policy pane, scroll down to Features and use the Stats toggle to enable the stats feature.

Step 2: Configure Your Game's Stats

These steps demonstrate how to configure your game's stats individually in the Developer Portal.

Note: You can also use the Bulk Importer and Exporter Tool to set up multiple stats in one action. For more information, see the Tool: Bulk Import / Export documentation.

You configure your game's stats individually in the Developer Portal on the Stats page. To do this, follow the steps below.

To go to the Stats page:

A. Go to your game's product page in the Developer Portal.

  • To do this:
    a. Sign in to the Developer Portal at (dev.epicgames.com/portal).
    b. In the left navigation, under Your Products, click the name of your game.
    • Note: You might have to click Back to organization before you can do this.

B. In the left navigation, click Epic Online Services.
C. In the Player and Game Data section, click Stats.

On the Stats page:

A. From the Deployment dropdown, select a deployment if it's not already selected.

  • Note: Stats you create are shared for all deployments in a sandbox. However, player data for stats are not shared for all deployments in a sandbox. Be sure to remember which sandbox your deployment is attached to. The name of the sandbox is highlighted beside the name of the deployment. For example, the default deployment is Release and the default sandbox is Live. The deployment dropdown displays each sandbox in its own section, with the available deployments for a sandbox listed directly below the sandbox name.

B. Click Create stat.
C. In the Name field, enter a name for the new stat. This is a name of your choice that is meaningful to you. You will refer to this stat name in your game code.

  • The name must consist only of letters, numbers, or the underscore character (_) with no spaces.
  • (The example stat names this guide uses are as follows but you can use any stat names you choose: AmountOfGammaCollected, LongestJumpDistance, NumberOfCarsSmashed, NumberOfEnemiesDefeated, LongestTransformation.)

D. Select an Aggregation Type. (Glossary: Aggregation type)

Repeat these steps to create as many stats as your game requires.

Results

The stats display on your game's Stats page in the Developer Portal.
