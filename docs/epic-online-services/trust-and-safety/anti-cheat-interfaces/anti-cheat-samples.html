Anti-cheat Samples

Overview of the Anti-cheat Samples.

7 mins to read

Note: Anti-Cheat does not support the following platforms: Linux ARM64 (Anti-Cheat Client Interface), Android, iOS, and console platforms.
Anti-Cheat requires EOS SDK 1.15 or higher, the start_protected_game.exe from EOS SDK 1.16 or higher, and a 64-bit operating system.

The anti-cheat Samples use the EOS SDK written in C. They demonstrate how to implement Easy Anti-Cheat with two different sample applications:

  • Anti-Cheat Server
  • Anti-Cheat Client

Note: To test Easy Anti-Cheat, you must build and run both of these sample applications. The samples demonstrate these features:

  • Join a protected game session.
  • Leave a protected game session.
  • Anti-cheat communication logs.

See the Anti-Cheat Interfaces documentation for more information on anti-cheat.

Before You Begin

To use these sample applications, you must meet these requirements:

  • An existing game (referred to as "test game" below) with the following configurations:
    • Epic Account Services configured for your game. See the Epic Account Services documentation for more information on how to set up Epic Account Services for your game.
    • Easy Anti-Cheat configured for your game. See the Anti-Cheat Interfaces documentation for more information on how to configure anti-cheat for your game.
  • The EOS SDK in C downloaded and unzipped. Download this from the Developer Portal. See the Guide: Get Started With EOS > 1. Set Up Your Account and Download the EOS SDK documentation for more information on how to download the EOS SDK.
  • If you use macOS or Linux, you must have these items installed:
    • SDL2
    • SDL2_ttf
    • SDL2_net
    • GLEW
    • cmake
    • gcc (through Command Line Tools for Xcode for Mac)

Step 1: Configure the Samples

Before you can use the samples, you must configure them to use your game's credentials. Follow the steps below for your operating system.

Windows

Follow these steps on Windows to configure the sample applications to use your test game's credentials. Configure these settings for each sample application separately:

  1. In the \EOS-SDK-[version]\Samples\ directory, open Samples.sln. Visual Studio opens it in the Solution Explorer.
  2. From the Solution Explorer, expand the sample application's file structure.
  3. Open the sample application's \Source\SampleConstants.h file.
  4. Replace the values for ProductId, SandboxId, DeploymentId, ClientCredentialsId (Client ID in the Developer Portal), and ClientCredentialsSecret (Client Secret in the Developer Portal) with the values for your test game. You can find these values in the Developer Portal, under your Product's Product Settings > SDK Download & Credentials tab, listed beneath the EOS SDK Credentials heading.

MacOS and Linux

On macOS and Linux, follow these steps for each sample application, separately, to configure the sample applications to use your test game's credentials:

  1. In Terminal, go to the sample application's directory:
    • Anti-Cheat Client: /EOS-SDK-[version]/Samples/AntiCheat/Client/
    • Anti-Cheat Server: /EOS-SDK-[version]/Samples/AntiCheat/Server/
  2. Open SampleConstants.h from the project and update ProductId, SandboxId, DeploymentId, ClientCredentialsId (Client ID in the Developer Portal), and ClientCredentialsSecret (Client Secret in the Developer Portal) based on the values for your test game. You can find these values in the Developer Portal, under your Product's Product Settings > SDK Download & Credentials tab, listed beneath the EOS SDK Credentials heading.

Step 2: Build the Samples

To build the samples, follow the steps below for your system.

Windows

Follow these steps for each app, separately, to build the sample applications on Windows:

  1. From the Solution Configurations dropdown in Visual Studio's toolbar, select:
    • Anti-Cheat Client: Release_DX or Debug_DX.
    • Anti-Cheat Server: Release or Debug.
  2. From the Solution Platforms dropdown in the toolbar, select x64 (Win64).
  3. In the Solution Explorer, right-click the sample application's project (shown below) and click Build.
    • Anti-Cheat Client: AntiCheat
    • Anti-Cheat Server: AntiCheatServer
  4. After a successful build, the EXE is available under the corresponding directory:
    • Anti-Cheat Client: \EOS-SDK\Samples\AntiCheat\Client\Bin\Win64\Release_DX\AntiCheat.exe
    • Anti-Cheat Server: \EOS-SDK\Samples\AntiCheat\Server\Bin\Win64\Release\AntiCheatServer.exe

MacOS and Linux

Follow these steps for each app, separately, to build the sample applications on macOS or Linux:

  1. Go to the project's directory:
    • Anti-Cheat Client: /EOS-SDK/Samples/AntiCheat/Client
    • Anti-Cheat Server: /EOS-SDK/Samples/AntiCheat/Server
  2. Run ./Build.sh (or you can run Build.command from Finder on Mac). After the build successfully completes, the sample application is listed under the corresponding directory:
    • Anti-Cheat Client: /EOS-SDK/Samples/AntiCheat/Client/Build/
    • Anti-Cheat Server: /EOS-SDK/Samples/AntiCheat/Server/Build/

Step 3: Set up and Run the Anti-Cheat Integrity Tool

To use the sample applications, you must install and configure the Anti-Cheat integrity tool for the Anti-Cheat Client sample application. After you set up the Anti-Cheat integrity tool, you can use it to generate an index file that the Easy Anti-Cheat module can validate against. For more information on how to configure the Anti-Cheat integrity tool for your game, see the Anti-Cheat Integrity Tool Configuration section of the Using the Anti-Cheat Interfaces documentation.

Follow the steps below to configure and run the Anti-Cheat integrity tool for the sample applications for your system.

  1. Go to the anti-cheat tools directory for your operating system as follows:
    • Windows: EOS-SDK\SDK\Tools\EOS_AntiCheatTools-win32-x64-[version]
    • MacOS or Linux: EOS-SDK\SDK\Tools\EOS_AntiCheatTools-[linux/mac]-x64-[version]
  2. Unzip EOS_AntiCheatTools-[version]\dist into the Anti-Cheat Client sample application directory for your OS:
    • Windows: [ClientSampleDir]\Bin\Win64\Release_DX
    • MacOS and Linux: /EOS-SDK-[version]/Samples/Anti-Cheat/Client/
  3. In the EasyAntiCheat/Settings.json file, fill in ProductId, SandboxId, and DeploymentId, and set the executable to the AntiCheat executable path:
    • Windows: AntiCheat.exe
    • MacOS: Build/AntiCheat.app/Contents/MacOS/AntiCheat
    • Linux: Build/AntiCheat
  4. Unzip the integrity tool EOS_AntiCheatTools-[version]\devtools to a directory of your choice, excluding the game directory or any of its subdirectories.
  5. Download your game's integrity tools from the Developer Portal. Follow these steps:
    • Go to the Developer Portal at https://dev.epicgames.com/portal.
    • Select your product from the left-side menu and go to Game Services > OPERATIONS > Anti-Cheat.
    • Click DOWNLOAD INTEGRITY KEYS at the top.
  6. Extract and move the base_private.key and base_public.cer files from the tooling zip file so that they are in the same directory as the anticheat_integritytool executable or app.
  7. Open the command line or terminal for your system and run the command below (replace CLIENT_SAMPLE_DIRECTORY and YOUR_EOS_PRODUCTID with your own values):
    • Windows: anticheat_integritytool.exe -target_game_dir CLIENT_SAMPLE_DIRECTORY\Bin\Win64\Release_DX -productid YOUR_EOS_PRODUCTID
    • MacOS and Linux: ./anticheat_integritytool -target_game_dir CLIENT_SAMPLE_DIRECTORY -productid YOUR_EOS_PRODUCTID
  8. Run EasyAntiCheat_EOS_Setup.exe install YOUR_EOS_PRODUCT_ID (replace YOUR_EOS_PRODUCTID with your own value).
  9. On success, the tool outputs files to the EasyAntiCheat\Certificates subdirectory of the target_game_dir you specified.

Step 4: Use the Samples

To use the Anti-Cheat samples, you must do the following:

  1. If you are using ClientServer (client-server) mode, start the Anti-Cheat Server sample application.
    • For information on client-server mode, see Anti-Cheat Interfaces—Game Network Architecture.
  2. Join a game in the Anti-Cheat Client sample application.

Start the Anti-Cheat Server

Note: You only need to follow this step if you are using the sample in ClientServer mode.

To run the Anti-Cheat Server sample application:
Windows:

  1. Open the Command Line.
  2. Go to the Anti-Cheat Server directory: \EOS-SDK\Samples\AntiCheat\Server\Bin\Win64\Release\.
  3. Run AntiCheatServer.exe.

MacOS and Linux:

  1. Open the Terminal.
  2. Go to the Anti-Cheat Server directory: /EOS-SDK/Samples/AntiCheat/Server/
  3. Run ./Run.sh (or you can run Run.command from Finder on Mac).

You can leave the Anti-Cheat Server running.

Note: The Anti-Cheat Server prints debug text to the console and to the debug log file (DebugOutput.log by default). It prints errors in red text and warnings in yellow text.

To stop the server, run this command from the Anti-Cheat Server's console:
Windows or Linux: Use Ctrl+C to stop the Server application.
MacOS: Use CMD+. (period) to stop the Server application.

Start the Anti-Cheat Client

To run the Anti-Cheat Client sample application, follow these steps:
Windows:

  1. Open the Command Line.
  2. Go to the Anti-Cheat Client sample directory: \EOS-SDK-[version]\Samples\AntiCheat\Client\Bin\Win64\Release_DX\.
  3. Run start_protected_game.exe.

MacOS and Linux:

  1. Open the Terminal.
  2. Go to the Anti-Cheat Client sample directory: /EOS-SDK-[version]/Samples/Anti-Cheat/Client/.
  3. Run ./Run.sh (or you can run Run.command from Finder on Mac).

Sign In

From the right-side panel, click one of these options to sign in:

  • Dev Auth: Enter the host port and credentials that you configured for the Developer Authentication Tool (for example, 127.0.0.1:8080 if you set 8080 for the host port) and click LOG IN. See the Developer Authentication Tool documentation for more information on the Developer Authentication Tool.
  • Account Portal: Click LOG IN to sign in through the Account Portal with your Epic Games account credentials or a supported identity provider. See the Identity Provider Management documentation for more information on identity providers.

Options

After you sign in with the Anti-Cheat Client sample application, you can use these options in it:

Option Description
Mode Choose whether to use ClientServer or P2P mode for anti-cheat. For information on client-server and peer-to-peer modes, see Anti-Cheat Interfaces—Game Network Architecture.
JOIN GAME SERVER Start a protected game session. Use the IP and Port text fields to configure which game server to join. Default values of these fields correspond to the default configuration of the Anti-Cheat Server Sample. This option is only available in ClientServer mode.
LEAVE GAME SERVER Leave the protected game session. This option is only available in ClientServer mode.
START P2P SESSION Start a protected game session. Use the Listen Port text field to specify what port this instance of the sample will listen on for incoming peer connections. This option is only available in P2P mode.
END P2P SESSION Leave the protected game session. This option is only available in P2P mode.
REGISTER PEER Connect to another instance of the sample that has started a protected game session in P2P mode. Use the IP and Port text fields to configure which peer to connect to. For Port, use the value that was specified in the Listen Port text field for the other instance of the sample. This option is only available in P2P mode.
