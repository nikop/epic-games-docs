Guide: Add Stats to Your Game — 3. Retrieve Stats

Step-by-step guide on how to retrieve player stats in your game code.

27 mins to read

Previous section: 2. Update Values for Stats

This section of the guide is available in C++ and C#. The C++ version uses the EOS SDK API in C.

You can add code to your game to retrieve a player's stats after you have completed the precursor steps listed in Before You Start, below.

To add code to your game to retrieve a player's stats, you query the stats to save them to the local cache. Then you can copy the cached stats and access the data for each stat. For example, you can query all the stats for a player and then display them to the player in a personal dashboard.

You can either copy the player's cached stats by stat name (for example, AmountOfGammaCollected, LongestJumpDistance, NumberOfCarsSmashed, NumberOfEnemiesDefeated, or LongestTransformation) or copy them all. This guide shows how to copy all stats for a player. For information on how to copy a player's stats individually by stat name, see the EOS_Stats_CopyStatByName function API reference documentation.

Note: You can only retrieve a player's value for a stat if your game has set a value for it. For example, if player Alice has no value for AmountOfGammaCollected, you cannot retrieve a value for AmountOfGammaCollected for Alice. (Section in this guide: 2. Update Values for Stats.)

The example code snippets in this guide are for guidance only. If you use the snippets, make sure you tailor them to the unique circumstances of your game.

Before You Start

Before you start, you must complete these steps:

  • Integrate the EOS SDK into your code. (Documentation: Guide: Get Started With EOS).
  • Use the Connect Interface in your code to get the local player’s Product User ID. (Documentation: Guide: Access Game Services With the Connect Interface.)
  • Set up stats. (Section in this guide: 1. Set Up Stats.)
  • Set the value for the stats. (Section in this guide: 2. Update Values for Stats.)

Step 1: Modify Your Stats Manager Class

Modify your stats manager class .h file to include the declarations for the functions and variables that you need to retrieve stats.

Note: The example code below is not the complete code. It includes only the additions that you must make to your stats manager class .h file. For the complete code, see the complete code snippet after these steps in the Complete Code section.

Example:

StatsManager.h 

// StatsManager.h #include <map>#include <string>... class StatsManager{public:    /**      * Getter for a read-only copy of the map.      *      * @return A read-only copy of the RetrievedStats map.     */    const std::map<std::string, int32_t>& GetRetrievedStats() const { return RetrievedStats; }        /** Function to manage querying all stats. */    void RetrieveAllStatsExample();    ... private:    /** Map to hold copied stat name, value pairs. */    std::map<std::string, int32_t> RetrievedStats;     /**      * Callback function that executes when the stats query completes.      *     * @param Data - Information passed to the callback function by the EOS SDK.     */    static void EOS_CALL OnQueryAllStatsComplete(const EOS_Stats_OnQueryStatsCompleteCallbackInfo* Data);     /** Function to copy all the player's stats after a query. */    void CopyAllStatsExample();    ...}

What's happening in the code?

The following sub-steps are a breakdown of the code example above.

  1. In your stats manager .h file, declare a public function to get read-only access to the stats map. (Note: The map itself is declared as a private variable and described in more detail in a step below.) In the example, it's called GetRetrievedStats:

    const std::map<std::string, int32_t> RetrievedStats& GetRetrievedStats() const { return RetrievedStats; }

  2. Declare a public function to query the player's stats. In the example, it's called RetrieveAllStatsExample:

    void RetrieveAllStatsExample();

  3. Declare a private map to hold stat name (string) and stat value (int32_t) pairs for the stats that you want to copy for the player. In the example, it's called RetrievedStats:

    std::map<std::string, int32_t> RetrievedStats;

    Note: When you query stats for a player, the EOS SDK saves those stats to the local cache. So, as you make more queries, the SDK fills the local cache with stats for various players.

    Tip: This example stores the stat name and its associated value in a map. This makes it easier to look up a stat and retrieve its value when you need it.

  4. Declare a private callback function to execute after the query completes. The function definition must match the EOS API EOS_Stats_OnQueryStatCompleteCallback callback. In the example, it's called OnQueryAllStatsComplete:

    static void EOS_CALL OnQueryAllStatsComplete(const EOS_Stats_OnQueryStatsCompleteCallbackInfo* Data);

  5. Declare a private function to copy the player's queried stats from the local cache. In the example, it's called CopyAllStatsExample:

    void CopyAllStatsExample();

Step 2: Implement Your Query All Stats Function

In your .cpp file, in your stats manager class, implement the query function to retrieve all the stats for a player.

Example:

void StatsManager::RetrieveAllStatsExample(){    // Create a data structure to hold the options to query stats.    EOS_Stats_QueryStatsOptions QueryStatsOptions = {};    QueryStatsOptions.ApiVersion = EOS_STATS_QUERYSTATS_API_LATEST;     // The Product User ID of the local player requesting the query.    QueryStatsOptions.LocalUserId = LocalProductUserId;     // The Product User ID for the player whose stats you want to query.    QueryStatsOptions.TargetUserId = LocalProductUserId;     // Set to something other than undefined to get stats starting from a certain POSIX time, and not before.    QueryStatsOptions.StartTime = EOS_STATS_TIME_UNDEFINED;     // Set to something other than undefined to get stats ending at a certain POSIX time and not after.    QueryStatsOptions.EndTime = EOS_STATS_TIME_UNDEFINED;     // Call the EOS SDK to query your stats.    // The callback function executes when the `QueryStats` function completes.    EOS_Stats_QueryStats(StatsHandle, &QueryStatsOptions, this, OnQueryAllStatsComplete);}

Note: Your client policy configuration determines which player you can query stats for (QueryStatsOptions.TargetUserId). It can be either the local player (local user ID) or another player (non-local user ID). For more information, see this guide's section: 1. Set Up Stats > Step 1: Configure Your Game's Client Policy.

What's happening in the code?

The following sub-steps are a breakdown of the code example above.

  1. In your stats manager class, implement the function to query the player's stats. In the example, it's called RetrieveAllStatsExample:

    void StatsManager::RetrieveAllStatsExample(){ }

  2. Create an instance of the EOS_Stats_QueryStatsOptions data structure to hold the query options for the player's stats. In the example, it's called QueryStatsOptions:

    EOS_Stats_QueryStatsOptions QueryStatsOptions = {};QueryStatsOptions.ApiVersion = EOS_STATS_QUERYSTATS_API_LATEST;QueryStatsOptions.LocalUserId = LocalProductUserId;QueryStatsOptions.TargetUserId = LocalProductUserId;QueryStatsOptions.StartTime = EOS_STATS_TIME_UNDEFINED;QueryStatsOptions.EndTime = EOS_STATS_TIME_UNDEFINED;

    Note: Your client policy configuration determines which player you can query stats for (QueryStatsOptions.TargetUserId). It can be either the local player (local user ID) or another player (non-local user ID). See this guide's section 1. Set Up Stats > Step 1: Configure Your Game's Client Policy for more information.

  3. Call the EOS API EOS_Stats_QueryStats() function. This function saves the player's stats to the local cache.
    The function takes the following arguments:

    • Stats Interface handle.
    • A reference to the query options for the stats.
    • (Optional) ClientData.
      In the example, we pass the stats manager (this in the example) for the ClientData field, so we can access it in the callback.
      If you don't need to pass any additional data to the callback, pass a nullptr instead.
    • A callback function to receive the EOS_Stats_OnQueryStatsCompleteCallbackInfo data structure` when the EOS Stats service completes the stats query.
    EOS_Stats_QueryStats(StatsHandle, &QueryStatsOptions, this, OnQueryStatByNameComplete);

Step 3: Implement Your Query All Stats Callback Function

In your .cpp file, implement your query stats callback function.

Example:

void EOS_CALL StatsManager::OnQueryAllStatsComplete(const EOS_Stats_OnQueryStatsCompleteCallbackInfo* Data){    if (Data->ResultCode == EOS_EResult::EOS_Success)    {        // If the code gets here, the stats were queried successfully.         // Retrieve the StatsManager pointer from the client data passed        // into the callback function.        StatsManager* Self = static_cast<StatsManager*>(Data->ClientData);         // Copy all stats.        Self->CopyAllStatsExample();    }    else if (EOS_EResult_IsOperationComplete(Data->ResultCode) == EOS_FALSE)    {        // If the code gets here, the operation is retrying and is not yet complete.        return;    }    else    {        // If the code gets here, there was an error.        // Handle this however you need for your game.        std::cerr << "Error querying all stats! Error code: " << static_cast<int>(Data->ResultCode) << " - " << EOS_EResult_ToString(Data->ResultCode) << std::endl;    }}

What's happening in the code?

The following sub-steps are a breakdown of the code example above.

  1. In your .cpp file, implement the callback function that executes when the EOS_Stats_QueryStats() function completes. The function definition must match the EOS_Stats_OnQueryStatsCompleteCallback callback which receives a EOS_Stats_OnQueryStatsCompleteCallbackInfo data structure. In the example, it's called OnQueryAllStatsComplete:

    void EOS_CALL StatsManager::OnQueryAllStatsComplete(const EOS_Stats_OnQueryStatsCompleteCallbackInfo* Data){ }

    Notes:

    • The EOS SDK calls this callback function asynchronously each time the EOS_Stats_IngestStat() function completes.
    • The EOS_CALL macro is part of the required definition.

  2. In your callback function, use the returned EOS_EResult Enum to confirm that the query is successful. If the query is successful, retrieve the stats manager pointer from the client data and call your function to copy the player's stats:

    if (Data->ResultCode == EOS_EResult::EOS_Success){    StatsManager* Self = static_cast<StatsManager*>(Data->ClientData);    Self->CopyAllStatsExample();}

  3. Use the EOS_EResult_IsOperationComplete function to check if the query is not complete yet. if the query is not complete, return so the operation can complete:

    else if (EOS_EResult_IsOperationComplete(Data->ResultCode) == EOS_FALSE){    return;}

  4. If the query is not successful, handle the errors.

    else{    std::cerr << "Error querying stats! Error code: " << static_cast<int>(Data->ResultCode) << " - " << EOS_EResult_ToString(Data->ResultCode) << std::endl;}

    Tip: Use the EOS_EResult_ToString() function to convert the E_EResult Enum to a string, which gives the name of the error type.

Step 4: Implement Your Copy All Stats Function

In your .cpp file, implement your copy-all-stats function.

Example:

void StatsManager::CopyAllStatsExample(){	    // Create a data structure to hold the stat count options.    EOS_Stats_GetStatCountOptions StatsCountOptions = {};    StatsCountOptions.ApiVersion = EOS_STATS_GETSTATSCOUNT_API_LATEST;     // The Product User ID of the player whose stats you want to count.    StatsCountOptions.TargetUserId = LocalProductUserId;     // Get the total number of stats from the EOS SDK.    uint32_t NumStats = EOS_Stats_GetStatsCount(StatsHandle, &StatsCountOptions);     // Loop through the player's stats and copy each one to the stats map.    for (uint32_t StatIndex = 0; StatIndex < NumStats; StatIndex++)    {         // Create a data structure to hold the options to copy the stats.        EOS_Stats_CopyStatByIndexOptions CopyStatOptions = {};        CopyStatOptions.ApiVersion = EOS_STATS_COPYSTATBYINDEX_API_LATEST;         // The Product User ID of the player whose stat you want to copy.        CopyStatOptions.TargetUserId = LocalProductUserId;         // The index of the stat that you want to copy.        CopyStatOptions.StatIndex = StatIndex;         // A variable to temporarily hold the copied stat data.        EOS_Stats_Stat* Stat = nullptr;         // Call the EOS SDK to copy the player's stats.        EOS_EResult CopyStatResult = EOS_Stats_CopyStatByIndex(StatsHandle, &CopyStatOptions, &Stat);         if (CopyStatResult == EOS_EResult::EOS_Success && Stat != nullptr)        {            // Store the retrieved stat in the map.            std::cout << "Stat retrieved - " << Stat->Name << ": " << Stat->Value << std::endl;            RetrievedStats[Stat->Name] = Stat->Value;             // Free the stat's memory when you're finished with it.            EOS_Stats_Stat_Release(Stat);        }        else        {            // If the code gets here, there was an error.            // Handle this however you need for your game.            std::cerr << "Error copying all stats! Error code: " << static_cast<int>(CopyStatResult) << " - " << EOS_EResult_ToString(CopyStatResult) << std::endl;        }    }}

What's happening in the code?

The following sub-steps are a breakdown of the code example above.

  1. In your .cpp file, implement the function to copy the player's stats and save those stats to a map for retrieval later on. In the example, it's called CopyAllStatsExample:

    void StatsManager::CopyAllStatsExample(){ }

  2. In your copy function, create an instance of the EOS_Stats_GetStatCountOptions data structure to hold the count options for your stats. You will use these options to get the total number of stats that are cached locally. In the example, it's called StatsCountOptions:

    EOS_Stats_GetStatCountOptions StatsCountOptions = {};StatsCountOptions.ApiVersion = EOS_STATS_GETSTATSCOUNT_API_LATEST;StatsCountOptions.TargetUserId = LocalProductUserId;

  3. Call the EOS API EOS_Stats_GetStatsCount() function to get the number of stats stored in the local cache, and assign the value to a variable to hold the returned count.
    The function takes the following arguments:

    • Stats Interface handle.
    • A reference to the count options for the stats.
    uint32_t NumStats = EOS_Stats_GetStatsCount(StatsHandle, &StatsCountOptions);

  4. Use the stats count to iterate through the list of queried stats that you want to copy:

    for (uint32_t StatIndex = 0; StatIndex < NumStats; StatIndex++)

  5. In the for loop, create an instance of the EOS_Stats_CopyStatByIndexOptions data structure to hold the copy options for your stats. In the example, it's called CopyStatOptions:

    EOS_Stats_CopyStatByIndexOptions CopyStatOptions = {};CopyStatOptions.ApiVersion = EOS_STATS_COPYSTATBYINDEX_API_LATEST;CopyStatOptions.TargetUserId = LocalProductUserId;CopyStatOptions.StatIndex = StatIndex;

  6. Define a pointer to store the copied stat data. In the example, it's called Stat:

    EOS_Stats_Stat* Stat = nullptr;

  7. Call the EOS API EOS_Stats_CopyStatByIndex() function to copy the player's stats from the local cache. Store the returned EOS_EResult Enum from the EOS_Stats_CopyStatByIndex() function in a variable. In this example, it's called CopyStatResult. You'll use this to verify the result of the function call in the next step.
    The function takes the following arguments:

    • Stats Interface handle.
    • A reference to the copy options for the stats.
    • A reference to the stat pointer to hold the returned stat data.
    EOS_EResult CopyStatResult = EOS_Stats_CopyStatByIndex(StatsHandle, &CopyStatOptions, &Stat);

  8. If the EOS_Stats_CopyStatByIndex() function call is successful, retrieve data for the stat from the stat pointer variable that you passed, and save the stat name and stat value pair to the stats map:

    if (CopyStatResult == EOS_EResult::EOS_Success && Stat != nullptr){    std::cout << "Stat retrieved - " << Stat->Name << ": " << Stat->Value << std::endl;    RetrievedStats[Stat->Name] = Stat->Value;

  9. Call the EOS API EOS_Stats_Stat_Release function to release the memory for the stat pointer variable when you've finished using it:

    EOS_Stats_Stat_Release(Stat);}

  10. If the EOS_Stats_CopyStatByIndex() function call is not successful, handle any errors:

    else{    std::cerr << "Error copying all stats! Error code: " << static_cast<int>(CopyStatResult) << " - " << EOS_EResult_ToString(CopyStatResult) << std::endl;}

    Tip: Use the EOS_EResult_ToString() function to convert the E_EResult Enum to a string, which gives the name of the error type.

Results

After you call the EOS_Stats_CopyStatByIndex() function, on success you can access the EOS_Stats_Stat data structure through the stat pointer that you passed in the EOS_Stats_CopyStatByIndex() function call. The EOS_Stats_Stat data structure contains information about the player's stat.

You can access the stats in your game code through the StatsManager::GetRetrievedStats function in the example code. Make sure there are no stat queries in progress before you call GetRetrievedStats. If there are queries in progress, the stats you retrieve might not include the latest updates from the active query and will therefore be outdated.

Notes

The cached stat data does not clear until after you have shut down the EOS SDK. This means that if you copy stat data for multiple players, the stat data for all players is added to the cache. To access stat data efficiently, we recommend that you save the stat data; the example code in this guide did this by saving to a map.
