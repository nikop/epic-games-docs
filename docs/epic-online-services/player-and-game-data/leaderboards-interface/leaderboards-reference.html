Leaderboards Interface Reference

Reference for the Leaderboards Interface.

3 mins to read

Use the EOS Leaderboards service to track and rank player stats in your game (or other software application).

Leaderboards rank your players by score for selected stats over a period of time that you specify. This lets your players compete with their friends or other players worldwide for the top ranking. Some examples of leaderboards include:

  • Rank all global players by the total number of enemies defeated.
  • Rank players by how much gamma radiation they have collected during a special timed event.
  • Offer players a way to compare who has the longest jump distance between friends.

See the Leaderboards Interface guide and Leaderboards Interface API documentation for details on how to integrate the service into your game.

Stat Milestones

You are limited to 100 unique milestones across all of your game's leaderboards, per deployment.

For example, you create the first leaderboard for your game with the following settings:

  • Start date: July 14th, 2025 at 9 AM
  • End date: July 25, 2025 at 5 PM

In the example, you create two stat milestones: one for the start date and one for the end date. This leaves 98 possible milestones to use for all the leaderboards in your game.

Using the same example, you create a second leaderboard with the following settings:

  • Start date: July 14th, 2025 at 9 AM (the same start date as the first leaderboard)
  • End date: July 30, 2025 at 5 PM (a different end date from the first leaderboard)

To add the second leaderboard, you only need to create one new stat milestone. You would reuse the existing stat milestone for the start date of July 14th, 2025 at 9 AM and create one new stat milestone for the end date of July 30, 2025 at 5 PM. This leaves 97 stat milestones to use for all the other leaderboards in your game.

Notes:

  • Leaderboards with no set end date (set to never expire) only use one stat milestone for the start date (if it's a unique start date that isn't shared by one of your other leaderboards).
  • The EOS SDK automatically deletes a stat milestone when the leaderboards in your game no longer reference it. This frees up a slot for other stat milestones.

Usage Limitations

For general information about throttling, usage quotas, and best practices, see the documentation on service usage limitations: EOS SDK Conventions and Limitations > Service Usage Limitations.

The following limits apply to a deployment's overall use of leaderboards:

Feature Limitation
Number of global leaderboards Limited by available milestones (see Stats Milestones on this page).
Total global leaderboard entries 1000 (+1000 overflow)
Number of friend leaderboards Unlimited (see Stats Milestones on this page).
Note: Friend leaderboards are made by directly querying Stats and are not affected by the global leaderboard limit.

There are also usage-rate limitations that apply on a per-user or per-deployment basis. Per-user limitations apply to individual users playing games and viewing existing leaderboards, while per-deployment limitations apply to calls that create or delete those leaderboards.

Feature Per-User Limitation Per-Deployment Limitation
Get a single leaderboard value 100 requests per minute -
Get all leaderboard values 10 requests per minute -
Create a leaderboard - 100 requests per minute
Delete a leaderboard - 100 requests per minute
