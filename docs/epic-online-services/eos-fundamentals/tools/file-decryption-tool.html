Tool: File Decryption

Manage files loaded to the Title Storage and Player Data Storage associated with your game.

2 mins to read

Use the File Decryption tool to encrypt or decrypt files loaded to Title Storage (documentation: Title Storage Interface) and Player Data Storage (documentation: Player Data Storage Interface).

For information on other tools that help you access, link, and delete the data stored on behalf of your players by Epic Online Services, see documentation: EOS Player Search.

The File Decryption tool is a command-line tool that is part of the EOS SDK distribution. To encrypt a file, you must specify an encryption key. To decrypt a file, you must provide the key that you used to encrypt the file.

You can encrypt or decrypt a single file or multiple files with one command, as follows:

  • If you specify a single file as the input, the tool encrypts or decrypts the file and outputs the result to another file.
  • If you specify a directory, the tool goes through all files in the directory, and its subdirectories, and places the output files in a duplicate directory structure.

The Title Storage Interface maintains a local cache, so you can copy encrypted files from that cache and decrypt them.

You must set the tool into the appropriate mode for the type of files that you want to encrypt or decrypt: Title Storage or Player Data Storage.

  • To encrypt or decrypt Title Storage files, use the -mode title parameter to enable Title Storage mode.
  • To encrypt or decrypt Player Data Storage files, you do not need to set the mode because the tool supports Player Data Storage files by default.
  • If the tool encounters a Player Data Storage file while in Title Storage mode, or a Title Storage file while in Player Data Storage mode, it skips over the file and reports an error.

Parameter Listing

Parameter Effect
-input (Location) Sets the path to the file (or directory) containing encrypted data to read
-output (Location) Sets the path to the file (or directory) where the decrypted data will be written
-key (EncryptionKey) Sets the encryption key to use for encrypting and decrypting operations. The key must be in hexadecimal and no more than 64 characters long
-mode (title for Title Storage mode or user for Player Data Storage mode) Enables Title Storage or Player Data Storage mode (Player Data Storage mode is the default)
-encrypt Enables encryption mode, meaning the output files will be encrypted copies of the input files; if not set, the output files will be decrypted copies of the input files

Note: The data format of the input files is unknown to the tool, so providing an incorrect encryption key does not cause an error. However, the output files will be unusable by the application due to the mismatch between keys.

Sample Command Lines

  • FileDecryptionTool -input encrypted_ts_data -output unencrypted_ts_data -key 123abcdef -mode title
  • FileDecryptionTool -input raw_ts_data_file -output encrypted_ts_data_file -key 123abcdef -encrypt -mode title
  • FileDecryptionTool -input encrypted_pds_file -output decrypted_pds_file -key 123abcdef -user 123abcdef
  • FileDecryptionTool -input directory_with_encrypted_pds_files -output directory_with_decrypted_pds_files -key 123abcdef -user 123abcdef
