Guide: Add Peer-to-Peer to Your Game — Introduction

Overview of how to use the EOS P2P service in your game.

2 mins to read

Type of service : This interface is an EOS Game Service — authenticate players with the Connect Interface.

Use the Epic Online Services (EOS) Peer-to-Peer (P2P) Interface to manage peer-to-peer networking for your multiplayer game (or other software application). With peer-to-peer networking, your players' game clients can connect to other game clients to send and receive data.

EOS P2P establishes the connections between peers for you, but you can customize what data is sent, how it is sent, and to whom. For example, you might set up your game to send players' gameplay data to each other so each player's game client stays in sync with each other. You might send data such as player movement, player or object animation, or game-state data about when a match has started or ended.

Note that when this guide refers to "player" connections, data sharing, and notifications, it means connections, data sharing, and notifications between each player’s game client.

This guide consists of the following sections:

  1. Notify Players About P2P Connections
  2. Establish P2P Connections
  3. Customize P2P Settings
  4. Send and Receive Data With EOS P2P

Note that you must complete the sections of this guide in the order that they are listed above.

This guide is available in C++ and C#. The C++ version uses the EOS SDK API in C.

Note: The example code snippets in this guide demonstrate how to connect the local player to only one remote player. Your game might require that you connect the local player to more than one remote player at a time. If you use the snippets, make sure you tailor them to the unique circumstances of your game.

For more information on P2P, see the P2P Interface Reference documentation.

Before You Start

Before you start this guide, you must complete these steps:

  • Integrate EOS SDK into your game code. (Guide: Get Started With EOS)
  • Add a client policy and at least one client for your game. (Note that in the Developer Portal, your game is usually known as a "product".) (Documentation: Guide: Manage Your Clients and Client Policies.)
  • Sign in the local player with the Connect Interface. (Documentation: Guide: Access Game Services With the Connect Interface.)
    • The Connect Interface provides the local player's Product User ID. You need this to set up the P2P service.
