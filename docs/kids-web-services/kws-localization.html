Localization in Kids Web Services

How to localize Kids Web Services (KWS) for your product.

1 min to read

Languages Supported by KWS Setup Tools

The Developer Portal (dev.epicgames.com/portal) and KWS documentation (this documentation) are available in multiple languages.

The Developer Portal is available in the following languages:

  • Chinese (Simplified)
  • English
  • French
  • German
  • Japanese
  • Korean
  • Portuguese (Brazil)
  • Spanish

This documentation is available in the following languages:

  • Chinese (Simplified) (Documentation: KWS in Chinese (Simplified))
  • English (Documentation: KWS in English)
  • Japanese (Documentation: KWS in Japanese)
  • Korean (Documentation: KWS in Korean)

You can click on the globe icon at the top right of the page to change languages.

Languages Supported by KWS APIs

You can localize your KWS integration to display all user-facing emails and Web UI screens in several languages.

To do this, you must pass the required language code in your call to the API.
