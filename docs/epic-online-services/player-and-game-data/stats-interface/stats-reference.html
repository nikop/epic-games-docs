Stats Interface Reference

Reference for the Stats Interface.

2 mins to read

Use the EOS Stats service to track player statistics (also known as "stats") in your game or other software application.

You can use these stats to unlock achievements, to rank players in leaderboards, or to create custom functionality for your game.

Stats can be anything you want. Here are some examples:

  • Track how much gamma radiation a player collects in your game and award them a "Radioactive Hero" achievement when they collect 1000 units of gamma radiation.
  • Track the total number of enemies a player defeats, so they can compete with their friends in a leaderboard.
  • Save a player's longest jump distance to show their personal record in the player log.

See the Stats Interface guide and Stats Interface API documentation for details on how to integrate the service into your game (or software application).

Usage Limitations

For general information about throttling, usage quotas, and best practices, see: EOS SDK Conventions and Limitations.

The following limits apply to the overall Stats system:

Feature Limitation
Number of stats 500 per deployment
Stat name length 256 characters
Max stats ingested per call 3000
Max milestones (default) 100

Stats Ingestion is the endpoint for submitting stat changes to the service and has a per-user rate limit. When a dedicated server submits stats on behalf of users, the per-user limits do not apply. In these cases, limits are based on the rate per second for each clientId per deployment.

Usage Type Per-User Limit Per-Deployment Limit
Ingest stats 60 requests per minute, 500 stats per request 1 request per 5 Client IDs per minute
Get stats by Player ID 100 requests per minute -
Get stats by Player IDs 100 requests per minute, 64 players per request, 25 stats per player -
Create Stat - 100 requests per minute
Delete Stat - 100 requests per minute

Test Your Achievements and Stats

To test your achievements in a sandbox, you must include your stats in a deployment to that sandbox. Do this before you deploy to your live environment. This allows you to check for errors in the stats structure and make sure that players can unlock achievements successfully.

For more information on creating a test sandbox for your game, see the documentation on Product, Sandbox, and Deployment IDs.
