Guide: Enable Player Reporting for Your Game — Introduction

Overview of how to use the EOS Player Reports service in your game.

1 min to read

Type of service : This interface is an EOS Game Service — authenticate players with the Connect Interface.

Use the EOS Player Reports service to allow your players to report other players that don’t respect your community rules in your game (or other software application). For example, a player can report another player for cheating, verbal abuse, or other behavior that they find to be offensive. Integrate the Reports Interface into your game to use the features of the Player Reports service.

You can use the Player Reports service by itself in your game, but we recommend that you combine it with other EOS services. For example, combine it with Easy Anti-Cheat so your players can report cheating as soon as it occurs. You can also combine it with the Sanctions service, so you can use the information from player reports to determine whether to take punitive action against a player.

For more information, see the documentation:

  • For more information on Easy Anti-Cheat, see the Anti-Cheat Interfaces documentation.
  • For more information on Sanctions, see the Sanctions Interface documentation.

Note: The Player Reports service is also available as a web API. See the Player Reports Web APIs documentation for more information. This guide does not cover how to use the Player Reports Web APIs.

This guide consists of the following sections:

  • 2. Manage Player Reports in the Developer Portal

Note that you must complete the sections of this guide in the order that they are listed above.
