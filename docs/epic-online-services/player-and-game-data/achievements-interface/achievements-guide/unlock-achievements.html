Guide: Add Achievements to Your Game — 4. Unlock Achievements Manually

Overview of how to add player achievements to your game that you can access through the EOS API.

15 mins to read

Previous section: 3. Retrieve a Player's Achievement Progress

This section of the guide is available in C++ and C#. The C++ version uses the EOS SDK API in C.

Players can unlock achievements automatically based on their stat progress, or you can unlock achievements for a player manually. For more information on how to create achievements that automatically unlock based on a player's stat progress, see the section in this guide: 1. Set Up Achievements. This guide shows how to unlock achievements manually through the EOS SDK API.

The example code snippets in this guide are for guidance only. If you use the snippets, make sure you tailor them to the unique circumstances of your game.

Before You Start

Before you start, you must complete these steps:

  • Integrate the EOS SDK into your code. (Documentation: Guide: Get Started With EOS.)
  • Use the Connect Interface in your code to get the local player’s Product User ID. (Documentation: Guide: Access Game Services With the Connect Interface.)
  • Create achievements that can be manually unlocked. (Section in this guide: 1. Set Up Achievements.)

Manually Unlock Achievements

Complete the following steps to manually unlock achievements for a player in your game:

  • Step 1: Modify Your Achievements Manager Class
  • Step 2: Implement Your Unlock Achievements Function
  • Step 3: Implement Your Unlock Achievements Callback Function

Note: There is a complete code snippet after these steps in the Complete Code section.

Step 1: Modify Your Achievements Manager Class

Modify your achievements manager class .h file to include the declarations for the functions and variables that you need to manually unlock achievements.

Note: The example code below is not the complete code. It includes only the additions that you must make to your achievements manager class .h file. For the complete code, see the complete code snippet after these steps in the Complete Code section.

Example:

AchievementsManager.h 

// AchievementsManager.h... class AchievementsManager{public:...    /**     * Manually unlocks a list achievements.     *     * @param AchievementIds - An array of achievement IDs in the Dev Portal.     *     * @param AchievementCount - The size of the achievement IDs array.     */    void UnlockAchievementsExample(const char** AchievementIds, uint32_t AchievementsCount); private:...    /**      * Callback called by the EOS SDK whenever a request to manually unlock an achievement is processed.     *      * @param Data - Information passed to the callback function by the EOS SDK.     */    static void EOS_CALL OnAchievementUnlockComplete(const EOS_Achievements_OnUnlockAchievementsCompleteCallbackInfo* Data);};

What's happening in the code?

The following sub-steps are a breakdown of the code example above.

  1. In your achievements manager class, declare a public function to query the player's achievements. In the example, it's called RetrievePlayerAchievementsExample:

    void RetrievePlayerAchievementsExample();

  2. Declare a public function to unlock the player's achievements. In the example, it's called UnlockAchievementsExample:

    void UnlockAchievementsExample(const char** AchievementIds, uint32_t AchievementsCount);

  3. Declare a private callback function to execute after the unlock completes. The function definition must match the EOS_Achievements_OnUnlockAchievementsCompleteCallback callback. In the example, it's called OnAchievementUnlockComplete:

    static void EOS_CALL OnAchievementUnlockComplete(const EOS_Achievements_OnUnlockAchievementsCompleteCallbackInfo* Data);

Step 2: Implement Your Unlock Achievements Function

In your .cpp file, in your achievements manager class, implement the function to unlock the achievements manually for a player.

Example:

void AchievementsManager::UnlockAchievementsExample(const char** AchievementIds, uint32_t AchievementsCount){    EOS_Achievements_UnlockAchievementsOptions UnlockAchievementOptions = {};    UnlockAchievementOptions.ApiVersion = EOS_ACHIEVEMENTS_UNLOCKACHIEVEMENTS_API_LATEST;     // The Product User ID of the player whose achievement is being unlocked (the local player in this example).    UnlockAchievementOptions.UserId = LocalProductUserId;     // The IDs of the achievements in the Dev Portal to unlock.    UnlockAchievementOptions.AchievementIds = AchievementIds;     // The number of achievements to unlock.    UnlockAchievementOptions.AchievementsCount = AchievementsCount;     // Call the EOS SDK to manually unlock achievements.    // The callback function will be called when the unlock is processed.    EOS_Achievements_UnlockAchievements(AchievementsHandle, &UnlockAchievementOptions, nullptr, OnAchievementUnlockComplete);}

Note: Your client policy configuration determines which player (EOS_Achievements_UnlockAchievementsOptions.UserId) you can unlock for the player. It can be either the local player (local user ID) or another player (non-local user ID). See this guide's section 1. Set Up Achievements > Step 1: Configure Your Game's Client Policy section for more information.

What's happening in the code?

The following sub-steps are a breakdown of the code example above.

  1. In your achievements manager class, implement the function to unlock the player's achievements.
    The example function includes the following parameters:

    • An array of achievement IDs for the achievements that you want to unlock for the player.
    • An integer for the number of achievements that you want to unlock for the player.
    void AchievementsManager::UnlockAchievementsExample(const char** AchievementIds, uint32_t AchievementsCount){ }

  2. In your unlock function, create an instance of the EOS_Achievements_UnlockAchievementsOptions data structure to hold the unlock options for the achievements. In the example, it's called UnlockAchievementOptions:

    EOS_Achievements_UnlockAchievementsOptions UnlockAchievementOptions = {};UnlockAchievementOptions.ApiVersion = EOS_ACHIEVEMENTS_UNLOCKACHIEVEMENTS_API_LATEST;UnlockAchievementOptions.UserId = LocalProductUserId;UnlockAchievementOptions.AchievementIds = AchievementIds;UnlockAchievementOptions.AchievementsCount = AchievementsCount;

    Note: Your client policy configuration determines which player (EOS_Achievements_UnlockAchievementsOptions.UserId) you can unlock for the player. It can be either the local player (local user ID) or another player (non-local user ID). See this guide's section 1. Set Up Achievements > Step 1: Configure Your Game's Client Policy section for more information.

  3. Call the EOS API EOS_Achievements_UnlockAchievements() function to unlock the passed in achievements manually for the player.

    The function takes the following arguments:

    • Achievements Interface handle.
    • A reference to the unlock options for the achievements.
    • (Optional) ClientData - an argument must be present but it can be a nullptr.
      In the example, we pass a nullptr because we don't need to pass any additional data to the callback.
    • A callback function to receive the EOS_Achievements_OnUnlockAchievementsCompleteCallbackInfo data structure when the EOS Achievements service completes the unlock achievements function call.
    EOS_Achievements_UnlockAchievements(AchievementsHandle, &UnlockAchievementOptions, nullptr, OnAchievementUnlockComplete);

Step 3: Implement Your Unlock Achievements Callback Function

In your .cpp file, implement your query achievements callback function.

Example:

void EOS_CALL AchievementsManager::OnAchievementUnlockComplete(const EOS_Achievements_OnUnlockAchievementsCompleteCallbackInfo* Data){    if (Data->ResultCode == EOS_EResult::EOS_Success)    {        std::cout << "Manual achievement unlock succeeded" << std::endl;    }    else if (EOS_EResult_IsOperationComplete(Data->ResultCode) == EOS_FALSE)    {        // If the code gets here, the operation is retrying and is not yet complete.        return;    }    else    {        // If the code gets here, there was an error.        // Handle this however you need for your game.        std::cerr << "Error unlocking achievement! Error code: " << static_cast<int>(Data->ResultCode) << EOS_EResult_ToString(Data->ResultCode) << std::endl;    }}

What's happening in the code?

The following sub-steps are a breakdown of the code example above.

  1. In your .cpp file, implement the callback function that executes when the EOS_Achievements_UnlockAchievements() function completes. The function definition must match the EOS_Achievements_OnUnlockAchievementsCompleteCallback callback which receives a EOS_Achievements_OnUnlockAchievementsCompleteCallbackInfo data structure. In the example, it's called OnAchievementUnlockComplete:

    void EOS_CALL AchievementsManager::OnAchievementUnlockComplete(const EOS_Achievements_OnUnlockAchievementsCompleteCallbackInfo* Data){ }

    Notes:

    • The EOS SDK calls this callback function asynchronously each time the EOS_Achievements_UnlockAchievements() function completes.
    • The EOS_CALL macro is part of the required definition.

  2. In your callback function, use the returned EOS_EResult Enum to confirm that the unlock is successful:

    if (Data->ResultCode == EOS_EResult::EOS_Success){    std::cout << "Manual achievement unlock succeeded" << std::endl;}

  3. Use the EOS_EResult_IsOperationComplete function to check if the unlock is not complete yet. If the unlock is not complete, return so the operation can complete:

    else if (EOS_EResult_IsOperationComplete(Data->ResultCode) == EOS_FALSE){    return;}

  4. If the unlock is not successful, handle the errors:

    else{    std::cerr << "Error unlocking achievement! Error code: " << static_cast<int>(Data->ResultCode) << EOS_EResult_ToString(Data->ResultCode) << std::endl;}

    Tip: Use the EOS_EResult_ToString() function to convert the E_EResult Enum to a string, which gives the name of the error type.

Results

After you call the EOS_Achievements_UnlockAchievements() function, on success the EOS Achievements service unlocks the player's achievements for the array of achievement IDs that you passed in the EOS_Achievements_UnlockAchievements() function call.

Note: Each achievement ID must match the achievement ID, exactly as you wrote it in the Developer Portal.

Notes

You can call the EOS_Achievements_UnlockAchievements() function more than once, even on every launch, as long as you respect proper retry rates and wait for the completion status to return before you try again (as demonstrated in this guide).

Subscribe to achievement unlocked notifications to be notified through your registered callback function when the player unlocks achievements (section in this guide: 5. Send Notifications When a Player Unlocks an Achievement).

The EOS SDK does not store achievement state locally or offline. If the player loses network connection to the EOS Stats service, the player can experience issues when they try to unlock an achievement. To mitigate issues, we recommend that you do the following:

  • Always download the player's achievement status, including stat data, when they sign in.
  • Compare the EOS Achievements service unlock state of an achievement to your game's stats data. Unlock the achievement if the stats meet the conditions to unlock the achievement.

Follow this same recommendation for new achievements that you introduce in an update that a player might have already completed.
