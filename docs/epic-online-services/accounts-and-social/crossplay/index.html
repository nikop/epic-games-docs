Crossplay

Enable players accessing your game from different storefronts to play together using a combined friends list.

Under 1 min to read

Note: The EOS Social Overlay provides a native UI and UX for crossplay features (for example, invites). The EOS Social Overlay is currently not available on the following platforms: macOS, Linux, Linux ARM64, Android, and iOS. The EOS SDK includes multiplayer features, like Sessions, that you can combine with your own UI to extend crossplay features to these platforms. (Documentation: Crossplay Introduction > Platform Agnostic Multiplayer Services)
