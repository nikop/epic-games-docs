Ecommerce Store Sample

Example program demonstrating how to build a store with the EOS SDK.

Epic Games Store
1 min to read

Overview

The Ecommerce Store Sample demonstrates the operations related to an in-game store in the Epic Online Services (EOS) SDK, including querying offers and the checkout process.

Sign In

From the right-side panel, click one of these options to sign in:

  • Dev Auth: Enter the host port and credentials that you configured for the Developer Authentication Tool (for example, 127.0.0.1:8080 if you set 8080 for the host port) and click LOG IN. See the Developer Authentication Tool documentation for more information on the Developer Authentication Tool.
  • Account Portal: Click LOG IN to sign in through the Account Portal with your Epic Games account credentials or a supported identity provider. See the Identity Provider Management documentation for more information on identity providers.

Offers List

After the sample starts, the offers are retrieved, and the information is visible in a column of offer titles on the right.

Starting Checkout

Click on the Checkout button next to an offer to start the checkout process. This opens the overlay depicted below.

This sample uses production servers. If users complete the checkout process, the sample will charge real-world money.

Search Offers

The sample features a Search Offers text box that you can use to filter offers. Type your search string into the box and hit the Enter key on your keyboard to filter the offers down to just those that contain the full string. The red button that appears next to the text box resets the filter.

Console Commands

In addition to the standard console commands, this sample supports one custom command - OFFERS - used to refresh the store catalog.
