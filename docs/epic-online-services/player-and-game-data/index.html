Player and Game Data

Keep progress persistent and increase long-term engagement. Securely manage and sync data across platforms.

2 mins to read

EOS Game Services are part of Epic Online Services (EOS).

Introduction

Introduction to the Player and Game Data group of EOS services.

Features

Player Search

Reference information and guidance on viewing and managing the data that EOS stores about your players on your behalf.
Ticketing System (Player Ticketing)

Reference information and guidance on managing support for your players with a pre-assigned email address and public web API key.

Interfaces

Achievements Interface

How-to guide and reference information on accessing data about player achievements, unlocking them for a player, getting data on a player's progression for an achievement, and sending notifications to players when they unlock an achievement.
Custom Invites Interface

Reference information and guidance on managing your game's player-invitation system through the EOS Overlay's Social Overlay UI.
Leaderboards Interface

How-to guide and reference information on defining leaderboards for your game, choosing the stats to include, how you rank players, and the lifespan of the leaderboards.
Metrics Interface

Reference information and guidance on setting up the game analytics dashboard in the Developer Portal and tracking worldwide game activity, player retention, and online player counts. You can view your game's usage data, including players' active sessions and past sessions.
Player Data Storage Interface

Reference information and guidance on saving, downloading, copying, and deleting player-related data for your game on cloud servers in encrypted form.
Stats Interface

How-to guide and reference information on defining the stats for your game in the Developer Portal. You can include any statistical data about a player that you want to track, for example the number of items the player has collected. You can use these stats to determine when to unlock achievements and how to rank players in leaderboards.
Title Storage Interface

Reference information and guidance on retrieving game-specific data that is stored in encrypted form on cloud servers.
