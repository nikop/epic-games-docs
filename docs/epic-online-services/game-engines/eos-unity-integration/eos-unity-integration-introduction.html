Unity and EOS SDK — Introduction

Introduction to Unity and EOS SDK integration guides.

2 mins to read

Epic Online Services (EOS) are free, games-platform-agnostic services to launch, operate, and scale your game. You can use them no matter what games platform your game clients run on, and no matter what game engine you use for development, or if you use no game engine at all. For more information on the available EOS services, see the EOS Overview documentation.

You must integrate the EOS SDK into your Unity project to use EOS.

You can do this in one of two ways:

  • Use the EOS Plugin for Unity (recommended).
    • For information, see the EOS Plugin for Unity's documentation in its GitHub repository at github.com/EOS-Contrib/eos_plugin_for_unity.
  • Manually integrate the EOS SDK without the EOS Plugin for Unity. (Only do this if you can’t use the EOS Plugin for Unity.)

This section of documentation shows you how to manually integrate the EOS SDK into your Unity project without the EOS Plugin for Unity.

EOS SDK Limitations in the Unity Editor

Be aware of the following limitations when you use the EOS SDK in the Unity Editor:

  • The EOS Overlay does not work in the Unity Editor.
    • Note: To test the EOS Overlay, you must create a standalone build in Unity. For more information on how to create a standalone build, see Unity’s documentation at docs.unity3d.com.
    • This is due to how rendering is set up in Unity.
  • Dynamic libraries (DLL) remain in memory and do not automatically update when you make changes. (Windows only)
    • Note: The Unity Editor only loads DLLs on startup so you must reboot the Unity Editor for changes you make to DLLs to take effect.
      • For example, If you make any changes to the values used to create and initialize the EOS Platform interface, the changes do not take effect until after you reboot the Unity Editor.
  • Callbacks might remain in memory.
    • Note: You must properly dispose of callbacks and other objects that you obtain from the EOS SDK.
    • The garbage collector cleans up the allocations and deallocations correctly.
