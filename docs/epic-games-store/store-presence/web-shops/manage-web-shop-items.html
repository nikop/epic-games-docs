Manage Web Shop Items

Create and manage your product's web shop items.

7 mins to read

Web shop items represent saleable content associated with your web shop. When you create a web shop item, the Developer Portal automatically creates a web shop item entry in the Dev sandbox.

You create and manage web shop items on the Web Shop page of the Developer Portal.

Create Web Shop Item

You can create different web shop items that let your users purchase or download different content associated with your web shop. When you create a web shop item, the item is added to the web shop item display list automatically.

To create a web shop item:

  1. In the Developer Portal, go to the Web Shop page. To do this:

    • a. Sign in to the Developer Portal (dev.epicgames.com/portal).

    • b. Select the correct organization for your product.

      (To check, see Organization at the top of the left navigation. To change organization, click Organization and follow the on-screen instructions.)

    • c. In the left navigation, under Your products, click the name of your product.

    • d. In the left navigation, click Epic Games Store > Web Shop.

  2. Click Create web shop item.
  3. Follow the on-screen instructions to enter the details of the web shop item. Use the following guidance to help you enter the details:
    • Item name: This name will appear as the name of the web shop item on the Epic Games Store.
    • URL preview: You can use this URL to access the web shop item while it is on the Dev or Stage sandbox, so that you can preview how the item will appear to users. This URL is locked when the web shop item is released.

Add Web Shop Item Details

This section describes the details that you can set on a web shop item when you create or edit the web shop item. After you create your web shop item, you can then add relevant details to the item. Some of these details are mandatory, and some are optional. The Developer Portal displays the web shop item details in sections called Required Information and Optional Information.

To view or add details to your web shop item:

  1. In the Developer Portal, go to the Web Shop page. To do this:

    • a. Sign in to the Developer Portal (dev.epicgames.com/portal).

    • b. Select the correct organization for your product.

      (To check, see Organization at the top of the left navigation. To change organization, click Organization and follow the on-screen instructions.)

    • c. In the left navigation, under Your products, click the name of your product.

    • d. In the left navigation, click Epic Games Store > Web Shop.

  2. Select the correct sandbox for your web shop item.
  3. Click the name of your web shop item.
  4. In the Web Shop Item Details panel, use the various buttons to go to the different categories for your web shop item, where you can view and change the settings in that category. For information about a specific category, see the appropriate documentation:
    • General details
    • Dates
    • Price
    • Images
    • Regions
    • Social preview
  5. When you have finished configuring the web shop item, click Save Changes.

Update Web Shop Item Dates

You can update web shop item dates at any time. However, the process is different depending on which sandbox the web shop item is currently in.

Note: You cannot directly update web shop item in the Stage sandbox. To update a web shop item in Stage, make the changes to the web shop item in your Dev sandbox. Then push the changes to Stage when appropriate. Find out more about the publishing process in the Publishing Tools Workflow documentation.

Web Shop Items in the Dev Sandbox

To update web shop item dates in your Dev sandbox:

  1. In the Developer Portal, go to the Web Shop page. To do this:

    • a. Sign in to the Developer Portal (dev.epicgames.com/portal).

    • b. Select the correct organization for your product.

      (To check, see Organization at the top of the left navigation. To change organization, click Organization and follow the on-screen instructions.)

    • c. In the left navigation, under Your products, click the name of your product.

    • d. In the left navigation, click Epic Games Store > Web Shop.

  2. Select the Dev sandbox.
  3. Click the name of the web shop item you want to update.
  4. Click Dates.
  5. To edit a date, click its calendar icon.
  6. Click Save Changes.

Web Shop Items in the Stage or Live Sandbox

To update the web shop item in your Stage or Live sandbox, follow the procedure in Web Shop Item in the Dev Sandbox on this page, then push the changes to Stage. To push to the Live sandbox, you must submit your web shop for review by the Epic Games Store team.

  • For more information about pushing to Stage and Live, see Get Started Steps > Submit for Final Review).

Manage the Item Display List

On the web shop item display list, you can add, re-order, or remove a web shop item from the display list. Web shop items you create are automatically added to the web shop item display list. The item display list follows the publishing tools workflow. (Documentation: Publishing Tools Workflow.)

Add Web Shop Items to the Item Display List

To add an item to the item display list:

  1. In the Developer Portal, go to the Web Shop page. To do this:

    • a. Sign in to the Developer Portal (dev.epicgames.com/portal).

    • b. Select the correct organization for your product.

      (To check, see Organization at the top of the left navigation. To change organization, click Organization and follow the on-screen instructions.)

    • c. In the left navigation, under Your products, click the name of your product.

    • d. In the left navigation, click Epic Games Store > Web Shop.

  2. Select the Dev sandbox.
  3. Find the item you want to add to the display list and click +.

Re-order Web Shop Items in the Display List

To re-order the item display list:

  1. In the Developer Portal, go to the Web Shop page. To do this:

    • a. Sign in to the Developer Portal (dev.epicgames.com/portal).

    • b. Select the correct organization for your product.

      (To check, see Organization at the top of the left navigation. To change organization, click Organization and follow the on-screen instructions.)

    • c. In the left navigation, under Your products, click the name of your product.

    • d. In the left navigation, click Epic Games Store > Web Shop.

  2. Find the web shop item display list section and click Edit.
  3. In the Web shop item display list panel, drag and drop the web shop items to change the order of the display list.

Remove Web Shop Items from the Display List

Doing this removes the web shop item from being displayed. It will not delete the web shop item from the web shop. To delete the web shop item from the web shop, see Delete Web Shop Item on this page.

To remove an item from the item display list:

  1. In the Developer Portal, go to the Web Shop page. To do this:

    • a. Sign in to the Developer Portal (dev.epicgames.com/portal).

    • b. Select the correct organization for your product.

      (To check, see Organization at the top of the left navigation. To change organization, click Organization and follow the on-screen instructions.)

    • c. In the left navigation, under Your products, click the name of your product.

    • d. In the left navigation, click Epic Games Store > Web Shop.

  2. Find the web shop item display list section and click Edit.
  3. Find the web shop item you want to delete from the display list and click x.

Delete Web Shop Item

When you delete a web shop item, you permanently remove the web shop item, and any corresponding details from your web shop. You cannot undo this action. You can only delete web shop items that are in your Dev sandbox. You cannot delete web shop items that are in your Stage or Live sandboxes.

Note: If you want to delete a web shop item in the Stage or Live sandbox, you must add an expiration date to a web shop item. Expired web shop items are no longer discoverable or purchasable on the Epic Games Store. However, they remain accessible to users who previously purchased them. For instructions on how to add an expiry date, see the Update Web Shop Item Dates section on this page.

To delete a web shop item:

  1. In the Developer Portal, go to the Web Shop page. To do this:

    • a. Sign in to the Developer Portal (dev.epicgames.com/portal).

    • b. Select the correct organization for your product.

      (To check, see Organization at the top of the left navigation. To change organization, click Organization and follow the on-screen instructions.)

    • c. In the left navigation, under Your products, click the name of your product.

    • d. In the left navigation, click Epic Games Store > Web Shop.

  2. Select the Dev sandbox.
  3. Find the web shop item you want to delete and click Delete.
