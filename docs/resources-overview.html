Overview

Introduction to the Epic Games Developer Portal, the Epic Games Store, Epic Online Services (EOS), Kids Web Services (KWS), and their associated tools.

5 mins to read

Epic's developer resources include a set of free services and tools which software developers can use to add network-based functionality to video games, and storefront distribution for video games.

The resources are as follows:

  • Epic Games Store — storefront distribution and games-store services
  • Kids Web Services (KWS)
  • Epic Online Services (EOS) — accounts and social, multiplayer, player and game data, trust and safety

The sets of resources have associated tools to configure and manage them with your game or other software application: the Epic Games Developer Portal (known as the "Developer Portal"), the KWS Developer Portal, SDKs and APIs.

Modular
The resources are modular, so you can use them individually, or combine as many as you need.

Platform-Agnostic
Epic Online Services (EOS) and Kids Web Services (KWS) are games-platform-agnostic and games-engine-agnostic. You can add them to your game whatever games platform your game clients run on, and whatever game engine you use for development, or if you use no game engine at all.

They are also storefront-agnostic, so you can use them on whatever storefront you make your game available on.

(Note that Epic Games Store's storefront distribution and Epic Games Store services are for products that run on PC: Windows or macOS.)

Epic Games Store

Storefront Distribution

The Epic Games Store is a storefront for players to buy and download products (games and other software applications) that run on PC: Windows or macOS. You can configure your storefront presence and distribute your games on the Epic Games Store using the Epic Games Store publishing tools.

Epic Games Store Services

You can use Epic Games Store Services to integrate online services functionality into your product, including e-commerce, cloud saves, Epic Games Launcher invites, mods, and Epic Games Store achievements.

Note:
While EOS is games-platform-agnostic, Epic Games Store is a storefront for players to buy and download products that run on PC only: Windows and macOS. The Epic Games Store services also run on PC only: Windows and macOS.

Epic Online Services (EOS)

Epic Online Services (EOS) are free, games-platform-agnostic, services to launch, operate, and scale your game, whatever games platform your game clients run on, and whatever game engine you use for development, or if you use no game engine at all. There are multiple services, each with their own interface and set of APIs. The following are groups of services:

  • Accounts and Social
    Bring your players together with the Epic Games account ecosystem, tapping into a cross-platform network of nearly a billion players.
    • Accounts and Social are EOS Epic Account Services — players can connect to these services in your game with an Epic Games account or proxy account. For details, see Epic Online Services (EOS) Overview > Type of Service.
    • Documentation: Epic Online Services (EOS) Overview > Accounts and Social
  • Multiplayer
    Make every match possible, however your players choose to connect. Enable multiplayer experiences across diverse platforms and services.
    • Multiplayer services are EOS Game Services — players can connect to your game with an account from any supported identity provider. For details, see Epic Online Services (EOS) Overview > Type of Service.
    • Documentation: Epic Online Services (EOS) Overview > Multiplayer.
  • Player and Game Data
    Keep progress persistent and increase long-term engagement. Securely manage and sync data across platforms.
    • Player and Game Data are EOS Game Services — players can connect to your game with an account from any supported identity provider. For details, see Epic Online Services (EOS) Overview > Type of Service.
    • Documentation: Epic Online Services (EOS) Overview > Player and Game Data.
  • Trust and Safety
    Protect players, build trust, safeguard your game’s integrity, and navigate the complexities of parental consent and verification.
    • Trust and Safety are EOS Game Services — players can connect to your game with an account from any supported identity provider. For details, see Epic Online Services (EOS) Overview > Type of Service.
    • Documentation: Epic Online Services (EOS) Overview > Trust and Safety.

EOS SDK and API
Use the EOS SDK API in C and C# to integrate EOS Game Services and EOS Epic Account Services into your product on multiple platforms, including PC, macOS, Linux, PlayStation 4 and PlayStation 5, Xbox One and Xbox Series X, Switch and Switch 2.

Documentation:

  • EOS Introduction
  • Guide: Get Started With EOS > 1. Set Up Your Account and Download the EOS SDK
  • EOS API Reference

EOS Web API
Use the Web API to integrate some EOS Game Services and EOS Epic Account Services into your product. The Web API covers anti-cheat, authentication, connect, player reports, sanctions, ownership verification (Ecom) and voice services.

Documentation:

  • EOS Web API Introduction

Note: EOS requires you to use the EOS SDK APIs or the EOS Web API.

Developer Portal

The Epic Games Developer Portal (“the Developer Portal”) is a browser-based UI to configure services for your organization and product (game or other software application), as well as Epic Games Store distribution for your product.

You can configure your product's setup for:

Developer Resources

  • The Epic Games Store:
    • Storefront distribution.
    • Epic Games Store services.
  • Kids Web Services (KWS) (listed in the Developer Portal under "Epic tools")
  • Epic Online Services (EOS)

Epic Tools

  • Unreal Engine users:
    • Declare product releases and royalties.
    • Manage seats (accounts that are assigned a license).
  • Fortnite Creative users:
    • Manage your tax profile.
    • Manage your payout account, such as Hyperwallet, so you can receive payments from Epic Games.
  • Twinmotion and RealityScan users:
    • Manage seats.

You can also view analytics for all your products, and access the EOS SDK and its release notes.

  • Visit the Developer Portal at dev.epicgames.com/portal.
