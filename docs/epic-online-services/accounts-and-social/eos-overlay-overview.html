EOS Overlay Overview

Get started with the Epic Online Services (EOS) Overlay in your game.

5 mins to read

Note: The EOS Overlay supports Windows, Xbox, PlayStation 4, PlayStation 5, and Nintendo Switch console platforms. MacOS, Linux, and Steam Deck are not currently supported. iOS and Android currently support only commerce in the EOS Overlay.

Use the EOS Overlay (also known as "the overlay") to add the following Accounts and Social features or Epic Games Store service to your game. All of the features are available through this single in-game overlay.

  • Social Overlay: Players can manage social features while they play your game, including a friends list. For more information, see the Social Overlay Overview documentation.
  • Account Portal: Players can sign in to their Epic Games account or authenticate with an external account. For more information, see the Crossplay: Crossplay Technical Overview documentation.
  • Commerce: Players can make in-game purchases (on desktop). For more information, see the Epic Games Store > Ecom Interface Overview documentation.

Installation

The installation requirements for the EOS Overlay depend on how you distribute your game:

  • Epic Games Store: The Epic Games launcher automatically installs the EOS Overlay. No further action is required.
  • Outside of the Epic Games Store (Windows and console): The EOS Overlay is not included in your game by default. In this case, to make the EOS Overlay available in your game, you must include the EOS redistributable installer as part of your game's prerequisites. For more information, see the Redistributable Installer documentation. General Integration Requirements

General Integration Requirements

It is important to initialize the EOS SDK and call EOS_Platform_Create before initializing Direct3D. This gives the EOS Overlay a chance to install graphics API hooks necessary to render the overlay with each game frame presented to the user.

On Windows, the EOS Overlay has experimental support for Direct3D9, Direct3D10, and OpenGL. To opt-in to the experimental functionality, initialize the Flags field in EOS_Platform_Options with the appropriate values before calling EOS_Platform_Create .

  • Direct3D9 - EOS_PF_WINDOWS_ENABLE_OVERLAY_D3D9
  • Direct3D10 - EOS_PF_WINDOWS_ENABLE_OVERLAY_D3D10
  • OpenGL - EOS_PF_WINDOWS_ENABLE_OVERLAY_OPENGL

Console Platform Integration Requirements

To integrate the EOS Overlay into your game on console platforms, you must do the following:

  • Support the UI rendering for the EOS Overlay.
  • Pass user input to the EOS Overlay.

Some platforms also require further modifications to ensure the EOS Overlay is rendered properly. See the EOS SDK documentation for more information on how to integrate the EOS Overlay on your platform:

  • To integrate the EOS Overlay on Xbox, see the EOS SDK for Xbox documentation.
  • To integrate the EOS Overlay on PlayStation 4, see the EOS SDK for PlayStation 4 documentation.
  • To integrate the EOS Overlay on PlayStation 5, see the EOS SDK for PlayStation 5 documentation.
  • To integrate the EOS Overlay on Nintendo Switch, see the EOS SDK for Nintendo Switch documentation.
  • To integrate the EOS Overlay on Nintendo Switch 2, see the EOS SDK for Nintendo Switch 2 documentation.

Anti-Cheat Integration Recommendations

If you integrate your own anti-cheat system into your game, and want to get the best runtime performance (in terms of memory, processing speed and responsiveness on your platform(s)), we recommend you whitelist the following EOS Overlay executables in your anti-cheat system:

  • EOSOverlayRenderer-Win32-Shipping.exe
  • EOSOverlayRenderer-Win64-Shipping.exe

This is because some anti-cheat systems block the Windows API calls that the EOS Overlay uses.

EOS Platform Flags for the EOS Overlay

The EOS_Platform_Options that you pass to EOS_Platform_Create take a Flags property (Documentation: Guide: Get Started With EOS > 3. Set Up the EOS SDK). This property is a bit-field with room for 64 flags.

The EOS SDK provides the following flags that you can use to configure the EOS Overlay:

Flag Description
EOS_PF_LOADING_IN_EDITOR Set this flag to disable the EOS Overlay when you use the EOS SDK in an editor, such as the UE4 Play-in-Editor (PIE) or the Unity Editor.
EOS_PF_DISABLE_OVERLAY Set this flag to disable the EOS Overlay in all situations. Note that when this flag is set, purchase-related functionality in the Ecom Interface fails. This flag is implied when you set the flag EOS_PF_LOADING_IN_EDITOR.
EOS_PF_DISABLE_SOCIAL_OVERLAY Set this flag to disable only the Social Overlay feature (Documentation: Social Overlay Overview). This flag is implied when you set the flag EOS_PF_LOADING_IN_EDITOR or EOS_PF_DISABLE_OVERLAY.
EOS_PF_RESERVED1 A reserved flag.
EOS_PF_WINDOWS_ENABLE_OVERLAY_D3D9 Set this flag to opt your game into experimental Direct3D 9 support for the EOS Overlay. This flag works only on Windows.
EOS_PF_WINDOWS_ENABLE_OVERLAY_D3D10 Set this flag to opt your game into experimental Direct3D 10 support for the EOS Overlay. This flag works only on Windows.
EOS_PF_WINDOWS_ENABLE_OVERLAY_OPENGL Set this flag to opt your game into experimental OpenGL support for the EOS Overlay. This flag works only on Windows.
EOS_PF_CONSOLE_ENABLE_OVERLAY_AUTOMATIC_UNLOADING Set this flag to opt your game into automatic unloading of the EOS Overlay module when possible. This flag works only on console platforms.
EOS_PF_ENABLE_OVERLAY_DEBUG_LOGGING Set this flag to add verbose debug logging and help identify issues when integrating the EOS Overlay in your game. You can set this flag in release builds.

Note:
  • This flag works only on console platforms.
  • Use this flag for debugging only, do not use it in a live game.

Localization

The EOS Overlay uses a locale code for localization of text in the Social Overlay, Account Portal, and commerce UI. The locale code comes from one of two sources:

  • The language that the player selected when they created their Epic Games account.
  • An override value that your game provides. You can set an override value for the locale with EOS_Platform_SetOverrideLocaleCode.

If your game uses an override value, the EOS Overlay uses the override, regardless of what the player selected in their Epic Games account.
