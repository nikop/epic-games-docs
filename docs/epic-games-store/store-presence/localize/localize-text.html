Localize Your Storefront Text

Localize the text in your storefront content to best reach global Epic Games Store users.

11 mins to read

You can localize the text of your store presence in two ways:

  • Use the Developer Portal's Localization page to add localized text for your store presence. For information, see the Create Your Own Text Localizations section on this page.
  • Use the free-of-charge translation service provided by Epic Games. For information, see the Request Text Translations from the Epic Translation Service section on this page.

For a list of the languages supported by the Epic Games Store, see documentation: Supported Languages.

For an overview of store presence localization, see documentation: Localize Your Store Presence.

Create Your Own Text Localizations

You can enter your own localized text for your store settings, offers, web shop items, and pages. To do so, use the following process:

  1. Step 1: Set Up the English-Language Text in your Product
  2. Step 2: Download the Localization Template from the Developer Portal
  3. Step 3: Enter Your Localized Text into the Localization Template
  4. Step 4: Import the Localization Template into the Developer Portal
  5. Step 5: Preview your Localizations
  6. Step 6: Publish your Localizations

Step 1: Set Up the English-Language Text in your Product

Before you begin, do the following:

  1. In the Dev sandbox, complete all of the mandatory fields in English for the pages, offers, web shop items, and store settings you want to localize.
    • Mandatory fields are marked in the Developer Portal with an asterisk (*).
    • You need English text in the localization template so that your translators know what text to localize.
    • Important notes about English text lengths:
      • Every text field on the Epic Games Store has a specific character limit. This limit on a field is the same for all languages. For example, the limit for an offer name is 64 characters in all languages.
      • You can see the character limit on a field when you edit the field in the Developer Portal.
      • A piece of localized text might be longer than the equivalent English text.
      • Therefore, we recommend that you use a maximum of 70-80% of the character limit in your English text for each field. This leaves space in that field for additional characters in other languages.
  2. Make sure that these pages, offers, web shop items, and store settings have the status Ready for Stage.
    • To learn more about statuses, see documentation: Release Management.

Step 2: Download the Localization Template from the Developer Portal

The localization template is a .CSV file that contains all user-facing content strings for your selected pages, offers, web shop items, and store settings. You must add your translations to this template.

Note:

  • If you cannot provide your own translations, you can request localization support from the Epic Games Store team. See Request Text Translations from the Epic Translation Service section of this page for more information.
  • If you want to localize some content for all locales and other content for specific locales only, we recommend that you download and complete a separate template for each set of localizations that you want to do. For more information, see the Combine Complete and Partial Text Localizations section on this page.

To download the localization template:

  1. In the Developer Portal, go to the Localization page. To do this:
    • a. Sign in to the Developer Portal (dev.epicgames.com/portal.
    • b. Select the correct organization for your product.
    • c. In the left navigation, under Your products, click the name of your product.
    • d. In the left navigation, click Epic Games Store > Localization.
  2. Select the Dev sandbox.
  3. At the top right, click Download Template.
  4. Select the pages, offers, web shop items, and sets of store settings that you want to localize.
    • Note: You cannot select pages, offers, and sets of store settings that have the draft status. For information on the draft status, see Release Management > Sandboxes.
  5. Click Download.

Step 3: Enter Your Localized Text into the Localization Template

Next, fill out the localization template with your translated content.

Note: If you have already created one or more text localizations, then the file will contain these localizations in the appropriate locale columns.

In the .CSV file, each row represents a specific string. The en column contains your English string. For each supported language, there is a locale column. You enter your translated strings into the appropriate locale columns.

The locale columns are labeled by locale code (such as ja or ko). For a full list of codes, see documentation: Supported Languages.

Note: Doing Localizations in Multiple Stages

You do not need to localize all your locales at the same time. If you want to, you can import your localized strings into the Developer Portal in groups of one or more locales at a time. For example, you might localize for French and German in one template, and import these. Then you might localize for Japanese and Korean in a separate template, and import these.

The maximum file size for the localization file is 5MB. If your file is larger than this, you must reduce the file size. To do so, split your localization into multiple stages, so that you import two or more smaller files instead of one large file.

When you import your localization template, follow these guidelines:

  • Do not edit or remove the first row (the header row).
  • Do not adjust the file format.
  • Do not change the template structure
  • Remove any unused locale columns before you upload the template.

To complete the localization template:

  1. Open the .CSV file in a suitable software application. We recommend Microsoft Excel.
  2. In the .CSV file, look at the following columns to to identify the strings that you want to localize:
    • Localization Field
    • Field Description
    • en
  3. For each string, add your translated content to the appropriate locale columns.
  4. Remove any locale columns that you do not use.
    • Your completed file must only include locale columns that contain translated content.
    • If you do not remove all unused columns, the import process might result in an error.
  5. Save your completed template as a .CSV UTF8 format file.
    • Important: You must save the file as a UTF-8 encoded file. The Developer Portal can only read multi-language data from a UTF-8 encoded file.
      • To do this in Microsoft Excel 2016 and higher: In the Save As dialog, select CSV UTF-8 (Comma delimited) (*.csv) as the file type.
      • For information on how to do this in other software applications, see your software application's documentation.

Step 4: Import the Localization Template into the Developer Portal

To import your localizations:

  1. In the Developer Portal, go to the Localization page. To do this:

    • a. Sign in to the Developer Portal (dev.epicgames.com/portal.

    • b. Select the correct organization for your product.

      (To check, see Organization at the top of the left navigation. To change organization, click Organization and follow the on-screen instructions.)

    • c. In the left navigation, under Your products, click the name of your product.

    • d. In the left navigation, click Epic Games Store > Localization.

  2. Select the Dev sandbox.
  3. At the top right, click Upload File.
  4. Do one of the following:
    • Drag and drop your .CSV file from a directory on your computer into Drop files here.
    • Click browse and then select your .CSV file.
    • Note: the maximum file size is 5MB. If your file is larger than this, you must reduce the file size. To do so, include fewer locale columns in the file.
  5. When the import process finishes, you see one of the following results:
    • The import was successful: The file displays with a confirmation message, and you can continue to Step 5: Preview your Localizations.
    • The import failed: If any issues are detected in the file, an alert message displays on the screen. You must resolve these errors before you can continue. For more information, see the Resolve Import Errors section on this page.

Resolve Import Errors

Errors can happen for a variety of reasons. Common errors include the following:

  • Translated content for a specific field exceeds its character limit.
  • Translated content is missing for one or more required fields.

Languages affected by one or more errors display with a warning icon in the Text Languages section of the Manage Localization page. (To open the Manage Localization page for a localization, on the Localization page, click the localization you want to view.)

To resolve errors:

  1. Click an affected language to review its specific error details.
  2. In your .CSV file, resolve the corresponding issues.
  3. Upload the modified file, as described in the Step 4: Import the Localization Template into the Developer Portal section on this page.
  4. Repeat this process to resolve any additional errors.
  5. When you import your localizations without error, continue to Step 5: Preview your Localizations.

Step 5: Preview your Localizations

You can preview how your localizations will appear to Epic Games Store users.

Note: You can only preview text localizations of pages, offers, and web shop items. You cannot preview store settings text.

To preview your localizations:

  1. In the Developer Portal, go to the Localization page. To do this:

    • a. Sign in to the Developer Portal (dev.epicgames.com/portal.

    • b. Select the correct organization for your product.

      (To check, see Organization at the top of the left navigation. To change organization, click Organization and follow the on-screen instructions.)

    • c. In the left navigation, under Your products, click the name of your product.

    • d. In the left navigation, click Epic Games Store > Localization.

  2. Select the Dev sandbox.
  3. In the list of localized items, click the page, offer, or web shop item that you want to preview.
  4. In the list on the right, click a language that you want to preview.
  5. Click Text.
  6. On the left, the Developer Portal displays the fields containing your localized content. to launch a storefront preview in a new tab, click Preview in Store at the top right of the fields.
  7. Check the preview.
    • If you are happy with the localized content, continue to Step 6: Publish Your Localizations.
    • If you want to make any changes to the content, return to Step 3: Enter Your Localized Text into the Localization Template and Step 4: Import the Localization Template into the Developer Portal as needed.

Step 6: Publish your Localizations

To publish your localizations, you must first push your localized pages, offers, web shop items, and store settings to the Stage sandbox and submit them for review. After the Epic Games Store team approves them, you can publish your changes to the Live sandbox.

To publish your localizations:

  1. In the Developer Portal, go to the Release Management page. To do this:
    • a. Sign in to the Developer Portal (dev.epicgames.com/portal.
    • b. Select the correct organization for your product.
    • c. In the left navigation, under Your products, click the name of your product.
    • d. In the left navigation, click Epic Games Store > Release Management.
  2. In the Dev sandbox, click Push to Stage.
  3. Select the pages, offers, web shop items, and store settings that contain your new localizations.
  4. At the top right, Push to Stage.
    • The pages, offers, web shop items, and sets of store settings appear in the Stage sandbox section of the screen.
  5. In the Stage sandbox, click Submit for Review.
    • This sends your content to the Epic Games Store team for review. Documentation: Submit for Final Review.
    • TIP: You don't need to keep your browser tab open while you wait for the review. You can return to the Release Management page later to check on the review progress.
    • Note: The outcome of the review might mean that you need to make content changes in English. In this scenario, you must also update any associated translations before you resubmit your pages, offers, web shop items, and store settings for review.
  6. After your pages, offers, web shop items, and sets of store settings are approved, push your content to the Live sandbox. To do so:
    • a. In the Stage sandbox, click Push to Live.
    • b. In the list of entities (artifacts and binaries, store settings, offers, pages, and web shop items), select the entities that you want to publish.
      • At a minimum, you must push the following entities, if they are not already in your Live sandbox:
        • A base product offer
        • A set of store settings
        • A product home page
        • An artifact for the base product offer (you do not need to do this for a "coming soon" offer).
        • Any other entities that are mandatory for your product (for example, an FAQ page if your product is a PC (Windows, macOS) product in Early Access).
          • For information on mandatory entities, see documentation: Epic Games Store Requirements.
    • c. At the top right, click Push to Live.

After you create localizations for your product, you can view them, remove specific locale support, and view a history of your template uploads.

Request Text Translations from the Epic Translation Service

To help you localize your store presence, the Epic Games Store offers the Epic Translation Service. If you cannot provide your own localizations, you can request free-of-charge text translations from this service. For a list of the languages that the Epic Games Store can localize your content into, see documentation: Supported Languages.

Note that this process can take two weeks or more to complete.

To request text translations:

  1. In the Dev Portal, complete the English-language text for your pages, offers, web shop items, and store settings.
  2. Download the localization template from the Developer Portal. To do so:

    • a. Sign in to the Developer Portal (dev.epicgames.com/portal).

    • b. Select the correct organization for your product.

      (To check, see Organization at the top of the left navigation. To change organization, click Organization and follow the on-screen instructions.)

    • c. In the left navigation, under Your products, click the name of your product.

    • d. In the left navigation, click Epic Games Store > Localization.

    • e. Select the Dev sandbox.

    • f. At the top right, click Download Template.

  3. Request text translation. To do so:
    • Create a private discussion on this support website: eoshelp.epicgames.com.
    • Attach the downloaded localization template to your private discussion message.
    • When the localization is done, the Epic Games Store team posts the completed template in your private discussion.
    • Note: the localization might take two or more weeks.
  4. After you receive the completed template, follow the Create Text Localizations process from Step 4: Import the Localization Template into the Developer Portal onwards to publish your localizations.

After you create localizations for your product, you can view them, remove specific locale support, and view a history of your template uploads.

Combine Complete and Partial Text Localizations

If you want to localize some content for all locales and other content for specific locales only, we recommend that you download and complete a separate template for each set of localizations that you want to do.

For example, if you want to localize your Product Home for all locales, but localize your Product Configuration for only some locales, do the following:

  1. Download a template for Product Home only. Provide localizations for all locale columns. Upload the Product Home Page template.
  2. Download a template for Product Configuration only and provide localizations in the appropriate locale columns. Remove any columns that do not contain localizations. Upload the Product Configuration template.
