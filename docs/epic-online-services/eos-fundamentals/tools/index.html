Epic Online Services (EOS) Tools

Reference information and guidance on EOS tools, including the Bulk Importer and Exporter tool and the File Decryption tool.

Under 1 min to read
Tool: Bulk Import / Export

Access CSV-formatted data, so you can view and edit your stats and achievements in bulk in a wide variety of existing programs or your own tools.
Tool: File Decryption

Create new files or decrypt files loaded to Title Storage and Player Data Storage directly through the command line.
