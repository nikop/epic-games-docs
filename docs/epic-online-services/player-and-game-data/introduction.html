Player and Game Data Introduction

Keep progress persistent and increase long-term engagement. Securely manage and sync data across platforms.

2 mins to read

Keep player progress persistent and increase long-term player engagement and retention. Enable players to carry their stats, achievements, and progression wherever they play, while you securely manage and sync data across platforms.

Player and Game Data are EOS Game Services — players can connect to your game with an account from any supported identity provider. For details, see Epic Online Services (EOS) Overview > Type of Service.

Manage player and game data for your game with the following EOS interfaces:

  • Leaderboards: Define leaderboards for your game, choose the stats to include, how you rank players, and the lifespan of the leaderboards.
  • Stats: Define the stats for your game in the Developer Portal. You can include any statistical data about a player that you want to track, for example the number of items the player has collected. You can use these stats to determine when to unlock achievements and how to use rank players in leaderboards.
  • Achievements: Access data about player achievements, unlock them for a player, get data on a player's progression for an achievement, and send notifications to players when they unlock an achievement.
  • Player Data Storage: Save, download, copy, and delete player-related data for your game on cloud servers in encrypted form.
  • Title Storage: Use the Title Storage Interface to retrieve game-specific data that is stored in encrypted form on cloud servers.
  • Custom Invites: If your game has its own player-invitation system, you can manage this through the Social Overlay UI (the Social Overlay is part of the EOS Overlay).
  • Metrics: Use the Metrics Interface to set up the game analytics dashboard in the Developer Portal and track worldwide game activity, player retention, and online player counts. You can view your game’s usage data, including players’ active sessions and past sessions.

Player and Game Data also has the following features:

  • Player Search: View and manage the data that EOS stores about your players on your behalf.
  • Ticketing System: Manage support for your players with a pre-assigned email address and public web API key.
