Guide: View EOS SDK Log Messages — 1. Enable EOS Logging

Overview of how to enable logs from the EOS SDK for your game.

19 mins to read

Previous section: Introduction

This section of the guide is available in C++ and C#. The C++ version uses the EOS SDK API in C.

To receive log messages from the EOS SDK, you must register a callback function through the Logging Interface. Then, you can set a log level for each log category to specify which log messages the EOS SDK sends to your game. We recommend that you save your log messages to a file when you receive them, so you can review them later if you need to or send them to support if you require help. You can also print them directly to the console for debugging.

The example code snippets in this guide are for guidance only. If you use the snippets, make sure you tailor them to the unique circumstances of your game.

Step 4: Set the Log Level

Set the log level for a log category, or all log categories, to specify the log messages that you want to receive for a log category, or all log categories, and how detailed (verbose) you want that information to be. You can also disable log messages for specific log categories. For the full list of log categories, see the API reference documentation: EOS_ELogCategory .

Log levels are ranked in the following order:

Log Level Description Integer
EOS_LOG_VeryVerbose Includes the most information. Set this log level if you need to share logs with support. 600
EOS_LOG_Verbose Includes more detailed information about EOS SDK processes than the Info level. 500
EOS_LOG_Info Includes general information about EOS SDK processes. This is the default log level for most categories. 400
EOS_LOG_Warning Includes information that might be indicative of issues but it is not an immediate cause for alarm. 300
EOS_LOG_Error Includes errors that prevent proper functionality of the EOS SDK. 200
EOS_LOG_Fatal Includes errors that prevent the EOS SDK from running. 100
EOS_LOG_Off Disables all log messages for the specified category. 0

Your registered callback can only receive log messages at or below the specified log level for a log category. For example, if you set the log level for a log category to “EOS_LOG_Warning”, then your registered callback function will receive log messages for that log category that have the log level EOS_LOG_Warning, EOS_LOG_Error, or EOS_LOG_Fatal.

This guide shows how to set the log level to EOS_LOG_VeryVerbose for development purposes. EOS_LOG_VeryVerbose is ideal during development because it provides the most information.

Note: Do not set the log level to EOS_LOG_VeryVerbose in the shipped version of your game. Instead, set the log level to EOS_LOG_Info. We recommend that you use a command line parameter to control the log level when you start the game. This approach lets you change your log level to EOS_LOG_VeryVerbose in the shipped version of your game if you need to.
