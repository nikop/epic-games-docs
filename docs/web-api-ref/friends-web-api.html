Friends Web API

RESTful endpoints to retrieve a player's friends list and block list without using the SDK.

6 mins to read

Note: This service is also available through the Epic Online Services (EOS) SDK API. See the Friends Interface documentation for more information.

Use the Friends Web API to retrieve an authenticated player's friends list and block list. You can then use these lists to integrate social features into your game. For example: showing a player's friends list in an in-game UI.

The Friends Web API is part of EOS Epic Account Services. To integrate the Friends Web API with your game, you use two EOS interfaces: these are the Auth Interface for player authentication and the Friends Interface for player friends lists and block-list retrieval.

Before You Start

When you use the Friends Interface, you must first authenticate players. Because the Friends Interface is part of EOS Epic Account Services, you use the Auth interface to do this. The Auth Interface enables player authentication with Epic Games accounts, providing an access token that your game uses in calls to Epic Account Services APIs, such as the Friends Interface, both the SDK Friends Interface and the Friends Web Interface.

For information about integrating EOS Auth and acquiring access tokens, see the documentation on requesting an access token: Authentication > Requesting an Access Token.

Note: All Friends Web API endpoints require that the player has already consented to Basic Profile and Friends permissions. Players do this as part of the permission consent flow. (Documentation: Get Started > Permissions.)

A player's friends list and block list only appear in results if the players on the lists have also consented to the Basic Profile permission.

Account ID

The endpoint to get a player's friends list and block list is: https://api.epicgames.dev/epic/friends/v1/{accountId}

You must pass an access token in the Authorization header using Bearer authorization. (Documentation: Authentication > Requesting an Access Token).

This endpoint supports the following query parameters:

Parameter Description
accountId The unique ID of the account to query.
