Guide: View EOS SDK Log Messages — Introduction

Overview of how to view log messages from the EOS SDK in your game.

Under 1 min to read

Use the Epic Online Services (EOS) Logging Interface to receive log messages about the EOS SDK services that run in your game (or other software application).These log messages can help you diagnose technical issues, both while you develop your game and after you have shipped it.

To view these log messages, you must first register a callback function through the Logging Interface to receive them. You can then save them to a file, so you can review them later or share them with support if you need help.

By default, the EOS SDK logs messages for all log categories. However, you can set a log level for those log categories to specify which log categories you receive log messages for and how detailed the information you receive is.

This guide consists of the following sections:

    1. Enable EOS Logging
    1. Find and Analyze Your Log Messages

This section of the guide is available in C++ and C#. The C++ version uses the EOS SDK API in C.

Note: You must initialize the Platform Interface before you can configure EOS SDK log messages. For more information, see the documentation: Platform Interface.

For more information on the Logging Interface, see the Logging Interface Reference documentation.
