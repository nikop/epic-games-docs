Guide: Access EOS Game Services With the Connect Interface — 2. Refresh Player Authentication

Overview of how to refresh the player's authentication with the Connect Interface in your game.

8 mins to read

Previous section: 1. Log In With an Epic Games Account

This section of the guide is available in C++ and C#. The C++ version uses the EOS SDK API in C.

When you log players in using the Connect Interface, you use an ID Token to authenticate the player. This authentication remains valid and keeps the player logged in for one hour before you must refresh it. You can subscribe to notifications from the EOS SDK to remind you to refresh the player’s authentication before it expires.

The example code snippets in this guide are for guidance only. If you use the snippets, make sure you tailor them to the unique circumstances of your game.

Before You Start

Before you add functionality to refresh the player’s authentication using the Connect Interface, you must complete these steps:

  • Integrate the EOS SDK into your code. (Documentation: Guide: Get Started With EOS.)
  • Integrate the Connect Interface. (Section in this guide: 1. Log In With an Epic Games Account.)

Refresh the Player’s Authentication

Complete these steps to refresh the player’s authentication:

  • Step A: Modify Your Connect Manager Class
  • Step B: Subscribe to the Authentication Expiration Notification
  • Step C: Implement Your Authentication Expiration Notification Callback Function

Note: There is a complete code snippet after these steps in the Complete Code section.

Step A: Modify Your Connect Manager Class

In your connect manager class, add a callback function to call when the player’s current authentication is about to expire.

Example:

// ConnectManager.h class ConnectManager{private:    ...     /**     * Callback function that executes when the current authentication is about to expire.     *     * @param Data - Information passed to the callback function by the EOS SDK.     */    static void EOS_CALL OnAuthExpirationNotification(const EOS_Connect_AuthExpirationCallbackInfo* Data);     ...}

What's happening in the code?

  1. Declare a private static callback function to execute when the player’s current authentication is about to expire. The function definition must match the EOS_Connect_OnAuthExpirationCallback callback function which receives a EOS_Connect_AuthExpirationCallbackInfo data structure. In the example, it's called OnAuthExpirationNotification:

    static void EOS_CALL OnAuthExpirationNotification(const EOS_Connect_AuthExpirationCallbackInfo* Data);

Step B: Subscribe to the Authentication Expiration Notification

In the constructor of your connect manager class, subscribe to your authentication expiration callback function.

Example:

// ConnectManager.cpp ConnectManager::ConnectManager(EOS_HPlatform InPlatformHandle, AuthManager* InAuthManagerPtr)    : PlatformHandle(InPlatformHandle)    , AuthManagerPtr(InAuthManagerPtr){    ConnectHandle = EOS_Platform_GetConnectInterface(PlatformHandle);     EOS_Connect_AddNotifyAuthExpirationOptions NotifyAuthExpirationOptions = {};    NotifyAuthExpirationOptions.ApiVersion = EOS_CONNECT_ADDNOTIFYAUTHEXPIRATION_API_LATEST;     // Assign a callback function that will be called when the current authentication is about to expire.    EOS_Connect_AddNotifyAuthExpiration(ConnectHandle, &NotifyAuthExpirationOptions, this, OnAuthExpirationNotification);}

What's happening in the code?

  1. In the constructor of your connect manager class, create an instance of the EOS_Connect_AddNotifyAuthExpirationOptions data structure to hold the notification options for the authentication expiration notifications. In this example, it’s called NotifyAuthExpirationOptions:

    EOS_Connect_AddNotifyAuthExpirationOptions NotifyAuthExpirationOptions = {};NotifyAuthExpirationOptions.ApiVersion = EOS_CONNECT_ADDNOTIFYAUTHEXPIRATION_API_LATEST;

  2. Call the EOS API EOS_Connect_AddNotifyAuthExpiration function to subscribe to authentication expiration notifications. This function takes the following arguments:

    • The Connect Interface handle.
    • A reference to the notification options for authentication expiration notifications.
    • (Optional) ClientData.
      In the example, we pass the connect manager (this in the example) for the ClientData field, so we can access it in the callback. If you don’t need to pass any additional data to the callback, pass a nullptr instead.
    • A callback function to receive the EOS_Connect_AuthExpirationCallbackInfo data structure when the current authentication is about to expire.
    EOS_Connect_AddNotifyAuthExpiration(ConnectHandle, &NotifyAuthExpirationOptions, this, OnAuthExpirationNotification);

Step C: Implement Your Authentication Expiration Notification Callback Function

Implement the callback function that executes when the player’s current authentication is about to expire.

Example:

// ConnectManager.cpp void EOS_CALL ConnectManager::OnAuthExpirationNotification(const EOS_Connect_AuthExpirationCallbackInfo* Data){    std::cout << "Player authentication is about to expire! Refreshing authentication..." << std::endl;     // Retrieve the ConnectManager pointer from the client data passed to the callback function.    ConnectManager* Self = static_cast<ConnectManager*>(Data->ClientData);     // Log in using a new ID Token.    Self->LogInWithIdTokenExample();}

What's happening in the code?

  1. Implement the callback function that executes when the current authentication is about to expire. The function definition must match the EOS_Connect_OnAuthExpirationCallback callback function which receives an EOS_Connect_AuthExpirationCallbackInfo data structure. In the example, it’s called OnAuthExpirationNotification:

    void EOS_CALL ConnectManager::OnAuthExpirationNotification(const EOS_Connect_AuthExpirationCallbackInfo* Data){ }

    Note:

    • The EOS SDK calls this callback function asynchronously each time the player’s current authentication is about to expire.
    • The EOS_CALL macro is part of the required definition.

  2. In your callback function, call your function to log in using an ID Token, which retrieves a new ID Token and logs in using the Connect Interface again.

    std::cout << "ID Token is about to expire! Refreshing authentication..." << std::endl; ConnectManager* Self = static_cast<ConnectManager*>(Data->ClientData); Self->LogInWithIdTokenExample();

Results

When the player’s current authentication is about to expire, your game calls your login function to refresh the player’s authentication and keep the player logged in. This process can be repeated for as long as the player needs to stay logged in.

Complete Code

This is the complete example code. It collates all the code snippet examples in the steps above.

// ConnectManager.h #pragma once #include <eos_connect.h>#include <eos_init.h>#include <eos_common.h>#include <eos_sdk.h>#include <string> class ConnectManager{public:    /**      * Constructor     *     * @param InPlatformHandle - The handle for the Platform Interface received during platform setup.     */    ConnectManager(EOS_HPlatform InPlatformHandle, AuthManager* InAuthManagerPtr); private:     /**     * Callback function that executes when the current authentication is about to expire.     *     * @param Data - Information passed to the callback function by the EOS SDK.     */    static void EOS_CALL OnAuthExpirationNotification(const EOS_Connect_AuthExpirationCallbackInfo* Data);}
// ConnectManager.cpp ConnectManager::ConnectManager(EOS_HPlatform InPlatformHandle, AuthManager* InAuthManagerPtr)    : PlatformHandle(InPlatformHandle)    , AuthManagerPtr(InAuthManagerPtr){    ConnectHandle = EOS_Platform_GetConnectInterface(PlatformHandle);     EOS_Connect_AddNotifyAuthExpirationOptions NotifyAuthExpirationOptions = {};    NotifyAuthExpirationOptions.ApiVersion = EOS_CONNECT_ADDNOTIFYAUTHEXPIRATION_API_LATEST;     // Assign a callback function that will be called when the current authentication is about to expire.    EOS_Connect_AddNotifyAuthExpiration(ConnectHandle, &NotifyAuthExpirationOptions, this, OnAuthExpirationNotification);} void EOS_CALL ConnectManager::OnAuthExpirationNotification(const EOS_Connect_AuthExpirationCallbackInfo* Data){    std::cout << "Player authentication is about to expire! Refreshing authentication..." << std::endl;     // Retrieve the ConnectManager pointer from the client data passed to the callback function.    ConnectManager* Self = static_cast<ConnectManager*>(Data->ClientData);     // Log in using a new ID Token.    Self->LogInWithIdToken();}
