Guide: Add Stats to Your Game — Introduction

Overview of how to integrate the Stats Interface into your game.

Under 1 min to read

Type of service : This interface is an EOS Game Service — authenticate players with the Connect Interface.

Use the EOS Stats service to track player statistics (also known as "stats") in your game or other software application.

You can use these stats to unlock achievements, to rank players in leaderboards, or to create custom functionality for your game.

Stats can be anything you want. Here are some examples:

  • Track how much gamma radiation a player collects in your game and award them a "Radioactive Hero" achievement when they collect 1000 units of gamma radiation.
  • Track the total number of enemies a player defeats, so they can compete with their friends in a leaderboard.
  • Save a player's longest jump distance to show their personal record in the player log.

This guide consists of the following sections:

    1. Set Up Stats
    1. Update Values for Stats
    1. Retrieve Stats

Note that you must complete the sections of this guide in the order that they are listed above.

The sections of this guide with code examples are available in C++ and C#. The C++ example code uses the EOS SDK API in C.

For more information on the Stats Interface, including usage limitations, see the Stats Interface Reference documentation.
