Guide: Add Leaderboards to Your Game — 2. Retrieve Leaderboards for Your Game

Overview of how to retrieve leaderboards for your game.

27 mins to read

Previous section: 1. Set Up Leaderboards

This section of the guide is available in C++ and C#. The C++ version uses the EOS SDK API in C.

You can add code to your game to retrieve the leaderboards that you have defined for your game (or other software application) after you have completed the precursor steps listed in Before You Start below.

To add code to your game to retrieve the leaderboards that you have defined for your game, you query the leaderboard definitions to save them to the local cache. Then you can copy the cached leaderboard definitions and access the data for each definition.

You can either copy the cached leaderboard definitions by leaderboard ID (for example, "CarsSmashedWorldwide") or copy them all. This guide shows how to copy all leaderboard definitions. For information on how to copy leaderboard definitions individually by leaderboard ID, see the EOS_Leaderboards_CopyLeaderboardDefinitionByLeaderboardId function API reference documentation.

The example code snippets in this guide are for guidance only. If you use the snippets, make sure you tailor them to the unique circumstances of your game.

Before You Start

Before you start, you must complete these steps:

  • Integrate the EOS SDK into your code. (Documentation: Guide: Get Started With EOS.)
  • Use the Connect Interface in your code to get the local player’s Product User ID. (Documentation: Guide: Access EOS Game Services With the Connect Interface.)
  • Create a leaderboard in the Developer Portal. (Section in this guide: 1. Set Up Leaderboards.)

Results

You can access the EOS_Leaderboards_Definition data structure through the leaderboard definition pointer that you passed in the EOS_Leaderboards_CopyLeaderboardDefinitionByIndex() function call. The EOS_Leaderboards_Definition data structure contains information about the leaderboard at the given index in the cached list of leaderboard definitions.

You can also call the LeaderboardsManager::GetRetrievedDefinitions() function in your game code to access the leaderboard definitions that you copied to the definitions map. Make sure there are no definition queries in progress before you call LeaderboardsManager::GetRetrievedDefinitions(). If there are queries in progress, the leaderboard definitions you retrieve might not include the latest updates from the active query and will therefore be outdated.
