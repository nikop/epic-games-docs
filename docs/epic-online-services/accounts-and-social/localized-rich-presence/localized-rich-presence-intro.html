Localized Rich Presence — Introduction

Introduction to rich presence messages, dynamic message content, and localization of these messages in your product.

1 min to read

Presence messages display the online status of a player to their friends. Your product (game or other software application) can also display additional information to a player's friends. This is called rich presence. For general information on presence, see documentation: Presence Interface.

In the Developer Portal, you can localize the text of rich presence messages so that each message appears in the language of the player receiving it. For each message that you want to localize, you must create a localized rich presence template. This template defines the text of the message in the languages of one or more locales.

Note: If you don't provide a localization for a particular locale, players in that locale see the rich presence message in the template's default locale. For example, if your localized rich presence template's default locale is English and you do not translate a rich presence message into Spanish, then Spanish-speaking users see the message in English. You choose the default locale when you create or edit the template.

Dynamic Message Content

Rich presence messages can optionally have dynamic content that changes depending on the player's status or activity. For example, a message might display the game level that a player is currently playing.

To include this dynamic content in your localized rich presence template, you must set up a localized presence variable for that dynamic content. For example, if you have a status message as follows:

Currently playing {level_id}

In this example, level_id is a localized presence variable. It provides the name of the game level that the player is currently playing.

In your game code, you can use the Epic EOS Account Services Presence Interface to set the dynamic content, as described below.
