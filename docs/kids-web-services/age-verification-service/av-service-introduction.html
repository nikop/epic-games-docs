Age Verification Service Introduction

An overview of the Age Verification Service.

1 min to read

Use the Age Verification (AV) Service to verify the age of a given user of your product (game or other software application).

The AV Service works as follows:

  1. In your product's user interface, you collect a user's email address, language preference, and country or region. You then pass this data to KWS in an authenticated API call.

  2. This API call triggers the verification flow and user interface managed by KWS.

  3. In the KWS verification flow, the user verifies their age using one of several verification methods if they are not found in KWS' AgeGraph.

  4. Upon successful verification, KWS directs the user to a URL that you have pre-specified. If you do not provide a URL, KWS displays a verification success message to the user.

  5. The user receives a verification success email.

  6. KWS notifies you of the successful verification using a webhook, an API verification response, or both.

When to Use the Age Verification Service

The Age Verification Service verifies the age of a given user of your product. You must not use the Age Verification Service to determine if a user can access content related, but not limited to, the following:

  • Financial services (for example, banking, money transfer, cryptocurrency)
  • Pornography
  • Gambling
  • Drugs and illegal substances

Note: If you are unsure whether the content falls within one of these prohibited categories, consult your legal counsel and inform your Technical Account Manager.
