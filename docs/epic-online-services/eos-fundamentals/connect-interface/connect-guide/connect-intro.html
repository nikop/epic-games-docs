Guide: Access EOS Game Services With the Connect Interface — Introduction

Overview of how to access EOS Game Services in your game.

Under 1 min to read

The following groups of services are EOS Game Services:

  • Multiplayer
  • Player and Game Data
  • Trust and Safety
  • EOS Fundamentals

EOS Game Services uses the Connect Interface to authenticate players. Using the Connect Interface, players can log in to your game (or other software application) using an account from any supported identity provider, such as a Steam account, Google account, Amazon account, or an Epic Games account, among others. (See the Identity Provider Management documentation for a complete list of providers.) Players don’t need to have an Epic Games account to access EOS Game Services.

Note: If your game requires players to use both type of service (both EOS Game Services and EOS Epic Account Services), they must log in to EOS Game Services with their Epic Games account or a proxy account. If players use EOS Epic Account Services in your game, they cannot log in to EOS Game Services with a supported external identity provider.

Note: The Connect service is also available as a web API. This guide does not cover how to use the Connect Web API. For more information, see the Connect Web APIs documentation.
