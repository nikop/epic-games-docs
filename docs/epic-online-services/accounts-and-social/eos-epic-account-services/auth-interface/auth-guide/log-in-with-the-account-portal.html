Guide: Access EOS Epic Account Services With the Auth Interface — 3. Log In With the Account Portal

Overview of how to log in to an Epic Games account in your game using the Account Portal.

27 mins to read

Previous section: 2. Log In With the Developer Authentication Tool

This section of the guide is available in C++ and C#. The C++ version uses the EOS SDK API in C.

One method you can use to log in to your Epic Games account and access Epic Account Services is the Account Portal. The Account Portal walks the user through the login process based on their account state. For example, when a user attempts to log in for the first time, the EOS SDK automatically prompts the user to permit the game’s associated Epic Account Services application to access basic information about their Epic Games account, as well as any other scopes the game requests. Alternatively, you can use the Developer Authentication Tool to log in while you develop your game (section in this guide: 2. Log in With the Developer Authentication Tool).

After a player logs in through the Account Portal for the first time, persistent authorization can be used for all future logins without the player needing to enter their account information into the Account Portal. We recommend that you attempt to log in the player with persistent authorization first. If the player has not logged in using the Account Portal before, the login will fail, and the game should attempt to log in the player through the Account Portal. The example code in this section demonstrates this workflow.

The example code snippets in this guide are for guidance only. If you use the snippets, make sure you tailor them to the unique circumstances of your game.

Before You Start

Before you start, you must complete these steps:

  • Integrate the EOS SDK into your code. (Documentation: Guide: Get Started With EOS.)
  • Create an Epic Account Services application for your product in the Developer Portal (section in this guide: 1. Set Up Epic Account Services)

Step A: Modify Your Auth Manager Class

Modify your auth manager class to log in with persistent authorization and the Account Portal.

Example:

// AuthManager.h class AuthManager{public:    ...     /**      * Log in to the player's Epic Games account using persistent authorization,      * or fall back to logging in with the Account Portal if the persistent authorization     * login fails.     */    void AttemptLogInWithPersistentAuthExample();     ... private:    ...     /**     * Callback function that executes when persistent authorization login is complete.     *     * @param Data - Information passed to the callback function by the EOS SDK.     */    static void EOS_CALL OnAuthLogInWithPersistentAuthComplete(const EOS_Auth_LoginCallbackInfo* Data);        /**     * Callback function that executes when Account Portal login is complete.     *     * @param Data - Information passed to the callback function by the EOS SDK.     */    static void EOS_CALL OnAuthLogInWithAccountPortalComplete(const EOS_Auth_LoginCallbackInfo* Data);     /** Log in to the player's Epic Games account using the Account Portal. */    void LogInWithAccountPortalExample();     ...}

In the example, it's called OnAuthLogInWithAccountPortalComplete:

  4. Declare a private function to log in using the Account Portal. In the example, it’s called LogInWithAccountPortalExample:

    void LogInWithAccountPortalExample();

Step B: Implement Your Persistent Authorization Login Function

In your auth manager class, implement the function to log in using persistent authorization.

Example:

//AuthManager.cpp void AuthManager::AttemptLogInWithPersistentAuthExample(){    // Set the credentials for persistent authorization.    EOS_Auth_Credentials Credentials = {};    Credentials.ApiVersion = EOS_AUTH_CREDENTIALS_API_LATEST;    Credentials.Type = EOS_ELoginCredentialType::EOS_LCT_PersistentAuth;    Credentials.Token = nullptr;    Credentials.Id = nullptr;     // Set the options for logging in.    EOS_Auth_LoginOptions LoginOptions = {};    LoginOptions.ApiVersion = EOS_AUTH_LOGIN_API_LATEST;    LoginOptions.ScopeFlags = EOS_EAuthScopeFlags::EOS_AS_BasicProfile;    LoginOptions.Credentials = &Credentials;     // Log into an Epic Games account using the Auth Interface.    EOS_Auth_Login(AuthHandle, &LoginOptions, this, OnAuthLogInWithPersistentAuthComplete);}

Note: The EOS_Auth_LoginOptions.ScopeFlags option must match the permissions you set for your Epic Account Services application in the Developer Portal. (Section in this guide: 1.Set Up Epic Account Services)

Step C: Implement Your Persistent Authorization Login Callback Function

Implement the function that executes when the EOS_Auth_Login function completes in your persistent authorization login function.

Example:

//AuthManager.cpp void EOS_CALL AuthManager::OnAuthLogInWithPersistentAuthComplete(const EOS_Auth_LoginCallbackInfo* Data){    if (Data->ResultCode == EOS_EResult::EOS_Success)    {        std::cout << "Logged in with persistent authorization successfully!" << std::endl;         // Retrieve the AuthManager pointer from the client data passed into the callback function.        AuthManager* Self = static_cast<AuthManager*>(Data->ClientData);         // Retrieve the Epic Account ID.         Self->EpicId = Data->LocalUserId;    }    else if (EOS_EResult_IsOperationComplete(Data->ResultCode) == EOS_FALSE)    {        // If the code gets here, the operation is retrying and is not yet complete.        return;    }    else    {        // If the code gets here, there was an error;        // attempt logging in using the account portal instead.        std::cerr << "Failed to log in with persistent authorization. Attempting log in through Account Portal. Error code: "            << static_cast<int>(Data->ResultCode) << " - " << EOS_EResult_ToString(Data->ResultCode) << std::endl;                // Retrieve the AuthManager pointer from the client data passed into the callback function.        AuthManager* Self = static_cast<AuthManager*>(Data->ClientData);                // If logging in with persistent authorization didn't work, try logging in through the Account Portal instead.        Self->LogInWithAccountPortalExample();    }}

Results

When you run your game for the first time, the Account Portal opens in the EOS overlay (or in your default web browser if the overlay is not enabled or installed). The first time you log in to your Epic Games account through the Account Portal, you receive an auth token from the EOS SDK on your device. The next time you run your game, the EOS SDK uses persistent authorization to automatically log you in to your Epic Games account. When you log in to your Epic Games account, you receive an Epic Account ID from the EOS SDK. You can use this ID to access the Epic Account Services type of service , such as the Friends Interface and the Presence Interface. You can also use an Epic Account ID to receive an auth token that you can use to log in to the Connect Interface to access EOS Game Services (Documentation: Connect Interface).

Note: Your player is logged out automatically when the game closes. To logout the player manually, use the EOS_Auth_Logout function. For more information, see the Notes section below.

Notes

Log the Player Out

The EOS SDK automatically logs the player out when they close your game. You can also manually log the player out if you need to. This is useful if you want to log the player out while your game is still running, or you want to delete the player’s persistent auth token to disable automatic login. To manually log the player out of your game:

  1. Create an instance of the EOS_Auth_LogoutOptions data structure to hold the log-out options for the player. In the example, it’s called LogoutOptions:

    EOS_Auth_LogoutOptions LogoutOptions = {};LogoutOptions.ApiVersion = EOS_AUTH_LOGOUT_API_LATEST;LogoutOptions.LocalUserId = EpicId;

  2. Call the EOS API EOS_Auth_Logout function to log the player out. This function takes the following arguments:

    • The Auth Interface handle.
    • A reference to the log-out options data structure.
    • (Optional) ClientData. For example, you can pass a pointer to the auth manager for the ClientData field, so you can access it in the callback. If you don’t need to pass any additional data to the callback, pass a nullptr instead.
    • A callback function to receive the EOS_Auth_LogoutCallbackInfo data structure when the Auth Interface completes the log-out process.

Disabling Automatic Login with Persistent Auth

To disable automatic login with persistent auth, call the EOS API EOS_Auth_DeletePersistentAuth function after you use the EOS API EOS_Auth_Logout function to log the player out. For more information, see the documentation: Auth Interface Reference > Persist Player Login to Epic Games Account outside Epic Games Launcher.
