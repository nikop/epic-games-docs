EOS SDK and Your Unity Project on Windows

How to integrate the EOS SDK into your Unity project on Windows.

7 mins to read

To integrate the EOS SDK into your Unity project, we recommend that you use the EOS Plugin for Unity. For information, see documentation: Introduction (EOS SDK & Game Engines) > Unity.

Use this how-to guide only if you cannot use the EOS Plugin for Unity.

This guide shows you how to manually integrate the EOS SDK into your Unity project on Windows. The sample code in this guide is written in C#.

After you complete these steps, you will know how to:

  • Download and install the EOS SDK into your Unity project
  • Initialize the EOS SDK
  • Create the Platform Interface
  • Shut down the EOS SDK

Before You Begin

Read the How to Integrate the EOS SDK Into Your Unity Project > Introduction page before you begin. It includes information on limitations that the EOS SDK has in the Unity Editor that you should be aware of.

To integrate the EOS SDK into your Unity project, you must first set up your Epic Games account and organization in the Developer Portal.
If you have not already done this, follow the guidance in Guide: Get Started With EOS > 1. Set Up Your Account and Download the EOS SDK to set these up.

Integrate the EOS SDK into Your Unity Project

To integrate the EOS SDK into your Unity project on Windows you must complete these steps:

  1. Download and install the EOS SDK into your Unity project.
  2. In your game's code, initialize the EOS SDK when your game starts.
  3. Create the EOS Platform Interface.
  4. In your game's code, shut down the EOS SDK when your game closes.

Step 1: Download and Install the EOS SDK into Your Unity Project

To download the EOS SDK for Windows and install it into your Unity Project, follow these steps:

  1. Download the EOS SDK from the Developer Portal.

    • a. Sign in to the Developer Portal at (dev.epicgames.com/portal).
    • b. In the left navigation, click Dashboard if it isn't already selected.
    • c. On the Dashboard page, under the Your products heading, click Downloads & Release notes.
    • d. Select the EOS SDK tab.
    • e. In SDK Type, select C# SDK.
    • f. In SDK Version, select the most recent version.
    • g. Click Download.

  2. Unzip the EOS SDK download.

  3. Organize the EOS SDK files in your Unity project as follows:

    • a. Move all the files from /SDK/Source into the Assets directory.

      Tip: Organize the SDK/Source files into a subdirectory of your Assets directory to make them easier to manage.

    • b. Move the SDK/Bin/x64 and SDK/Bin/x86 directories into the Assets/Plugins/Windows directory in your Unity project.

  4. Verify that the binaries are configured to load for the correct platform.
    To do this, click the binary file and verify that the settings are for the correct Windows platform.
    Verify that the EOSSDK-Win32-Shipping.dll loads only on x86 versions of the Editor and standalone player, and that the x86-64 (Intel 64-bit) binary, EOSSDK-Win64-Shipping.dll loads only on x86-64 (Intel 64-bit).

    Note: You can import binaries for different platforms into the same project, but you must make sure that they are configured to load on the proper platform. For more information, see Unity's documentation at docs.unity3d.com/~/plug-in-inspector.

Step 3: Create the EOS Platform Interface

After you initialize the EOS SDK, you must create the Platform Interface to configure the options for your platform. This lets you do several things, including:

  • Retrieve handles to access the other EOS Interfaces.
  • Control the EOS SDK lifecycle (for example, shut down the EOS SDK).
  • Keep the per-frame update code running (known as ticking).

When you are ready to close your game, you must also shut down the EOS SDK. During shutdown, do the following:

  • Release the global state held by the EOS SDK
