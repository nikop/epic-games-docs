Guide: Sanction Players — 2. Retrieve Sanctions

Step-by-step guide on how to retrieve active sanctions against a player, in your game code.

28 mins to read

Previous section: 1. Set Up and Apply Sanctions

This section of the guide is available in C++ and C#. The C++ version uses the EOS SDK API in C.

This section of the guide explains how your game can retrieve the details of any active sanctions for a specific player. To do this, your game code must query the active sanctions to save them to the local cache, copy the cached sanctions, then access the data for each sanction.

You can use this sanction data however you choose to in your game, but common scenarios include the following:

  • Copy the reference ID of an active sanction against the player and use it in a sanction appeal (section of this guide: 3. Allow Players to Appeal Sanctions).
  • Enforce gameplay restrictions on the player based on the action of the sanction against them.

The example code snippets in this guide are for guidance only. If you use the snippets, make sure you tailor them to the unique circumstances of your game.

Before You Start

  • Integrate the EOS SDK into your code. (Documentation: Get Started Steps.)

Results

After you call the EOS_Sanctions_CopyPlayerSanctionByIndex() function, on success, you can access the EOS_Sanctions_PlayerSanction data structure through the sanction pointer that you passed in the EOS_Sanctions_CopyPlayerSanctionByIndex() function call.

You can also call the SanctionsManager::GetRetrievedSanctions() function to access the sanctions that you copied to the sanctions vector. Make sure there are no sanction queries in progress before you call GetRetrievedDefinitions. If there are queries in progress, the sanctions you retrieve might not include the latest updates from the active query and will therefore be outdated.
