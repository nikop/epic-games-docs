Social Restrictions

Information about the different types of social restrictions and how they are displayed in the Social Overlay.

3 mins to read

Note: The Social Overlay does not support the following platforms: macOS, Linux, Linux ARM64, Android, and iOS.
Players must sign in with their Epic Games account or a proxy account to use the Social Overlay.

This documentation assumes that you install the Social Overlay with your game and initialize the EOS SDK when a player starts your game. For more information on how to install and initialize the Social Overlay, see the SDK Integration documentation.

The Social Overlay displaying social restriction information.

Information about the ban or restriction appears in the Social Overlay if a player has ban, or if social features are disabled either by parental controls, user settings or console settings

For more information about social bans and account sanctions, see the Sanction Players — Introduction documentation.

Friend request restrictions

Restriction Type Restriction Message Description
Social ban You have X days left of your ban from adding friends for breaking community rules The player has a ban for breaking community rules. The Social Overlay displays the days remaining until the ban is lifted.
