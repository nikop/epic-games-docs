Edit a Localized Rich Presence Template

How to edit a localized rich presence template.

Under 1 min to read

Use localized rich presence templates to define localized text for custom status messages (rich presence) that your product displays to your users' friends. For more information, see Localize Your Game's Rich Presence Messages—Introduction.

Note: To quickly find a specific template that you want to edit, see documentation: Find a Specific Template.

To edit a template:

  1. Sign in to the Developer Portal (dev.epicgames.com/portal).

  2. Select the correct organization for your product, if prompted.

    (To check which organization is selected, see Organization at the top of the left navigation. To change organization, click Organization and follow the on-screen instructions.)

  3. In the left navigation, under Your products, click the name of your product.

  4. In the left navigation, click Epic Online Services.

  5. In the Accounts & Social section, click Localized Presence.

  6. In the list, locate the template you want to edit.

    • Note: If you want to search for a specific template, see documentation: Find a Specific Template.

  7. For that template, click the three dots ( … ).

  8. Click Edit.

  9. Fill out the template options. You must select a value for eveyr option marked with an asterisk (*).

    • Template ID*: A short name for the template. Choose a name that describes the event or status that triggers the message, such as onEnterMenu.
      • In your product code, specify this template ID. For more information, see documentation: Display Localized Presence in Your Game.
      • The template ID must be unique per deployment.
      • You can enter between 1 and 200 characters.
      • After you create a template, you cannot change its ID later. This is a safeguard feature in case the ID is already in use in a user client. However, you can create a copy of the template and choose a new ID for the copy. To do this, click Save as new template next to Template ID:
    • Default locale*: Select the main locale for your product.
      • If you do not provide localized text for a locale, then message recipients in that locale see messages in the language of the default locale. For example, if your default locale is English and you don't provide localized text for Italian, then users in the Italian locale see the message in English.
    • Variables: In your template, you can include dynamic content that your user client provides during runtime. For each piece of dynamic content, you must add a variable instance to the template.
      • You can only add a variable instance to your template if you have already created a matching variable definition in the Variable definitions tab. For more information, see Variable Definitions—Introduction.
      • You can add up to eight variable instances to a template.
      • You can only use a variable instance name once in the same template.
      • For each variable you want to add:
        • a. Click Add variable.
        • b. Set the options as follows:
          • Variable definition ID: Select the variable definition you want to base this variable instance on.
            • The variable definition determines the allowed values in the variable instance.
            • To create a variable definition, see Create a Variable Definition.
          • Variable instance name: Enter a name for the variable instance. To include the variable instance in your message text (in Localized values below), use this variable instance name inside curly braces.
            • For example, if the variable instance name is current_map, the message text might be Playing in {current_map}.
            • In your code, use the variable instance name that you enter here. For more information, see documentation: Display Localized Presence in Your Game.
      • To delete a variable instance from the template, click the trash can icon next to it.
    • Localized values
      • A localized value is a translation of the template text for a specific locale.
      • For each localized value, set the following options:
        • Locale*: Select the locale where this translation will appear.
        • Value*: Enter the translated text for this locale. For example, if you select Arabic as the Locale, then the Value is a translation in Arabic of the message text.
          • To include dynamic content in the text, enter an appropriate variable name in curly braces. For example Playing in {current_map}.
            • You must also add this variable to the template. For more information, see Variables above.
        • For each additional localized value you want to add, click Add locale, and set Locale and Value for the localized value.

  10. Click Save Changes.
