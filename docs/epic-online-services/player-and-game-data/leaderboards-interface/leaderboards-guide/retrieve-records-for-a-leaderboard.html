Guide: Add Leaderboards to Your Game — 3. Retrieve Records for a Leaderboard

Overview of how to retrieve records for a leaderboard.

30 mins to read

Previous section: 2. Retrieve Leaderboards for Your Game

This section of the guide is available in C++ and C#. The C++ version uses the EOS SDK API in C.

You can add code to your game to retrieve the records for your leaderboards after you have completed the precursor steps in Before You Start below.

A leaderboard record consists of the following data for the player who set the record:

  • The Product User ID of the player.
  • The display name of the player.
  • The score for the record.
  • The numerical ranking in the leaderboard for the record.

Note: The EOS API refers to a leaderboard record as a “record” in most circumstances. However, in certain circumstances, the EOS API refers to a leaderboard record as a “rank” (these circumstances are noted below).

To add code to your game to retrieve the leaderboard records for your leaderboards, you query the record to save it to the local cache. Then you can copy the record data and access the leaderboard records. For example, you can query the records for the “CarsSmashedWorldwide” leaderboard and then display them to the player in a personal dashboard.

You can either copy the cached leaderboard records by user ID or copy them all. This guide shows how to copy all leaderboard records. For information on how to copy leaderboard records individually by user ID, see the EOS_Leaderboards_CopyLeaderboardRecordByUserId function API reference documentation.

The example code snippets in this guide are for guidance only. If you use the snippets, make sure you tailor them to the unique circumstances of your game.

Before You Start

Before you start, you must complete these steps:

  • Integrate the EOS SDK into your code. (Documentation: Guide: Get Started With EOS.)
  • Use the Connect Interface in your code to get the local player’s Product User ID. (Documentation: Guide: Access Game Services With the Connect Interface.)
  • Create a leaderboard in the Developer Portal. (Section in this guide: 1. Set Up Leaderboards.)

Step 1: Modify Your Leaderboards Manager Class

Modify your leaderboards manager class to include the variables that you need to retrieve leaderboard records.

Note: The example code below is not the complete code. It includes only the additions that you must make to your leaderboards manager class .h file. For the complete code, see the complete code snippet after these steps in the Complete Code section.

Example:

LeaderboardsManager.h 

// LeaderboardsManager.h /** A data structure to hold information copied from the queried leaderboard records. */struct LeaderboardRecordCopy{    /** The ID of the leaderboard, exactly as you wrote it in the Developer Portal. */    std::string LeaderboardId;     /** The ranking of the leaderboard record based on the score. */    uint32_t Rank;        /** The score set for the leaderboard by the player holding the record. */    int32_t Score;     /** The display name of the player holding the record. */    std::string UserDisplayName;     /** The Product User ID of the player holding the record. */    EOS_ProductUserId UserId;}; class LeaderboardsManager{public:    ...     /**     * Getter for a read-only copy of one of the records maps.     *     * @return A read-only copy of a map within the RetrievedRecords map of maps.     */    const std::map<uint32_t, LeaderboardRecordCopy>        GetRetrievedLeaderboardRecords(const char* LeaderboardId) const { return RetrievedRecords.at(LeaderboardId); }        /**     * Begins the process of querying and then copying the records of a leaderboard.     *     * @param LeaderboardId - The ID of the leaderboard to retrieve the records of.     */    void RetrieveLeaderboardRecordsExample(const char* LeaderboardId); private:    ...     /** Map of maps to hold copied leaderboard records for each definition. */    std::map<std::string, std::map<uint32_t, LeaderboardRecordCopy>> RetrievedRecords;        /**     * Callback function that executes when the records (ranks) query completes.     *     * @param Data - Information passed to the callback function by the EOS SDK.     */    static void EOS_CALL OnQueryLeaderboardRanksComplete(const EOS_Leaderboards_OnQueryLeaderboardRanksCompleteCallbackInfo* Data);     /** Called after querying leaderboard records to copy the records to the records map. */    void CopyLeaderboardRecordsExample(const char* LeaderboardId);     ...};

What's happening in the code?

The following sub-steps are a breakdown of the code example above.

  1. In the LeaderboardsManager.h file, create a custom leaderboard record data structure to hold the leaderboard record data that you want to copy for your game. In the example, it’s called LeaderboardRecordCopy.

    struct LeaderboardRecordCopy{    std::string LeaderboardId;    uint32_t Rank;    int32_t Score;    std::string UserDisplayName;    EOS_ProductUserId UserId;};

  2. In your LeaderboardsManager class, declare a public function to get read-only access to the leaderboards records map for a specific leaderboard ID. (Note: The map itself is declared as a private variable and described in more detail in a step below.) In the example, it's called GetRetrievedLeaderboardRecords:

    const std::map<uint32_t, LeaderboardRecordCopy>        GetRetrievedLeaderboardRecords(const char* LeaderboardId) const { return RetrievedRecords.at(LeaderboardId); }

  3. Declare a public function to query the records for a leaderboard. In the example, it’s called RetrieveLeaderboardRecordsExample:

    void RetrieveLeaderboardRecordsExample(const char* LeaderboardId);

  4. Declare a private map to hold leaderboard records that you want to copy for your game. The map holds leaderboard ID (std::string) and nested map pairs. The nested map for each leaderboard ID holds numerical ranking (uint32_t) and custom leaderboard record data structure (LeaderboardRecordCopy) pairs. In the example, the map is called RetrievedRecords:

    std::map<std::string, std::map<uint32_t, LeaderboardRecordCopy>> RetrievedRecords;

  5. Declare a private static callback function to execute when the EOS_Leaderboards_QueryLeaderboardRanks() function completes. The function definition must match the EOS_Leaderboards_OnQueryLeaderboardRanksCompleteCallback callback function which receives a EOS_Leaderboards_OnQueryLeaderboardRanksCompleteCallbackInfo data structure. In the example, it's called OnQueryLeaderboardRanksComplete:

    static void EOS_CALL OnQueryLeaderboardRanksComplete(const EOS_Leaderboards_OnQueryLeaderboardRanksCompleteCallbackInfo* Data);

  6. Declare a private function to copy the queried leaderboard records from the local cache. In the example, it’s called CopyLeaderboardRecordsExample:

    void CopyLeaderboardRecordsExample(const char* LeaderboardId);

Step 2: Implement Your Query Leaderboard Records Function

Note: In this instance, the EOS API refers to a leaderboard record as a “rank.”

In your .cpp file, in your leaderboards manager class, implement the query function to retrieve the records for a leaderboard.

Example:

// LeaderboardsManager.cpp void LeaderboardsManager::RetrieveLeaderboardRecordsExample(const char* LeaderboardId){    EOS_Leaderboards_QueryLeaderboardRanksOptions QueryRankOptions = {};    QueryRankOptions.ApiVersion = EOS_LEADERBOARDS_QUERYLEADERBOARDRANKS_API_LATEST;     // The ID of the leaderboard whose records you are querying (also referred to as "ranks").    QueryRankOptions.LeaderboardId = LeaderboardId;     // The Product User ID of the local player requesting the query.    QueryRankOptions.LocalUserId = LocalProductUserId;     // Create an std::pair to store both the class pointer and the leaderboard ID.    auto ClassPointerAndLeaderboardId = new std::pair<LeaderboardsManager*, const char*>(this, LeaderboardId);     // Call the EOS SDK to query your leaderboard records (ranks).    // The callback function will be called when it finishes.    EOS_Leaderboards_QueryLeaderboardRanks(LeaderboardsHandle, &QueryRankOptions,         ClassPointerAndLeaderboardId, OnQueryLeaderboardRanksComplete);}

What's happening in the code?

The following sub-steps are a breakdown of the code example above.

  1. In your leaderboards manager class, implement the function to query the records for a leaderboard. In the example, it's called RetrieveLeaderboardRecordsExample:

    void LeaderboardsManager::RetrieveLeaderboardRecordsExample(const char* LeaderboardId){ }

  2. In your query function, create an instance of the EOS_Leaderboards_QueryLeaderboardRanksOptions data structure to hold the query options for the leaderboard records. In the example, it's called QueryRankOptions.

    Note: In this instance, the EOS API refers to a leaderboard record as a “rank.”

    EOS_Leaderboards_QueryLeaderboardRanksOptions QueryRankOptions = {};QueryRankOptions.ApiVersion = EOS_LEADERBOARDS_QUERYLEADERBOARDRANKS_API_LATEST;QueryRankOptions.LeaderboardId = LeaderboardId;QueryRankOptions.LocalUserId = LocalProductUserId;

  3. Create a pair object that will store both a pointer to the leaderboards manager class and the ID of the leaderboard that you want to query the ranks for.

    auto ClassPointerAndLeaderboardId = new std::pair<LeaderboardsManager*, const char*>(this, LeaderboardId);

  4. Call the EOS API EOS_Leaderboards_QueryLeaderboardRanks() function. This function saves the leaderboard records to the local cache.

    Note: In this instance, the EOS API refers to a leaderboard record as a “rank.”

    The function takes the following arguments:

    • The Leaderboards Interface handle.
    • A reference to the query options for the leaderboard ranks.
    • (Optional) ClientData.
      In the example, we pass the pointer to the pair that contains the class pointer and leaderboard ID. (Note: The leaderboard ID is the name of the leaderboard, exactly as you wrote it in the Developer Portal.)
    • A callback function to receive the EOS_Leaderboards_OnQueryLeaderboardRanksCompleteCallbackInfo data structure when the EOS Leaderboards service completes the ranks query.
    EOS_Leaderboards_QueryLeaderboardRanks(LeaderboardsHandle, &QueryRankOptions,     ClassPointerAndLeaderboardId, OnQueryLeaderboardRanksComplete);

Step 3: Implement Your Query Leaderboard Ranks Callback Function

Implement the callback function that executes when the EOS_Leaderboards_QueryLeaderboardRanks() function completes.

Note: In this instance, the EOS API refers to a leaderboard record as a “rank.”

Example:

// LeaderboardsManager.cpp void EOS_CALL LeaderboardsManager::OnQueryLeaderboardRanksComplete(const EOS_Leaderboards_OnQueryLeaderboardRanksCompleteCallbackInfo* Data){    if (Data->ResultCode == EOS_EResult::EOS_Success)    {        // If the code gets here, the leaderboard ranks were queried successfully.         // Retrieve the LeaderboardsManager pointer and the leaderboard ID from the client data passed to the callback function.        auto ClassPointerAndLeaderboardId = static_cast<std::pair<LeaderboardsManager*, const char*>*>(Data->ClientData);        LeaderboardsManager* Self = ClassPointerAndLeaderboardId->first;        const char* LeaderboardId = ClassPointerAndLeaderboardId->second;         // Free the memory for the std::pair now that the data from the std::pair has been copied.        delete ClassPointerAndLeaderboardId;         // Copy all leaderboard records.        Self->CopyLeaderboardRecordsExample(LeaderboardId);    }    else if (EOS_EResult_IsOperationComplete(Data->ResultCode) == EOS_FALSE)    {        // If the code gets here, the operation is retrying and is not yet complete.        return;    }    else    {        // If the code gets here, there was an error.        // Handle this however you need for your game.        std::cerr << "Error querying leaderboard ranks! Error code: " << static_cast<int>(Data->ResultCode)            << " - " << EOS_EResult_ToString(Data->ResultCode) << std::endl;    }}

Step 4: Implement Your Copy Leaderboard Records Function

In your .cpp file, implement your function to copy the leaderboard records currently saved to the cache.

Example:

// LeaderboardsManager.cpp void LeaderboardsManager::CopyLeaderboardRecordsExample(const char* LeaderboardId){    EOS_Leaderboards_GetLeaderboardRecordCountOptions GetRecordCountOptions = {};    GetRecordCountOptions.ApiVersion = EOS_LEADERBOARDS_GETLEADERBOARDRECORDCOUNT_API_LATEST;     // Get the number of leaderboard records for the currently cached leaderboard from the EOS SDK.    uint32_t RecordCount = EOS_Leaderboards_GetLeaderboardRecordCount(        LeaderboardsHandle, &GetRecordCountOptions);     // Loop over each record.    for (uint32_t RecordIndex = 0; RecordIndex < RecordCount; RecordIndex++)    {        EOS_Leaderboards_CopyLeaderboardRecordByIndexOptions CopyRecordOptions = {};        CopyRecordOptions.ApiVersion = EOS_LEADERBOARDS_COPYLEADERBOARDRECORDBYINDEX_API_LATEST;         // The current record index.        CopyRecordOptions.LeaderboardRecordIndex = RecordIndex;         // Create a pointer to store the record info.        EOS_Leaderboards_LeaderboardRecord* Record = nullptr;         // Copy the record data from the cache into the record pointer.        EOS_EResult CopyRecordResult = EOS_Leaderboards_CopyLeaderboardRecordByIndex(            LeaderboardsHandle, &CopyRecordOptions, &Record);         if (CopyRecordResult == EOS_EResult::EOS_Success)        {            // Copy the record data to the map.            LeaderboardRecordCopy& Entry = RetrievedRecords[LeaderboardId][Record->Rank];            Entry.LeaderboardId = LeaderboardId;            Entry.Rank = Record->Rank;            Entry.Score = Record->Score;            Entry.UserDisplayName = Record->UserDisplayName;            Entry.UserId = Record->UserId;             std::cout << "Record copied for leaderboard " << LeaderboardId << " - User: " <<                 Record->UserDisplayName << " Rank: " << Record->Rank << " Score: " << Record->Score << std::endl;             // Release the memory for the EOS API struct when done with it.            EOS_Leaderboards_LeaderboardRecord_Release(Record);        }        else        {            // If the code gets here, there was an error.            // Handle this however you need for your game.            std::cerr << "Error copying leaderboard records! Error code: " << static_cast<int>(CopyRecordResult)                << EOS_EResult_ToString(CopyRecordResult) << std::endl;        }    }}

What's happening in the code?

The following sub-steps are a breakdown of the code example above.

  1. In your .cpp file, implement the function to copy the records for a leaderboard and save those records to a map for retrieval later on. In the example, the copy function is called CopyLeaderboardRecordsExample:

    void LeaderboardsManager::CopyLeaderboardRecordsExample(const char* LeaderboardId){ }

  2. In your copy function, create an instance of the EOS_Leaderboards_CopyLeaderboardRecordByIndexOptions data structure to hold the count options for the leaderboard records. You will use these options to get the total number of leaderboard records that are cached locally. In the example, it’s called GetRecordCountOptions:

    EOS_Leaderboards_GetLeaderboardRecordCountOptions GetRecordCountOptions = {};GetRecordCountOptions.ApiVersion = EOS_LEADERBOARDS_GETLEADERBOARDRECORDCOUNT_API_LATEST;

  3. Call the EOS API EOS_Leaderboards_GetLeaderboardRecordCount function to get the total number of leaderboard records stored in the local cache, and assign the value to a variable to hold the returned count.

    The function takes the following arguments:

    • The Leaderboards Interface handle.
    • A reference to the count options for the leaderboard records.
    uint32_t RecordCount = EOS_Leaderboards_GetLeaderboardRecordCount(    LeaderboardsHandle, &GetRecordCountOptions);

  4. Use the record count to iterate through the list of queried records that you want to copy:

    for (uint32_t RecordIndex = 0; RecordIndex < RecordCount; RecordIndex++){ }

  5. In the for loop, create an instance of the EOS_Leaderboards_CopyLeaderboardRecordByIndexOptions data structure to hold the copy options for the leaderboard records. In the example, it's called CopyRecordOptions:

    EOS_Leaderboards_CopyLeaderboardRecordByIndexOptions CopyRecordOptions = {};CopyRecordOptions.ApiVersion = EOS_LEADERBOARDS_COPYLEADERBOARDRECORDBYINDEX_API_LATEST;CopyRecordOptions.LeaderboardRecordIndex = RecordIndex;

  6. Define a pointer to temporarily store the copied leaderboard record data. In the example, it's called Record:

    EOS_Leaderboards_LeaderboardRecord* Record = nullptr;

  7. Call the EOS API EOS_Leaderboards_CopyLeaderboardRecordByIndex() function to copy the leaderboard records from the local cache.

    The function takes the following arguments:

    • The Leaderboards Interface handle.
    • A reference to the options for copying the leaderboard records.
    • A reference to the leaderboard record pointer to hold the returned record.
    EOS_EResult CopyRecordResult = EOS_Leaderboards_CopyLeaderboardRecordByIndex(    LeaderboardsHandle, &CopyRecordOptions, &Record);

  8. If the EOS_Leaderboards_CopyLeaderboardRecordByIndex() function call is successful, do the following:

    • Find the nested map for the current leaderboard ID within the records map.
    • Retrieve data for the leaderboard record from the record pointer variable that you passed in, and save the leaderboard ID and custom leaderboard record data structure pair to the nested map.
    • Call the EOS_Leaderboards_LeaderboardRecord_Release function on the record pointer afterwards to free its memory.
    if (CopyRecordResult == EOS_EResult::EOS_Success){    // Copy the record data to the map.    LeaderboardRecordCopy& Entry = RetrievedRecords[LeaderboardId][Record->Rank];    Entry.LeaderboardId = LeaderboardId;    Entry.Rank = Record->Rank;    Entry.Score = Record->Score;    Entry.UserDisplayName = Record->UserDisplayName;    Entry.UserId = Record->UserId;     std::cout << "Record copied for leaderboard " << LeaderboardId << " - User: " <<         Record->UserDisplayName << " Rank: " << Record->Rank << " Score: " << Record->Score << std::endl;     // Release the memory for the EOS API struct when done with it.   9. If the EOS_Leaderboards_CopyLeaderboardRecordByIndex() function call is not successful, handle any errors:

    else{    std::cerr << "Error copying leaderboard records! Error code: " << static_cast<int>(CopyRecordResult)        << EOS_EResult_ToString(CopyRecordResult) << std::endl;}

Results

You can access the EOS_Leaderboards_LeaderboardRecord data structure through the leaderboard record pointer you passed into the function call. The EOS_Leaderboards_LeaderboardRecord data structure contains information about the record at the given index in the cached list of leaderboard records.

You can also call the LeaderboardsManager::GetRetrievedLeaderboardRecords() function in your game code to get a read-only reference to the leaderboard records map. Make sure there are no record queries in progress before you call LeaderboardsManager::GetRetrievedLeaderboardRecords(). If there are queries in progress, the leaderboard records you retrieve might not include the latest updates from the active query and will therefore be outdated.
