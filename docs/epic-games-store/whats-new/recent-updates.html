March 26, 2026 Release

Preset Campaigns: Mid-Campaign Discounts

A product can now join a preset campaign partway through the campaign. This change lets you enroll your products in preset campaigns in situations where date restrictions prevent the product joining the campaign at the start. You can enroll your product before the campaign starts, or while the campaign is running.

Note:

  • The product must join the campaign at least seven days before the campaign end date. This seven-day restriction ensures that your product is promoted for a meaningful length of time. It also prevents a short discount period from triggering the standard 30-day cooldown restriction between discounts.
  • If you want your product to be considered for marketing support from Epic Games, you still need to follow the official submission deadlines for the preset campaign. Epic Games communicates these deadlines in the Promotions News & Updates emails and Community Portal threads. If you submit a discount after these deadlines, your product will be included and tagged in the preset campaign's pages, but it might not be eligible for additional marketing support.

Documentation:

  • Discounts, including preset campaigns: Discounts Quick Guide.
  • Enroll a product in a preset campaign: Discounts Quick Guide > Preset Campaigns: Mid-Campaign Discounts.
  • Marketing support from Epic Games: Marketing Overview.

February 19, 2026 Release

Selective Publishing

You can now choose which entities (artifacts and binaries, store settings, offers, pages, and web shop items) to push from the Stage sandbox to Live. This lets you publish specific changes to your product without publishing other entities that are not ready for publication.

Example situation: You update the binaries for an offer, and you make changes to an offer page. All of these changes are in your Stage sandbox. The binaries are ready to publish, but you have not finished your edits to the offer page. You can now publish the binaries without publishing the changes to the offer page.

For more information, see documentation: Get Started > Release Your Product.

Improvements to Scheduled Publishing

To make the publishing workflow more robust, and provide you with more control over the process, we made the following changes:

  • You can only have one scheduled publish at a time for a product.
  • You can view details of which assets and other entities are included in the scheduled publish.
  • At any time, you can cancel a scheduled publish or change the scheduled date and time.
  • If you want to change which artifacts and binaries, settings, offers, and pages are included in the scheduled publish, you must cancel the scheduled publish and then schedule a new publish.
  • To prevent unexpected changes being published in a scheduled publish, if you push any changes to your Stage sandbox when you have a scheduled publish, you can only proceed if you cancel the scheduled publish. If you still want to schedule a publish, you will need to schedule it again, and re-select any entities you want to include in the publish.

For more information, see documentation: Scheduled Publishing.

November 17, 2025 Release

Gifting: Users Can Now Buy Your Offer as a Gift

Epic Games Store users can now buy an offer as a gift, for people on their Epic Games friends list (this means friends they have added in the Social tab of the Epic Online Services Social Overlay). The selected friend gets a notification from the Epic Games Store and they can choose to either accept or reject the gift.

This feature is available automatically for all eligible existing and future offers on the Epic Games Store. All offers are eligible, except for free-of-charge offers, pre-purchase offers, consumable items, and subscriptions such as EA Play.

For more information on this feature, see the Epic Games Store Gifting FAQ for Epic Games Store users: store.epicgames.com/~/gifting.

October 6, 2025 Release

EOS Overlay Update

We have updated the EOS Overlay's Social Overlay feature.

Some products distributed on the Epic Games Store use the EOS Overlay's Social Overlay feature. The EOS Overlay completes authentication and Epic Games Store checkout flows, while the EOS Overlay’s Social Overlay feature displays achievements, shows friends for game invites, and provides crossplay with other storefronts.

What's changed:

  • We've refined, polished, and modernized the Social Overlay’s design, providing users with a streamlined interface that’s easier to navigate across devices and that integrates more seamlessly into your product.

  • We've improved navigation and usability for all input methods, with particular attention to controller use and mobile optimizations. Whether users scroll through their friends list, manage parties, or send invites, the Social Overlay is now more intuitive across all devices.

  • This update brings significant performance improvements to the Social Overlay, especially on Nintendo Switch and mobile (iOS and Android). Users now experience smoother scrolling, more responsive navigation, and have a better overall experience when interacting with a large friends list.

You do not need to make any changes to your product’s code, EOS configuration, Epic Games Store configuration, or any other storefront configuration because of this update; the update applies automatically.

See the new-look Social Overlay in the following documentation: EOS > Social Overlay Tabs

July 17, 2025 Release

Epic Games Store Services: Ecommerce (Ecom Service) Update

If your product accesses the Ecommerce service, it does this through the Epic Online Services (EOS) Ecom service, using either the EOS Ecom Web API or the EOS SDK Ecom Interface.

Two EOS releases on July 17, 2025 have made updates to the EOS Ecom service.

  • EOS Ecom Web API
    Version 4 released on July 17, 2025 (known as “v4”).

    V4 adds server-side validation of durable items in the Epic Games Store.
    If your product uses the Ecom Web API, we recommend you update to v4 as soon as you are able to. (If your product uses the EOS SDK Ecom Interface, see the bullet point below.)

  • EOS SDK Ecom Interface
    EOS SDK version 1.17.1.3-CL43253399 released on July 17, 2025 (known as “v1.17.1.3”) included an update to the EOS SDK Ecom Interface.

    This release adds server-side validation of durable items in the Epic Games Store and updates the EOS SDK Ecom Interface API.
    From this release, you must use the EOS SDK API EOS_Ecom_QueryOwnership function to query ownership of durable items in the Epic Games Store. If you previously used the EOS SDK API EOS_Ecom_QueryEntitlements function to query ownership of durable items, note that the EOS_Ecom_OnQueryEntitlementsCallback callback now returns a EOS_InvalidRequest result code. Use QueryEntitlements to validate consumable purchases only.

Documentation:

  • Epic Games Store Services: Ecom Interface Overview
  • EOS Web API Reference: Ecom Web API

For improved offer management, you now unlink base offers from Edition-type offers in the Dev sandbox. This improvement helps ensure updates that you make to base offers are reflected in their associated editions.

January 24, 2023 Release

New! IARC ratings are now supported for products distributed on the Epic Games Store!

The International Age Rating Coalition (IARC) provides a globally streamlined age classification process for digital products. This system helps to ensure users are given consistent access to established and trusted ratings across platforms.

With this release, partners can now easily obtain IARC ratings through the Epic Games Store publishing tools and display that information on product home pages in the storefront.

More information:

  • IARC ratings on the Epic Games Store documentation: IARC Ratings
  • How to configure ratings for your product (including how to obtain IARC ratings) documentation: Manage Regions and Ratings

June 23, 2022 Release

New! When setting dates for product offers, users are now presented with a guided walkthrough for a simplified, more intuitive experience. The new experience prompts users to answer a series of questions related to their offer to ensure relevant details are captured up front (i.e., Was this offer previously released on PC or Mac?). Additionally, the new experience features an offer date timeline visualization that helps boost understanding and overall accuracy of configurations.

Note: While the guided experience presents information in a new format, the specific details requested have not changed with this update.

  • The guided experience displays by default when configuring offer dates for a new offer. Similarly, the guided experience displays when configuring dates for the first time on an existing offer.
  • When updating previously-configured offer dates, users can select Guided Experience to walk through the steps and complete their desired changes. Alternatively, users can leverage the classic offer date view to complete their desired updates from a single page.

March 9, 2022 Release

Localization Template Updates- FAQ and About Section Contents

  • Before, section contents for sections containing multiple text blocks and images (About and FAQ sections) were combined into a single cell in the localization template, including markdown code for images. Now, content blocks are separated into separate rows in the localization file, and no longer contain information about images.

New! Asynchronous localization file upload

  • Before, users needed to wait for a localization file to upload and save when the upload completed. Now, users can upload a file and come back to see the results in the History section.
  • Users can now see any errors that occurred with an uploaded file on the upload screen.
  • Users can download a previously uploaded file from the file upload screen.

New! Localization file upload history

  • Users can now view a history of uploaded localization files for all files uploaded after this update.
  • Users can view the status of uploaded files in file upload history.
  • Users can view a detailed error report of all issues with previous uploaded files.
  • Users can download previous uploaded localization files from the file history screen.
