Testing

How to test your KWS integration in your test environment.

3 mins to read

You can test your KWS integration end-to-end using the API integration and authentication credentials from the Developer Portal.

Note:

  • We strongly recommend that you test each service thoroughly, following success and failure paths in your test environment, before you set up your production environment.
  • Additionally, although thorough testing in the test environment should suffice, we recommend that you also perform an end-to-end test run of your flow in the production environment and leave ample time to address any issues you may discover at this stage.

To test your KWS integration, you must:

  1. Initiate a KWS verification flow using a test user email address.

  2. When prompted to verify your age, use known test values to test your integration in various scenarios.

See the sections below for guidance on input values.

Note: Rate limits are fixed to ten requests per hour per unique user email address in both the test and production environments.

Restrictions on Test Environment User Email Addresses

The email address that you use for testing must be either:

  • An email address that belongs to a developer or admin within your organization. The developer or admin must have appropriate access to the relevant product — for example, test.user@domain.com.
  • An alias of an email address that belongs to a developer or admin within your organization. The developer or admin must have appropriate access to the relevant product. For example, test.user+1@domain.com.

In the test environment, KWS does not add verified user email addresses to the AgeGraph. For this reason, you will test the pre-verified user flow by adding the ‘+verified’ alias to the test email address. For example, test.user+verified@domain.com. For more information about the pre-verified user flow, see the following documentation:

  • The Age Verification Service Flow > Pre-Verified Users
  • The Parent Verification Service Flow > Pre-Verified Parents or Guardians

Test Social Security Number (SSN) Verification Using Known Values

Each known value tests a different SSN verification scenario. Use the following values to test Social Security Number (SSN) verification:

Last four digits of SSN Scenario
1111 Age Not Verified (Failure)
2222 Individual Deceased (Failure)
3333 Multiple Dates of Birth for Individual (Failure)
4444 Individual Underage (Failure)
5555 General Verification Error (Failure)
(any other value) Verification Success

Test Credit or Debit Card Verification Using Test Card Numbers

KWS uses Stripe to perform credit or debit card verification. For more information, see the following documentation:

  • On how KWS performs credit card verification, see:

    • Age Verification Service Verification Methods > Credit Card
    • Parent Verification Service Verification Methods > Credit Card

  • On how KWS performs debit card verification, see:

    • Age Verification Service Verification Methods > Debit Card
    • Parent Verification Service Verification Methods > Debit Card

To test credit or debit card verification, use the test card numbers provided by Stripe (see Stripe’s developer documentation: docs.stripe.com/testing).

Each test card number tests a different payment scenario. For example, you can test successful payment, payment declined, and expired card scenarios.

To test 3D Secure flows, use Stripe’s 3D Secure test card numbers (see Stripe’s developer documentation: docs.stripe.com/payments/3d-secure#three-ds-cards).

Test CPF Number Using Known Values

KWS uses Serpro to perform CPF number verification. For more information, see the following documentation:

  • Age Verification Service Verification Methods > CPF
  • Parent Verification Service Verification Methods > CPF

Each test value tests a different CPF number verification scenario. Use the following values to test CPF number verification:

Test Value Scenario
40442820135 Pass
40532176871 Fail (Suspended)
05137518743 Fail (Deceased)
20803407009 Fail (Under 16)
30272095079 Fail (Under 18)

Note: You must use November 14, 1970 as the Date of Birth in all test cases.
