Leaderboards Sample

Overview of the Leaderboards Sample.

2 mins to read

The Leaderboards sample demonstrates features that you can add to your game when you implement the EOS Leaderboards Interface. The Leaderboards sample is one of the code samples included in the Epic Online Services (EOS) SDK download. For more information, see the following documentation:

  • For information on the Leaderboards Interface, see: Leaderboards Interface.
  • For guidance on how to access the EOS SDK download, see: Guide: Get Started With Epic Online Services > 1. Set Up Your Account and Download the EOS SDK.

This sample demonstrates the following features that you can add to your game when you implement the EOS Leaderboards Interface:

  • Query leaderboard definitions.
  • Query leaderboard ranking data.
  • Query leaderboard scores of friends.

The sample provides a user interface that you can use to test these leaderboard features and view the player data for your game's leaderboards.

Before You Begin

The sample program uses the Auth Interface to authenticate the local player for demonstration purposes. To use the Auth Interface, you must set up your game (or program in this case) as an EOS Epic Account Services application and assign client credentials to the application. You can use the SDK functionality that the sample program demonstrates with any of the supported identity providers for player authentication. Sign In

From the right-side panel, click one of these options to sign in:

  • Dev Auth: Enter the host port and credentials that you configured for the Developer Authentication Tool (for example, 127.0.0.1:8080 if you set 8080 for the host port) and click LOG IN. See the Developer Authentication Tool documentation for more information on the Developer Authentication Tool.
  • Account Portal: Click LOG IN to sign in through the Account Portal with your Epic Games account credentials or a supported identity provider. See the Identity Provider Management documentation for more information on identity providers.

Leaderboard Definitions

When you start the sample, the EOS SDK retrieves your game's leaderboard definitions you created in the Developer Portal and displays them in a list. The sample displays the definition names in a column on the right, under the header Leaderboard.

Select a Leaderboard

Click a leaderboard definition to select it. The sample highlights the definition:

Global Rankings

After you have selected a leaderboard definition, click SHOW GLOBAL to display the global ranking data for all players who have scores in the leaderboard.

Friend Scores

After you have selected a leaderboard definition, click SHOW FRIENDS to display the scores for all friends who have scores in the leaderboard.

Console Commands

This sample supports the console commands in the Auth and Friends Sample as well as the following additional commands:

Console Command Usage Description
GETDEFS GETDEFS Makes a request to retrieve the leaderboard definitions for this application.
INGEST INGEST <STAT_NAME> <INGEST_AMOUNT> Ingests a stat with the name supplied in STAT_NAME, with an ingest value of INGEST_AMOUNT. See the documentation: Guide: Add Stats to Your Game > 2. Update Values for Stats.
