Guide: Add Achievements to Your Game — 5. Send Notifications When a Player Unlocks an Achievement

Overview of how to add player achievements to your game that you can access through the EOS API.

13 mins to read

Previous section: 4. Unlock Achievements Manually

This section of the guide is available in C++ and C#. The C++ version uses the EOS SDK API in C.

You can add code to your game to notify a player when they unlock an achievement after you have completed the precursor steps listed in Before You Start, below.

To add code to your game to notify a player when they unlock an achievement, you must subscribe to achievement notifications. When you no longer want to send these notifications, you can unsubscribe from them.

The example code snippets in this guide are for guidance only. If you use the snippets, make sure you tailor them to the unique circumstances of your game.

Before You Start

Before you start, you must complete these steps:

  • Integrate the EOS SDK into your code. (Documentation: Guide: Get Started With EOS.)
  • Use the Connect Interface in your code to get the local player’s Product User ID. (Documentation: Guide: Access Game Services With the Connect Interface.)
  • Set up achievements in the Developer Portal. (Section in this guide: 1. Set Up Achievements.)

Note: This guide follows an order. However, only section 1. Set Up Achievements is a pre-requisite to provide achievements in your game. You can follow any section of this guide from section 2 onwards independently of each other and in any order.

Step 1: Modify Your Achievements Manager Class

Modify your achievements manager class .h file to include the declarations for the functions and variables that you need to subscribe to and unsubscribe from achievement unlocked notifications.

Note: The example code below is not the complete code. It includes only the additions that you must make to your achievements manager class .h file. For the complete code, see the complete code snippet after these steps in the Complete Code section.

Example:

AchievementsManager.h 

// AchievementsManager.h...class AchievementsManager{public:...    /** Subscribes your program to notifications from EOS for when achievements are unlocked. */    void SubscribeToAchievementNotificationsExample();     /** Unsubscribes your program from EOS achievement notifications. */    void UnsubscribeFromAchievementNotificationsExample(); private:...    /** Keeps track of the player's notification subscription. */    EOS_NotificationId NotificationId;            /**      * Callback called by the EOS SDK whenever an achievement unlock notification is sent.     *      * @param Data - Information passed to the callback function by the EOS SDK.     */    static void EOS_CALL OnAchievementUnlockNotification(const EOS_Achievements_OnAchievementsUnlockedCallbackV2Info* Data);};

What's happening in the code?

The following sub-steps are a breakdown of the code example above.

  1. In your achievements manager .h file, declare two public functions to handle notifications when a player unlocks an achievement (one to subscribe to the notifications, one to unsubscribe from the notifications). In the example, these functions are called SubscribeToAchievementNotificationsExample() and UnsubscribeFromAchievementNotificationsExample():

    void SubscribeToAchievementNotificationsExample(); void UnsubscribeFromAchievementNotificationsExample();

  2. Declare a private variable to hold the notification ID that will be used to keep track of your notification subscription. To unsubscribe from the achievement unlocked notifications, you must provide the notification ID. In the example, it's called NotificationId:

    EOS_NotificationId NotificationId;

  3. Declare a private static callback function to execute when the player unlocks an achievement. The function definition must match EOS_Achievements_OnAchievementsUnlockedCallbackV2 callback which receives a EOS_Achievements_OnAchievementsUnlockedCallbackV2Info data structure. In the example, it's called OnAchievementUnlockNotification:

    static void EOS_CALL OnAchievementUnlockNotification(const EOS_Achievements_OnAchievementsUnlockedCallbackV2Info* Data);

Step 2: Implement Your Subscribe Function

In your .cpp file, , in your achievements manager class, implement the function to subscribe to achievement notifications.

Example:

void AchievementsManager::SubscribeToAchievementNotificationsExample(){    EOS_Achievements_AddNotifyAchievementsUnlockedV2Options NotificationOptions = {};    NotificationOptions.ApiVersion = EOS_ACHIEVEMENTS_ADDNOTIFYACHIEVEMENTSUNLOCKEDV2_API_LATEST;     // Set up notifications for achievement unlocks. The callback function will be called when an achievement is unlocked.    NotificationId = EOS_Achievements_AddNotifyAchievementsUnlockedV2(AchievementsHandle, &NotificationOptions, nullptr, OnAchievementUnlockNotification);}

What's happening in the code?

The following sub-steps are a breakdown of the code example above.

  1. In your .cpp file, implement the function to subscribe to notifications when the player unlocks an achievement:

    void AchievementsManager::SubscribeToAchievementNotificationsExample(){ }

  2. In your subscribe function, create an instance of the EOS_Achievements_AddNotifyAchievementsUnlockedV2Options data structure to hold the notification options for the achievement unlocked notifications. In the example, it's called NotificationOptions:

    EOS_Achievements_AddNotifyAchievementsUnlockedV2Options NotificationOptions = {};NotificationOptions.ApiVersion = EOS_ACHIEVEMENTS_ADDNOTIFYACHIEVEMENTSUNLOCKEDV2_API_LATEST;

  3. Call the EOS API EOS_Achievements_AddNotifyAchievementsUnlockedV2() function to subscribe to achievement notifications, and assign the returned notification ID to NotificationId. To unsubscribe from these achievement notifications, you must provide this ID (see the Notes section for more information).

    The function takes the following arguments:

    • Achievements Interface handle.
    • A reference to the notification options for the achievement notifications.
    • (Optional) ClientData - an argument must be present but it can be a nullptr.
      In the example, we pass a nullptr because we don't need to pass any additional data to the callback.
    • A callback function to receive the OnAchievementsUnlockedCallbackV2Info data structure when a player unlocks an achievement.
    NotificationId = EOS_Achievements_AddNotifyAchievementsUnlockedV2(AchievementsHandle, &NotificationOptions, nullptr, OnAchievementUnlockNotification);

Step 3: Implement Your Unsubscribe Function

In your .cpp file, in your achievements manager class, implement the function to unsubscribe from achievement notifications.

Example:

void AchievementsManager::UnsubscribeFromAchievementNotificationsExample(){    EOS_Achievements_RemoveNotifyAchievementsUnlocked(AchievementsHandle, NotificationId);}

What's happening in the code?

The following sub-steps are a breakdown of the code example above.

  1. In your achievements manager class, implement the function to unsubscribe from notifications when the player unlocks an achievement:

    void AchievementsManager::UnsubscribeFromAchievementNotificationsExample(){ }

  2. Call the EOS API RemoveNotifyAchievementsUnlocked() function to unsubscribe from achievement unlocked notifications.

    The function takes the following arguments:

    • Achievements Interface handle.
    • The notification ID that you received from the EOS_Achievements_AddNotifyAchievementsUnlockedV2() function.
    EOS_Achievements_RemoveNotifyAchievementsUnlocked(AchievementsHandle, NotificationId);

Step 4: Implement Your Achievement Unlocked Notification Callback Function

In your .cpp file , in your achievements manager class, implement your achievement unlocked notification callback function.

Example:

void EOS_CALL AchievementsManager::OnAchievementUnlockNotification(const EOS_Achievements_OnAchievementsUnlockedCallbackV2Info* Data){    std::cout << "Unlocked Achievement ID: " << Data->AchievementId << " at time " << Data->UnlockTime << std::endl;}

What's happening in the code?

The following sub-steps are a breakdown of the code example above.

  1. Implement the callback function that executes when the player unlocks an achievement. The function definition must match the EOS_Achievements_OnAchievementsUnlockedCallbackV2 callback which receives a EOS_Achievements_OnAchievementsUnlockedCallbackV2Info data structure. In the example, it's called OnAchievementUnlockNotification:

    void EOS_CALL AchievementsManager::OnAchievementUnlockNotification(const EOS_Achievements_OnAchievementsUnlockedCallbackV2Info* Data){ }

    Notes:

    • The EOS SDK calls this callback function asynchronously each time a player unlocks an achievement.
    • The EOS_CALL macro is part of the required definition.

  2. In your callback function, notify the player that they've unlocked an achievement:

    std::cout << "Unlocked Achievement ID: " << Data->AchievementId << " at time " << Data->UnlockTime << std::endl;

Results

After you call the EOS_Achievements_AddNotifyAchievementsUnlockedV2() function, on success, your callback function executes when a player unlocks an achievement.

You can also call the AchievementsManager::UnsubscribeAchievementNotificationsExample() function, and pass in the AchievementsManager::NotificationId, in your game code to unsubscribe from achievement unlocked notifications.

Notes

  • After you subscribe to these notifications, the EOS Achievements service sends the notifications when the player unlocks an achievement through stat progression and when you manually unlock an achievement for them.
  • When you want to stop receiving notifications about unlocked achievements, call the EOS_Achievements_RemoveNotifyAchievementsUnlocked() function and pass the notification ID that you received when you subscribed to notifications.

Tip: Retrieve the achievement ID from the EOS_Achievements_OnAchievementsUnlockedCallbackV2Info data structure parameter of your callback function. Then pass the achievement's ID to the EOS_Achievements_CopyPlayerAchievementByAchievementId() function to copy the player achievement and access more information about it.
