Logging Interface Reference

Reference for the Logging Interface.

2 mins to read

Use the Epic Online Services (EOS) Logging Interface to receive log messages about the EOS SDK services that run in your game (or other software application). These log messages can help you diagnose technical issues, both while you develop your game and after you have shipped it.

See the Logging Interface guide and Logging Interface API documentation for details on how to integrate the EOS Logging service into your game (or software application).

Log Levels

You can set the log level to filter the EOS SDK log messages that you receive (Guide: View EOS SDK Log Messages > Step 4: Set the Log Level). This allows you to specify the type of information that you want to receive and how detailed (verbose) you want that information to be. You can set the log level for an individual log category, or you can set the log level for all log categories at once. You can also disable log messages for log categories, so you only receive the log messages you require. For the full list of log categories, see the API reference documentation: EOS_ELogCategory .

Log levels are ranked in the following order:

Log Level Description Integer
EOS_LOG_VeryVerbose Includes the most information. Set this log level if you need to share logs with support. 600
EOS_LOG_Verbose Includes more detailed information about EOS SDK processes than the Info level. 500
EOS_LOG_Info Includes general information about EOS SDK processes. This is the default log level for most categories. 400
EOS_LOG_Warning Includes information that might be indicative of issues but it is not an immediate cause for alarm. 300
EOS_LOG_Error Includes errors that prevent proper functionality of the EOS SDK. 200
EOS_LOG_Fatal Includes errors that prevent the EOS SDK from running. 100
EOS_LOG_Off Set the level to this to hide all logs for the specified category. 0

Your registered callback can only receive log messages for a category that match the set log level for that category and lower. For example, if your log level for a category is set to EOS_LOG_Warning, then your registered callback function will receive log messages for that category that have the log level EOS_LOG_Warning, EOS_LOG_Error, or EOS_LOG_Fatal.

Note: Do not set the log level to EOS_LOG_VeryVerbose in the shipped version of your game. Instead, set the log level to EOS_LOG_Info. We recommend that you use a command line parameter to control the log level when you start the game. This approach lets you change your log level to EOS_LOG_VeryVerbose in the shipped version of your game if you need to.

Note: The default log level for most log categories is EOS_LOG_Info.
