EOS SDK for iOS

How to implement EOS SDK in an iOS project using Xcode.

5 mins to read

Supported iOS Release Versions

The table below lists the iOS release version which each EOS SDK release version supports:

EOS SDK Release Version iOS Release Version
EOS SDK 1.17.0-CL43712763 - 1.19.0.7-CL52449437 supports iOS 12 and 18
EOS SDK 1.16.4-CL36651368 - 1.17.0-CL39599718 supports iOS 12 or higher
EOS SDK 1.10.2 - 1.16.3-CL35276460 supports iOS 11 or higher

Tip: You can call the EOS_GetVersion function to get the EOS SDK version and the version of the platform that your game is compiled against.

Set up the EOS SDK for iOS

To use Epic Online Services (EOS) SDK in your project, you must embed it in your project and link to it within your project. The EOS SDK download includes both .framework and .xcframework bundles in the /SDK/Bin/IOS directory. XCFrameworks contain multiple frameworks for different platforms and architectures. These instructions assume that you have an existing iOS project in Xcode, and they provide steps on how to embed the EOS SDK as .framework.

Before you implement the SDK with iOS, see the documentation on general guidelines and references for information on platform implementation.

Notes

  • The EOS SDK is not thread safe. You must make all calls to EOS from the same thread. For more information, see the following documentation: Conventions and Limitations > Thread Safety.
  • You must call the EOS_Platform_SetApplicationStatus function when you place your application into the background or foreground.

Objective-C and Swift iOS Projects

The EOS SDK for iOS is written in C. If your game's code is written in Objective-C (ObjC) or Swift, we recommend writing an ObjC wrapper around the EOS SDK, as the EOS SDK is not a Swift module. The Login Sample, included in the EOS SDK download for iOS, uses an ObjC wrapper. See the Login Sample's /Login/EOS/EOSWrapper.h file for an example implementation. See Using the iOS Samples documentation for more information on using the Login Sample app.

1. Download the EOS SDK Framework for iOS

Follow these steps to download the EOS SDK framework for iOS (the framework):

  1. Sign in to the Developer Portal at (dev.epicgames.com/portal).
  2. In the left navigation, click Dashboard if it isn't already selected.
  3. On the Dashboard page, under the Your products heading, click Downloads & Release notes.
  4. Select the EOS SDK tab.
  5. For SDK Type, select SDK for iOS.
  6. For SDK Version, select the version with (Latest) next to the version number.
  7. Click Download EOS SDK.

2. Add the EOS SDK Framework to Your Project

After you have downloaded the EOS SDK framework, you must add it to your project. The example below references a sample game project called EOSGame. If you know how to link and embed an iOS framework, you can skip to the Framework Dependencies section below.

Follow these steps to add the EOS SDK framework to your project:

  1. Go to the ./SDK/Bin/IOS/EOSSDK.framework folder inside the EOS SDK zip you downloaded.

  2. Copy the EOSSDK.framework folder into your project's root folder.

  3. Open your project in Xcode.

  4. In Xcode, select your project in the left column to open its properties.

  5. Select your target in the middle column, under the TARGETS section.

  6. Select the General tab and scroll to the Frameworks, Libraries and Embedded Content section at the end.

  7. Drag the EOSSDK.framework folder from your project folder in Finder and drop it into the Frameworks, Libraries and Embedded Content section in Xcode.

  8. Click the Build Phases tab, and configure these settings for EOSSDK.framework:

    • From the Link Binary With Libraries > Status drop-down menu, select Required.
    • Check Embed Frameworks > Code Sign On Copy.

3. Add Framework Dependencies

The EOS SDK requires the AuthenticationServices.framework to support the following features for iOS:

  • iOS 12+: Login flows.
  • iOS 13+: Sign in with Apple login.

Follow these steps to add the AuthenticationServices dependency to your project:

  1. Click the + (the plus icon) at the end of the Frameworks, Libraries and Embedded Content section.

  2. Select AuthenticationServices.framework from the list, and click Add to add it to your project.

  3. You can now see the dependency listed in the Frameworks, Libraries, and Embedded Content section, along with the EOSSDK.framework. Change the Embed option for the AuthenticationServices framework to Do Not Embed.

4. Initialize the EOS SDK

You must initialize the EOS SDK before you can use the EOS SDK interfaces. For more information on how to initialize the EOS SDK, see the following documentation: Guide: Get Started With EOS > 3. Set Up the EOS SDK.

5. Build and Run the Application

Before you implement authentication in your application in the next step, build and run the application on your device to make sure everything runs properly.

Note: Simulator support in Xcode is currently not available to test the EOS SDK. To run the EOS SDK framework in your project, you must have a physical, connected device with iOS 12 or higher.

6. Specify the Window for Sign-In

To allow players to sign-in, you must specify which UI window you want to display the sign-in view. The steps below demonstrate how to do this using Objective-C. For an example written in Swift, see the iOS sample in the EOS SDK for iOS Samples documentation.

To specify the UI window to use, follow these steps:

  1. Implement a NSObject that returns the UIWindow that you want to display the sign-in view.
  1. Initialize and retain the NSObject that you implemented and pass it to the EOS_Auth_LoginOptions struct.

Note: Below is an example implementation. The additional credentials options, credentials, and login options depend on the requirements of your game. For more information, see the documentation: Guide: Access Epic Account Services With the Auth Interface.
  1. Call EOS_Auth_login() and pass the EOS_Auth_LoginOptions that you configured in step 2. For more information on how to use the Auth Interface, see the Auth Interface documentation.

7. Build and Run the Application

After you've implemented authentication in your application, build your application again to make sure it runs properly.
