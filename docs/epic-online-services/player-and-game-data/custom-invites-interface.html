Custom Invites Interface

Manage your game's player-invitation system through the EOS Overlay's Social Overlay UI.

3 mins to read

Type of service : This interface is an EOS Game Service — authenticate players with the Connect Interface.

Note: The Custom Invites Interface requires SDK 1.14.1 or higher.

If your game has its own player-invitation system, you can use the Custom Invites Interface to manage this through the Social Overlay UI (the Social Overlay is part of the EOS Overlay).

The Custom Invites Interface is an EOS Game Services interface that you use with Social Overlay. Note that the Social Overlay is a feature of the Accounts and Social group of services, which are EOS Epic Account Services and use the Auth Interface for player authentication, but the Custom Invites Interface is an EOS Game Service and uses the Connect Interface for player authentication.

Custom Invites and the Social Overlay

If you require players to send and receive invites through the Social Overlay’s UI using your game’s own player-invitation system, you must use the Custom Invites Interface. For more information on the Social Overlay, see the Social Overlay documentation.

Custom Invites and the Epic Games Launcher

EOS transports and delivers custom invites to the Epic Games Store and the Epic Games Launcher in the same way it transports and delivers session and lobby invites. When the Store or Launcher receives a custom invite, EOS prompts the player with a UI notification indicating the invite’s sender and the game they are sending it from. If the player accepts the invitation, the relevant game starts.

Send a Custom Invite

Prepare Custom Invite Payload

A Custom Invite Payload is an FString that may be no longer than EOS_CUSTOMINVITES_MAX_PAYLOAD_LENGTH characters (currently 500). Its contents are opaque to the SDK and are delivered as-is to the receiving user.

Set Custom Invite Payload

Before attempting to send a Custom Invite or allow the local player to use the Social Overlay to send a Custom Invite, use the EOS_CustomInvites_SetCustomInvite to set the Custom Invite Payload. All calls to EOS_CustomInvites_SendCustomInvite and all Invitations initiated by the player via the Invite to game button in the Social Overlay will use this payload.

Send Custom Invite via EOSSDK

Once a payload has been set, you can use EOS_CustomInvites_SendCustomInvite to send an invite to the specified user or group of users.

Send Custom Invite via Social Overlay

Whenever a Custom Invite Payload has been set via EOS_CustomInvites_SetCustomInvite , the Social Overlay will allow the local player to use the Invite to game button to send an invite with the currently set Custom Invite Payload to their friends.

For more information on the Social Overlay, see the Social Overlay and SDK integration documentation.

Custom Invite Callback Functions

You can register to these functions to receive notifications for custom invite events. This lets you detect and process custom invites, and create custom UI to respond to them. You should call these functions prior to login, as the act of logging in and initializing can discover pending custom invites that generate immediate notifications. The table below lists the available callback functions that you can register to for custom invite notifications:

Notification Callback Function
Invite Received Call EOS_CustomInvites_AddNotifyCustomInviteReceived to receive notifications when any logged in local user receives a custom invite. You must call EOS_CustomInvites_RemoveNotifyCustomInviteReceived to remove the notification.
Invited Accepted Call EOS_CustomInvites_AddNotifyCustomInviteAccepted to receive notifications when any logged in local user accepts a custom invite. You must call EOS_CustomInvites_RemoveNotifyCustomInviteAccepted to remove the notification.
Invite Rejected Call EOS_CustomInvites_AddNotifyCustomInviteRejected to receive notifications when any logged in local user rejects a custom invite. You must call EOS_CustomInvites_RemoveNotifyCustomInviteRejected to remove the notification.

After you've handled the custom invite (accepted or rejected by the user), you must call EOS_CustomInvites_FinalizeInvite to remove it from both the internal SDK and the Social Overlay's awareness.

Policy Configuration

You must create a custom client policy and enable the Notification service with the userRequired checkbox selected and allow:

  • sendCustomInviteToAnyUser : Allows the user to send a custom invite to any user.
