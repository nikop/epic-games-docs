Parent Verification Service API Reference

An overview of the Parent Verification Service API.

Under 1 min to read

The Parent Verification (PV) Service uses a REST API over HTTPS. More information: Parent Verification Service API Specification.

  • All Parent Verification Service API requests must include a user-agent header containing a non-empty string identifying their client or HTTP library. Failure to do so results in a 403 Request blocked response code.
  • Rate limiting is fixed to ten requests per hour per unique user email address in both the test and production environments.
