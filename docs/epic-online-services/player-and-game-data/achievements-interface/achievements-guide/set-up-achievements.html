Guide: Add Achievements to Your Game — 1. Set Up Achievements

Overview of how to add player achievements to your game that you can access through the EOS API.

4 mins to read

To provide achievements in your game, you must first set up EOS achievements in the Developer Portal.

If you publish your game on the Epic Games Store, you can enhance your game's user experience further with Epic Games Store achievements. Epic Games Store achievements extend EOS achievements by rewarding your users with experience points (XP) and other benefits in their Epic Games accounts. This guide shows how to set up and manage EOS Achievements only. For more information on Epic Games Store achievements, see the documentation: Epic Games Store Achievements > Achievements Overview.

Before You Start

Before you start, you must complete these steps:

  • Integrate the EOS SDK into your code. (Documentation: Guide: Get Started With EOS.)
  • Set up stats in the Developer Portal. (Documentation: Guide: Add Stats to Your Game > 1. Set Up Stats.)

Note: We recommend that you set up the Logging Interface to receive useful messages that can help you diagnose technical issues with the EOS SDK. (Documentation: Logging Interface.)

Note: This guide follows an order. However, only section 1. Set Up Achievements is a pre-requisite to provide achievements in your game. You can follow any section of this guide from section 2 onwards independently of each other and in any order.

Configure Your Game in the Developer Portal

Complete the following steps in the Developer Portal to set up the available EOS achievements for your game:

  • Step 1: Configure Your Game's Client Policy.
  • Step 2: Configure Your Game's EOS Achievements.

Step 1: Configure Your Game's Client Policy

Note: This guide uses a preset client policy type for simplicity. For a game in a production environment, we recommend that you create your own custom client policy to ensure your game is secure. For more information on client policies, see the following documentation: Guide: Manage Your Clients and Client Policies.

You configure your game's client policy in the Developer Portal, on the Product Settings page's Clients tab. To do this, follow the steps below. (Note that in the Developer Portal, your game is usually known as a "product".)

To go to the Clients tab:

A. Go to your game's product page in the Developer Portal.

  • To do this:
    a. Sign in to the Developer Portal at (dev.epicgames.com/portal).
    b. In the left navigation, under Your Products, click the name of your game (or software application).
    • Note: You might have to click Back to organization before you can do this.

B. In the left navigation, click Product Settings.
C. From the default tab (SDK Download & Credentials), click Clients.

Note that the Clients tab might show new agreements to accept.

On the Clients tab:

A. Scroll down to the Client policies section. (This is below the Clients section.)
B. Either create a new client policy or enable the Achievements feature for an existing client policy.

  • To create a new client policy:
    a. Click Add new client policy. (Do not click “Add new client”.)
    b. For Client policy name, enter a name of your choice.
    c. For Client policy type, select GameClient w/ Unlock Achievements.
    d. Leave the default options and click Add new client policy. The preset client policy enables the Achievements feature by default.
  • To enable the Achievements feature for an existing client policy:
    a. Locate the client policy and click the three dots (...) next to it, then select Edit.
    b. In the Edit client policy pane, scroll down to Features and use the Achievements toggle to enable the achievements feature.

Step 2: Configure Your Game's EOS Achievements

These steps demonstrate how to configure your game's achievements individually in the Developer Portal.

Note: You can also use the Bulk Importer and Exporter Tool to set up multiple achievements in one action. For more information, see the Tool: Bulk Import / Export documentation.

Players can unlock achievements through stat progression, or you can manually unlock an achievement with the EOS SDK API. This guide shows how to create achievements that you can manually unlock. To create an achievement that players automatically unlock through stat progression, select the stat(s) when you create the achievement.

You configure your game's achievements individually in the Developer Portal on the Achievements page. To create an achievement that you manually unlock, follow the steps below.

To go to the Achievements page:

A. Go to your game's product page in the Developer Portal.

  • To do this:
    a. Sign in to the Developer Portal at (dev.epicgames.com/portal).
    b. In the left navigation, under Your products, click the name of your game.
    • Note: You might have to click Back to organization before you can do this.

B. In the left navigation, click Epic Online Services.
C. In the Player & Game Data section, click Achievements.

On the Achievements page:

A. From the Deployment dropdown, select a deployment that is attached to the same sandbox where you created your stats. Stats and achievements you create are shared for all deployments in a sandbox.
B. Click Create Achievement.
C. Don't select a stat, and click Next.
D. In the Achievement ID field, enter a name for the new achievement. Choose a name that is meaningful to you, because you will refer to this achievement ID in your game code.

  • Note: The achievement ID can't contain a percent (%) symbol.

E. Select the Locale for the language that the achievement is written in.
F. Follow the rest of the onscreen instructions to create the achievement.

Note: Image files that you upload for locked and unlocked icons must meet these requirements:

  • Smaller than 1024 x 1024 pixels.
    • We recommend that you make your icons 192 x 192 pixels.
  • JPG, PNG, BMP, or non-animated GIF format.
  • 1.02 MB or less.
  • Have a unique file name.
    • If you upload an image with the same file name as an existing image, the new image overwrites the old one.

Repeat these steps to create as many achievements as your game requires.

Results

You can see the achievements on your game's Achievements page in the Developer Portal.
