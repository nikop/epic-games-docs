Guide: Add Achievements to Your Game — 3. Retrieve Achievement Progress

Overview of how to add player achievements to your game that you can access through the EOS API.

31 mins to read

Previous section: 2. Retrieve Achievements for Your Game

This section of the guide is available in C++ and C#. The C++ version uses the EOS SDK API in C.

You can add code to your game to retrieve a player's achievements after you have completed the precursor steps listed in Before You Start, below.

To add code to your game to retrieve a player's achievements, you query the achievements to save them to the local cache. Then you can copy the cached achievements and access the achievement data. For example, you can query a player's achievements and then display them to the player in a personal dashboard.

You can either copy the cached achievements by achievement ID (for example, "Radioactive Hero") or copy them all. This guide shows how to copy all achievements for a player. For information on how to copy a player's achievements individually by achievement ID, see the EOS_Achievements_CopyPlayerAchievementById function API reference documentation.

Note: To access all the available data for a player achievement, you must query the achievement definitions for your game before you retrieve the player's achievements ( Section in this guide: 2. Retrieve the Achievements for Your Game).

If you retrieve a player's achievements without first retrieving all the available achievements for your game, you can't access the following information for the player's achievements:

  • Achievements marked as hidden that are locked.
  • DisplayName. This will be null.
  • Description. This will be null.
  • IconURL. This will be null.
  • FlavorText. This will be null.
  • StatInfo. This will be null if the player has not ingested stat values. (Documentation: Stats Guide > 2. Update Values For Stats.)

The example code snippets in this guide are for guidance only. If you use the snippets, make sure you tailor them to the unique circumstances of your game.

Before You Start

Before you start, you must complete these steps:

  • Integrate the EOS SDK into your code. (Documentation: Guide: Get Started With EOS.)
  • Use the Connect Interface in your code to get the local player's Product User ID. (Documentation: Guide: Access EOS Game Services With the Connect Interface.)
  • Set up achievements in the Developer Portal. (Section in this guide: 1. Set Up Achievements.)

Note: This guide follows an order. However, only section 1. Set Up Achievements is a pre-requisite to provide achievements in your game. You can follow any section of this guide from section 2 onwards independently of each other and in any order.

Retrieve a Player's Achievements

Complete the following steps to retrieve a player's achievements and save them so you can look them up later:

  • Step 1: Modify Your Achievements Manager Class
  • Step 2: Implement Your Query Achievements Function
  • Step 3: Implement Your Query Player Achievements Callback Function
  • Step 4: Implement Your Copy Player Achievements Function

Step 1: Modify Your Achievements Manager Class

Modify your achievements manager class to include the variables that you need to retrieve achievements.

Note: The example code below is not the complete code. It includes only the additions that you must make to your achievements manager class. For the complete code, see the complete code snippet after these steps in the Complete Code section.

What's happening in the code?

The following sub-steps are a breakdown of the code example above.

  1. Create a data structure to hold the copied player achievement data. This data structure can contain whichever achievement data you need to copy for your game.

    struct PlayerAchievementCopy{    std::string AchievementId;    std::string DisplayName;    std::string Description;    double Progress;};

  2. In your achievements manager.h file, declare a public function to get read-only access to the player achievements map. (Note: The map itself is declared as a private variable and described in more detail in a step below.) In the example, it's called GetRetrievedAchievements:

    const std::map<std::string, PlayerAchievementCopy>& GetRetrievedAchievements() const { return RetrievedAchievements; }

  3. Declare a public function to query the player's achievements. In the example, it's called RetrievePlayerAchievementsExample:

    void RetrievePlayerAchievementsExample();

  4. Declare a private map to hold achievement ID (string) and custom player achievement data structure (PlayerAchievementCopy) pairs for the player achievements that you want to copy for the player. In the example, the map is called RetrievedAchievements:

    std::map<std::string, PlayerAchievementCopy> RetrievedAchievements;

    Note: When you query achievements for a player, the EOS SDK saves those achievements to the local cache. So, as you make more queries, the SDK fills the local cache with achievements for various players.

    Tip: This example stores the achievement ID and its associated value in a map. This makes it easier to look up an achievement and retrieve its value when you need it.

  5. Declare a private callback function to execute after the query completes. The function definition must match the EOS API EOS_Achievements_OnQueryPlayerAchievementsCompleteCallback callback. In the example, it's called OnQueryPlayerAchievementsComplete:

    static void EOS_CALL OnQueryPlayerAchievementsComplete(const EOS_Achievements_OnQueryPlayerAchievementsCompleteCallbackInfo* Data);

  6. Declare a private function to copy the player's queried achievements from the local cache. In the example, it's called CopyPlayerAchievementsExample:

    void CopyPlayerAchievementsExample();

Step 2: Implement Your Query Achievements Function

In your .cpp file, in your achievements manager class, implement the query function to retrieve the player's achievements.

Example:

void AchievementsManager::RetrievePlayerAchievementsExample(){    EOS_Achievements_QueryPlayerAchievementsOptions QueryAchievementOptions = {};    QueryAchievementOptions.ApiVersion = EOS_ACHIEVEMENTS_QUERYPLAYERACHIEVEMENTS_API_LATEST;     // The Product User ID of the local player requesting the query.    QueryAchievementOptions.LocalUserId = LocalProductUserId;     // The Product User ID of the player whose achievements are being queried (the local player in this example).    QueryAchievementOptions.TargetUserId = LocalProductUserId;     // Call the EOS SDK to query player achievements.    // The callback function will be called when the query is complete.    EOS_Achievements_QueryPlayerAchievements(AchievementsHandle, &QueryAchievementOptions, this, OnQueryPlayerAchievementsComplete);}

Note: Your client policy configuration determines which player you can query achievements for (QueryPlayerAchievementsOptions.TargetUserId). See this guide's section 1. Set Up Achievements > Step 1: Configure Your Game's Client Policy for more information.

Step 4: Implement Your Copy Player Achievements Function

In your .cpp file, implement your copy player achievements function.

Example:

// AchievementsManager.cpp void AchievementsManager::CopyPlayerAchievementsExample(){    EOS_Achievements_GetPlayerAchievementCountOptions GetAchievementCountOptions = {};    GetAchievementCountOptions.ApiVersion = EOS_ACHIEVEMENTS_GETPLAYERACHIEVEMENTCOUNT_API_LATEST;     // The Product User ID of the player whose achievements are being counted (the local user in this example).    GetAchievementCountOptions.UserId = LocalProductUserId;     // Get the number of player achievements from the EOS SDK.    uint32_t AchievementCount = EOS_Achievements_GetPlayerAchievementCount(AchievementsHandle, &GetAchievementCountOptions);     // Loop over each achievement.    for (uint32_t AchievementIndex = 0; AchievementIndex < AchievementCount; AchievementIndex++)    {        EOS_Achievements_CopyPlayerAchievementByIndexOptions CopyAchievementByIndexOptions = {};        CopyAchievementByIndexOptions.ApiVersion = EOS_ACHIEVEMENTS_COPYPLAYERACHIEVEMENTBYINDEX_API_LATEST;         // The Product User ID of the local player requesting the copy        CopyAchievementByIndexOptions.LocalUserId = LocalProductUserId;         // The Product User ID of the player whose achievement is being copied (the local player in this example).        CopyAchievementByIndexOptions.TargetUserId = LocalProductUserId;         // The index of the achievement to be copied.        CopyAchievementByIndexOptions.AchievementIndex = AchievementIndex;         //Create a pointer to store the player achievement info. EOS_Achievements_PlayerAchievement_Release(Achievement);        }        else        {            // If the code gets here, there was an error.            // Handle this however you need for your game.            std::cerr << "Error copying player achievements! What's happening in the code?

The following sub-steps are a breakdown of the code example above.

  1. In your .cpp file, implement the function to copy the player's achievements and save them to a map for retrieval later on. In the example, it's called CopyPlayerAchievementsExample:

    void AchievementsManager::CopyPlayerAchievementsExample(){ }

  2. In your copy function, create an instance of the EOS_Achievements_GetPlayerAchievementCountOptions data structure to hold the count options for your achievements. You will use these options to get the total number of achievements that are cached locally. In the example, it's called GetAchievementCountOptions:

    EOS_Achievements_GetPlayerAchievementCountOptions GetAchievementCountOptions = {};GetAchievementCountOptions.ApiVersion = EOS_ACHIEVEMENTS_GETPLAYERACHIEVEMENTCOUNT_API_LATEST;GetAchievementCountOptions.UserId = LocalProductUserId;

  3. Call the EOS API EOS_Achievements_GetPlayerAchievementCount() function to get the number of achievements stored in the local cache, and assign the value to a variable to hold the returned count.

    The function takes the following arguments:

    • Achievements Interface handle.
    • A reference to the count options for the achievements.
    uint32_t AchievementCount = EOS_Achievements_GetPlayerAchievementCount(AchievementsHandle, &GetAchievementCountOptions);

  4. Use the achievement count to iterate through the list of queried achievements that you want to copy:

    for (uint32_t AchievementIndex = 0; AchievementIndex < AchievementCount; AchievementIndex++){ }

  5. In the for loop, create an instance of the EOS_Achievements_CopyPlayerAchievementByIndexOptions data structure to hold the copy options for your achievements. In the example, it's called CopyAchievementByIndexOptions:

    EOS_Achievements_CopyPlayerAchievementByIndexOptions CopyAchievementByIndexOptions = {};CopyAchievementByIndexOptions.ApiVersion = EOS_ACHIEVEMENTS_COPYPLAYERACHIEVEMENTBYINDEX_API_LATEST;CopyAchievementByIndexOptions.LocalUserId = LocalProductUserId;CopyAchievementByIndexOptions.TargetUserId = LocalProductUserId;CopyAchievementByIndexOptions.AchievementIndex = AchievementIndex;

  6. Define a pointer to temporarily store the copied player achievement data. In the example, it's called Achievement:

    EOS_Achievements_PlayerAchievement* Achievement = nullptr;

  7. Call the EOS API EOS_Achievements_CopyPlayerAchievementByIndex() function to copy the player's achievements from the local cache.

    The function takes the following arguments:

    • Achievements Interface handle.
    • A reference to the copy options for the achievements.
    • A reference to the achievement pointer to hold the returned achievement data.
    EOS_EResult CopyAchievementByIndexResult = EOS_Achievements_CopyPlayerAchievementByIndex(AchievementsHandle, &CopyAchievementByIndexOptions, &Achievement);

  8. If the EOS_Achievements_CopyPlayerAchievementByIndex() function call is successful, do the following:

    • Retrieve data for the achievement from the achievement pointer variable that you passed in.
    • Copy the achievement ID and custom player achievement data structure pair to the achievements map.
    • Call the EOS_Achievements_PlayerAchievement_Release function on the achievement pointer afterwards to free its memory.
    if (CopyAchievementByIndexResult == EOS_EResult::EOS_Success){    // Copy the achievement data to the map.    PlayerAchievementCopy& Entry = RetrievedAchievements[Achievement->AchievementId];    Entry.AchievementId = Achievement->AchievementId;    Entry.Description = Achievement->Description;    Entry.DisplayName = Achievement->DisplayName;    Entry.Progress = Achievement->Progress;     std::cout << "Achievement copied: " << Entry.DisplayName << " - Progress: " << Entry.Progress << std::endl;     // Release the memory for the EOS API data structure when done with it.    EOS_Achievements_PlayerAchievement_Release(Achievement);}

  9. If the EOS_Achievements_CopyPlayerAchievementByIndex() function call is not successful, handle any errors:

    else{    std::cerr << "Error copying player achievements! Error code: " << static_cast<int>(CopyAchievementByIndexResult) << EOS_EResult_ToString(CopyAchievementByIndexResult) << std::endl;}

Results

After you call the EOS_Achievements_QueryPlayerAchievements() function, on success you can access the EOS_Achievements_PlayerAchievement data structure through the achievement pointer that you passed in the EOS_Achievements_QueryPlayerAchievements() function call.

For example, you can retrieve a player's achievement progress for an achievement through the EOS_Achievements_PlayerAchievement data structure's Progress property. This provides the progress of the achievement as a percentage. You can retrieve the threshold for each stat (the stat value that the player must meet for the achievement) and the player's progress towards meeting those thresholds through the EOS_Achievements_PlayerAchievement data structure's StatInfo property. For more information on how the EOS SDK calculates the progress percentage, see the Notes section below.

You can access the achievements in your game code through the AchievementsManager::GetRetrievedAchievements() function in the example code. Make sure there are no achievement queries in progress before you call GetRetrievedAchievements. If there are queries in progress, the achievements you retrieve might not include the latest updates from the active query and will therefore be outdated.

How The EOS SDK Calculates Achievement Progress Percentage

Each stat threshold that a player must meet to unlock an achievement is worth the same progress percentage for the achievement. For example, if a "Radioactive Hero" achievement has two stat thresholds that the player must meet (100 ENEMIES_DEFEATED and 50 CARS_SMASHED ), each stat threshold is worth 50% of the progress towards unlocking the achievement. If the player defeats 100 enemies and smashes 0 cars, their overall progress towards unlocking the "Radioactive Hero" achievement is 50%.
