Epic Games Store Introduction

Introduction to distributing products on the Epic Games Store.

Under 1 min to read

The Epic Games Store is a storefront for players to buy and download games and other software applications that run on PC: Windows or macOS. You configure your storefront presence and distribute your product on the Epic Games Store using the Epic Games Store publishing tools.

Epic Games also provides Epic Game Store Services. Use these to integrate online services functionality into your product, including e-commerce, cloud saves, Epic Games Launcher invites, mods, and Epic Games Store achievements. (Documentation: Epic Games Store Services.)
