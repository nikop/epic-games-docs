Guide: Get Started With Epic Online Services — 2. Create and Configure Your Visual Studio Project

Step-by-step guide on how to create and configure a Visual Studio project, based on CMake, to use EOS.

9 mins to read

Previous section: 1. Set Up Your Account and Download the SDK

Note: This section of the guide is for Windows only.

Visual Studio provides a robust interface that you can use to edit and run your code. Although it is not required, we recommend that you use Visual Studio to integrate the EOS SDK with your game.

This guide shows how to use CMake to set up a project in Visual Studio for Windows. CMake is a cross-platform build system generator that instructs Visual Studio (and other integrated development environments) how to compile, link, and run your project. For more information on CMake, see CMake’s documentation at cmake.org/cmake/~/latest.

Note: CMake is included with Visual Studio when you install the Desktop development with C++ workload.

Unreal Engine, Unity, macOS, Linux

Visual Studio Version
This guide was last tested with Visual Studio Community 2026 version 18.3.3.

You can still follow these steps if you are using a later release version of Visual Studio or a different type of Visual Studio, such as Professional or Enterprise. To ensure the steps work, make sure you are using Visual Studio with the Desktop development with C++ workload.

You cannot follow this guide if you are using Visual Studio Code, which is a different tool from Visual Studio.

Before You Start

Before following this section of the guide, complete the following steps:

  • Set Up Your Account and Download the SDK
  • Download and install Visual Studio from visualstudio.microsoft.com. Be sure to download Visual Studio and not Visual Studio Code, which is a different tool.
    • Note: You must install the the Desktop development with C++ workload as part of your installation. Leave the default opti ons selected.

Create and Configure Your Visual Studio Project

Complete the following steps to set up your Visual Studio project with CMake and configure it to use the EOS SDK:

  • Step A: Create Your Project Structure
  • Step B: Open and Build the Project in Visual Studio

Step A: Create Your Project Structure

  1. Create a new directory called “ExampleEOSGame” to hold your project in the location of your choice.
    Visual Studio uses the name of the directory as the project’s name.

  2. From your EOS SDK download directory, copy the SDK directory into the ExampleEOSGame directory you just created.

  3. In the ExampleEOSGame directory, create a file called CMakeLists.txt and copy the following configuration to it:

    cmake_minimum_required(VERSION 3.15) project(EOSHowTosCpp) set(CMAKE_CXX_STANDARD 17) # Define pathsset(EOS_SDK_PATH "${CMAKE_SOURCE_DIR}/SDK")set(EOS_DLL "${EOS_SDK_PATH}/Bin/EOSSDK-Win64-Shipping.dll")set(EOS_LIB "${EOS_SDK_PATH}/Lib/EOSSDK-Win64-Shipping.lib") # Grab source filesfile(GLOB_RECURSE SOURCES "Source/*.cpp") # Add main executableadd_executable(ExampleEOSGame ${SOURCES}) # Add Include pathtarget_include_directories(ExampleEOSGame PRIVATE "${EOS_SDK_PATH}/Include") # Link librarytarget_link_libraries(ExampleEOSGame PRIVATE "${EOS_LIB}") # Copy EOS DLL to build outputadd_custom_command(TARGET ExampleEOSGame POST_BUILD   COMMAND ${CMAKE_COMMAND} -E copy_if_different      "${EOS_DLL}"      $<TARGET_FILE_DIR:ExampleEOSGame>)

    This file instructs CMake how to build the Visual Studio project. Visual Studio uses these instructions to configure the project settings.

  4. Save the file.

  5. In the ExampleEOSGame directory, create a Source subdirectory.

  6. In the ExampleEOSGame/Source subdirectory, create a C++ file called EOSGame.cpp.

    Tip: If you use File Explorer to create the C++ file, you can only edit the extension if file extensions are visible. To make file extensions visible, in the top navigation of the File Explorer, click View > Show > File name extensions. This is helpful whenever you need to create files with extensions other than .txt.

You now have the following directory structure:

ExampleEOSGame/  ├──CMakeLists.txt  ├──SDK/  ├──Source/        └──EOSGame.cpp

Step B: Open and Build the Project in Visual Studio

  1. Open Visual Studio.

  2. Click Open a local folder.

  3. Navigate to the project directory ExampleEOSGame that you created in Step A and click Select Folder.
    Visual Studio detects the CMakeLists.txt file in your project directory and imports the configuration settings. After Visual Studio opens the project, the Output window in the bottom pane displays the CMake build output. The output ends with the message CMake generation finished.

  4. In the top navigation, confirm that the green play button displays the executable name ExampleEOSGame.exe next to it.
    You defined this executable name in CMakeLists.txt. Don’t click the play button yet: your project still needs the main function to run.
    Note: If you do not see the CMake output, or if the executable name ExampleEOSGame.exe is not beside the green play button, there was a problem with the CMake import or generation. Close the Visual Studio project and verify that the filename, extension, and contents of CMakeLists.txt match the CMakeLists.txt file that you configured in Step A.

  5. In the Solution Explorer, expand the Source folder and double-click EOSGame.cpp to open it.

  6. Copy and paste the following code into EOSGame.cpp to add a main function with a print statement:

    #include <iostream> int main(){   std::cout << "Hello World!" << std::endl;}

    The main function provides an entry point for the game.

  7. Run the project.
    To do this, from the top navigation, click the green play button beside the “ExampleEOSGame.exe” text.
    This builds the project using CMake and runs the resulting executable file ExampleEOSGame.exe. A console opens and displays the text “Hello World!”

Note: This guide provides instructions to set up a simple command-line project that demonstrates the implementation of most EOS services. If you want to use the EOS Overlay, your game requires graphics rendering, which is outside the scope of this guide.
For more information, see the documentation: EOS Overlay Overview.

Your project is now configured to use the EOS SDK.
