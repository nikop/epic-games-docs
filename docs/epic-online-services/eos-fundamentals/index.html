EOS Fundamentals

The foundation to using Epic Online Services in your game.

Under 1 min to read
Introduction

Introduction to the foundation of using Epic Online Services in your game.

Interfaces

Platform Interface

Reference information and guidance on using the Platform Interface to facilitate your game's integration with all other EOS services.
Connect Interface

How-to guide and reference information on logging players into your game, using either a supported external identity provider (for example, a Steam or PlayStation account) or an Epic Games account, to access EOS Game Services.
Logging Interface

How-to guide and reference information on receiving log messages about the EOS SDK services that run in your game.

Features

Client and Client Policy

How-to guide and reference information on defining and managing the software clients that can access EOS services in your game.
Identity Provider Management

Reference information and guidance on configuring which identity provider accounts can participate in the EOS cross-platform features of your game.
Tools

Reference information and guidance on EOS tools, including the Bulk Importer and Exporter tool to manage your game's stats and achievements outside of the Developer Portal, and the File Decryption tool to manage files loaded to the Title Storage and Player Data Storage associated with your game.
