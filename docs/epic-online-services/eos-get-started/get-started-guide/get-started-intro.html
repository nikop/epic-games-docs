Guide: Get Started With Epic Online Services — Introduction

Overview of how to integrate EOS into your game.

1 min to read

Epic Online Services (EOS) is a free*, modular set of services that streamline implementing common game functionality. EOS services are scalable, so you can use them in your game (or other software application) whether you are an indie developer or a AAA studio. EOS services are game-engine-agnostic and available for PC (Windows, macOS, Linux), consoles, and mobile (iOS, Android).

For more information on EOS and a list of all the services it provides, see the EOS Overview documentation.

*The anti-cheat service, like all other services, is free. However, additional anti-cheat support and features are available with a paid enterprise agreement. (More information: Anti-Cheat Interfaces.)

Unreal Engine EOS Plugins and EOS Plugin for Unity
Do not use this guide if you use one of the Unreal Engine EOS plugins or the EOS Plugin for Unity to integrate the EOS SDK into your game. This guide does not apply to these plugins.

This guide shows how to manually integrate the EOS SDK into your game, which is an alternative to using the plugins. For more information on the options available to integrate the EOS SDK into your game, including the plugins, see the documentation: EOS SDK and Game Engines Introduction.
