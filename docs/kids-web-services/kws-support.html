KWS Support

Where to get information and support when using Kids Web Services.

2 mins to read

KWS Developer Support

Documentation

First, refer to the KWS documentation at epicgames.com/docs/kids-web-services because it might contain the answers to your questions.

Community Support

If you need support beyond the documentation, use the Epic Online Services (EOS) Developer Support page at eoshelp.epicgames.com to open a private discussion.

To create a private discussion:

  1. Sign in to your Epic Games account, click LOGIN in the top right, and enter your login credentials.

  2. Click Create Private Discussion.

  3. Fill out the required fields.

  4. In TOPIC, select Kids Web Services.

KWS Platform Uptime Status

Check the Platform Uptime Status page at status.kidswebservices.com for any issues that might impact KWS, such as an outage or slow response times.

To sign up to receive automatic updates:

  1. Go to the Platform Uptime Status page at status.kidswebservices.com.

  2. Click Subscribe to Updates.

  3. Select the tab for whichever update method you prefer.

Other Useful Resources

  • KWS Developer Terms Hub (kidswebservices.com/en-US/developer-terms-hub)

  • KWS Privacy Hub (kidswebservices.com/en-US/privacy-hub)

KWS End User Support

Users can use the KWS End User Support website to:

  • Contact the dedicated KWS End User Support team.
  • Get answers to frequently asked questions.
  • View troubleshooting tips in case of unsuccessful verification.
  • Find out more about Kids Web Services, its privacy policy, and its terms of use.

Note: The KWS End User Support team cannot assist with queries unrelated to Kids Web Services, such as in-game issues. Instead, the support team will direct the user to your product's support team.

Hours and Response Times

KWS End User Support is available 24 hours a day, 7 days a week.

The support team responds to user queries within one working day and aims to resolve all issues within three working days. The support team will notify you if anything may affect these timeframes.

Redirect a Query to KWS

If a user contacts you regarding age or parent verification, direct them to the KWS End User Support website at support.kidswebservices.com.
