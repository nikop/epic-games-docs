Integrate a Third-Party Launcher with Epic Games Store

Reference for how to integrate a third-party game launcher with the Epic Games Store.

1 min to read

If your game provides a launcher to include additional launch options, promotions or other news, then your launcher must manage the sign-in flow. The Epic Games Launcher generates exchange codes that expire after a short period of time. You must prevent the exchange codes from expiring. Use the following pattern if the Epic Games Launcher is not directly launching your game:

  1. The Epic Games Launcher starts the third-party launcher, passing the exchange code on the command line (Documentation: Auth Interface Reference > Epic Games Launcher).
  2. The third-party launcher uses the Exchange Code to sign in the player by using the EOS_Auth_Login API. Initialize EOS_Auth_LoginOptions by setting the Type and Token fields of the EOS_Auth_Credentials struct to EOS_LCT_ExchangeCode and the exchange code from the command line respectively.
  3. When the player launches the game, use the EOS_Auth_CopyUserAuthToken API to get a copy of the token details. Copy the RefreshToken from the EOS_Auth_Token and call the EOS_Auth_Token_Release API to free the memory allocated by the SDK.
  4. Pass the refresh token to the game application by setting an environment variable that the game can read on startup. Do not sign the player out in the third-party launcher when it exits as this will invalidate the refresh token.
  5. When the game process starts up, the game can sign the player in using the EOS_Auth_Login API. Initialize EOS_Auth_LoginOptions by setting the Type and Token fields of the EOS_Auth_Credentials struct to EOS_LCT_RefreshToken and the refresh token from the environment variable respectively.
