Bulk Import Localized Rich Presence Templates

How to import multiple localized rich presence templates from a CSV file.

4 mins to read

Use localized rich presence templates to define localized text for custom status messages (rich presence) that your product displays to your users' friends. For more information, see Localize Your Game's Rich Presence Messages—Introduction.

You can bulk import multiple rich presence templates from a CSV file. To do this, you need to create and upload the following CSV files:

  • A templates .CSV file, containing the template definitions.
  • A variables .CSV file, containing definitions of any variables your templates use that you haven't already defined in the Developer Portal. You only need to upload this file if both of the following apply:
    • Your templates use variables.
    • You haven't already defined these variables, either in the Developer Portal (documentation: Create a Variable Definition) or with a previous bulk import.

Workflow

To bulk import templates, you need to carry out the following steps:

  • A. Download the Template Files
  • B. Populate the Template Files
  • C. Upload the Template Files

A. Download the Template Files

To download the template files:

  1. Sign in to the Developer Portal (dev.epicgames.com/portal).

  2. Select the correct organization for your product.

    (To check which organization is selected, see Organization at the top of the left navigation. To change organization, click Organization and follow the on-screen instructions.)

  3. In the left navigation, under Your products, click the name of your product.

  4. In the left navigation, click Epic Online Services.

  5. Under Accounts & Social, click Localized Presence.

  6. Above the list, click Bulk import.

  7. Click Download templates .csv template.

  8. If you plan to use variables in your templates, click Download variables.csv template.

B. Populate the Template Files

(Optional) Populate the Variable Definitions .CSV File

If you plan to use variables in your templates, you need to populate the variable definitions .CSV with definitions of these variables. Important: You must do this before you upload the templates .CSV file.

For guidance on how to populate the file, see the example text in the file you downloaded.

For more information on variable definitions, see Variable Definitions for Localized Rich Presence Templates — Introduction.

Note: You only need to populate the variable definitions file if you haven't already defined these variables in the appropriate deployment, either in the Developer Portal (documentation: Create a Variable Definition) or with a previous bulk import.

To populate the variables .CSV file:

  1. Make one row for each variable definition.
    • If you want to define multiple locales for a variable definition, add one row for each locale.
    • For an example, see the contents of the downloaded file.
  2. Populate the columns on each row.
    • For information on the options for variable definitions, see documentation: Variable Definition Options.

Note: variable names
If you import a variable definition with the same name as an existing variable definition in your target deployment, then the existing variable definition is overwritten by the imported variable definition. If you want to avoid this, make sure that the variable definitions in your variable definitions .CSV have different names from the variable definitions in your target deployment.

Populate the Templates .CSV File

To populate the templates .CSV file:

  1. Make one row for each template.
    • If you want to define multiple locales for a template, add one row for each locale.
    • For an example, see the contents of the downloaded file.
  2. On each row, populate the columns.
    • For information on the options for templates, see documentation: Template Options.

For guidance on how to populate the file, see the example text in the file you downloaded.

Note: Template names
If you import a template with the same name as an existing template in your target deployment, then the existing template is overwritten by the imported template. If you want to avoid this, make sure that the templates in your templates .CSV have different names from those in your target deployment.

Note: If you use variables in your templates
If you want to use variables in a template, you must populate the definitions for these variables in the variables .CSV file. See (Optional) Populate the Variable Definitions .CSV File above. You can use up to eight variables per template.

C. Upload the Template Files

Note: Duplicate names

  • If you import a template with the same name as an existing template in your target deployment, then the existing template is overwritten by the imported template. If you want to avoid this, make sure that the templates on your templates .CSV have different names from those in your target deployment.
  • If you import a variable definition with the same name as an existing variable definition in your target deployment, then the existing variable definition is overwritten by the imported variable definition. If you want to avoid this, make sure that the variable definitions in your variables .CSV have different names from those in your target deployment.

To upload the template files:

  1. Sign in to the Developer Portal (dev.epicgames.com/portal).

  2. Select the correct organization for your product.

    (To check which organization is selected, see Organization at the top of the left navigation. To change organization, click Organization and follow the on-screen instructions.)

  3. In the left navigation, under Your products, click the name of your product.

  4. In the left navigation, click Epic Online Services.

  5. Under Accounts & Social, click Localized Presence.

  6. Above the list, click Bulk import.

  7. If you have a variables .CSV file, add it as follows:

    • Either drag and drop it to the file drop area for the variables .CSV, or click browse and select the .CSV file.
    • It is important that you do this before you move on to step 7.

  8. Add your templates .CSV file, as follows:

    • To do so, either drag and drop it to the file drop area for the templates .CSV, or click browse and select the .CSV file.

  9. Click Next.

  10. Check that the templates displayed on screen match what you want to import.

  11. Click Import.
