EOS Get Started Introduction

Key information when integrating Epic Online Services (EOS) into your game.

8 mins to read

Use the Epic Online Services (EOS) SDK to integrate the following groups of EOS services into your game:

  • Accounts and Social
  • Multiplayer
  • Player and Game Data
  • Trust and Safety
  • EOS Fundamentals

Note: Some Epic Games Store Services are also available through the EOS SDK (Documentation: Epic Games Store > Epic Games Store Services).

For more information on the available EOS services, see the EOS Overview documentation.

Integrate these groups of services into a game running on multiple platforms, including Windows, macOS, Linux, PlayStation, Xbox and Switch. (Note you can only use Epic Games Store Services on Windows and macOS.)

For a full list of platforms and platform versions supported, see the Platforms Supported documentation.

EOS SDK

Interfaces

You integrate EOS services with your game through interfaces. These interfaces are SDK APIs and Web APIs. To integrate EOS services, you must call these APIs in your game’s (or software application’s) code.

The interfaces are modular and specific to each EOS service. For example:

  • The Lobbies Interface integrates your game with the EOS lobbies service. This service manages the creation and interactions of your game’s lobbies. (Documentation: Lobbies Interface.)

  • The Friends Interface integrates your game with the EOS friends service. This service manages the features associated with a player’s friends list. (Documentation: Friends Interface.)

Accounts and Social

The Accounts and Social interfaces are as follows:

  • Friends: Enable players to invite friends to join a game-play session. Retrieve and display friend information to players.
  • Presence: Display a player’s status (online, offline, playing) in a game.
  • EOS Epic Account Services Authentication — Auth Interface: Authenticate players, get authorization credentials (access tokens), and handle other Epic Games account-related interactions with Epic Online Services (EOS).
  • Progression Snapshot: Merge a player’s Epic Games account and proxy account.
  • UI: Implement a product-independent overlay window that displays status updates, shows or hides the overlay, and adjusts display and hotkey preferences.
  • User Info: Obtain information about a player, such as their display name or country.

Accounts and Social also has the following features:

  • Epic's Account Ecosystem: EOS Epic Account Services provide player accounts: either an Epic Games account or a proxy account. This enables your game to tap into a player account ecosystem of nearly a billion players across multiple platforms and stores.
  • Crossplay: Enable players accessing your game from different storefronts to play together using a combined friends list.
  • Social Overlay: Display to a player their achievements and friends information, including if their friends are playing the same game.
  • Localized Rich Presence: Localize the dynamic messages you display to players.

Accounts and Social are EOS Epic Account Services — players can connect to these services in your game with an Epic Games account or proxy account. For details, see Epic Online Services (EOS) Overview > Type of Service.

Multiplayer

The interfaces are as follows:

  • Peer-to-Peer (P2P) (also known as "NAT P2P"): Enable players to connect with other players in a game.
  • Lobbies: Enable players to create, remove, join, and leave lobbies.
  • Sessions: Allow players to host, find, and interact with online gaming sessions.
  • Voice Interface and Real-Time Communication Interface: Help players talk, strategize, and socialize. Voice chat enables you to create and manage cross-platform voice chat rooms between your players during matches or in lobbies. Real-time-communication (RTC) text chat is also available. To integrate voice or text chat, either use EOS Lobbies (through the Lobbies Interface) or your own trusted server.

Multiplayer services are EOS Game Services — players can connect to your game with an account from any supported identity provider. For details, see Epic Online Services (EOS) Overview > Type of Service.

Player and Game Data

The interfaces are as follows:

  • Leaderboards: Define leaderboards for your game, choose the stats to include, how you rank players, and the lifespan of the leaderboards.
  • Stats: Define the stats for your game in the Developer Portal. You can include any statistical data about a player that you want to track, for example the number of items the player has collected. You can use these stats to determine when to unlock achievements and how to rank players in leaderboards.
  • Achievements: Access data about player achievements, unlock them for a player, get data on a player's progression for an achievement, and send notifications to players when they unlock an achievement.
  • Player Data Storage: Save, download, copy, and delete player-related data for your game on cloud servers in encrypted form.
  • Title Storage: Use the Title Storage Interface to retrieve game-specific data that is stored in encrypted form on cloud servers.
  • Custom Invites: If your game has its own player-invitation system, you can manage this through the Social Overlay UI (the Social Overlay is part of the EOS Overlay).
  • Metrics: Use the Metrics Interface to set up the game analytics dashboard in the Developer Portal and track worldwide game activity, player retention, and online player counts. You can view your game’s usage data, including players’ active sessions and past sessions.

Player and Game Data also has the following features:

  • Player Search: View and manage the data that EOS stores about your players on your behalf.
  • Ticketing System: Manage support for your players with a pre-assigned email address and public web API key.

Player and Game Data are EOS Game Services — players can connect to your game with an account from any supported identity provider. For details, see Epic Online Services (EOS) Overview > Type of Service.

Trust and Safety

The interfaces are as follows:

  • Anti-Cheat (also known as "Easy Anti-Cheat"): Prevent and detect players cheating within your game.
  • Reports (also known as “Player Reports”): Collect and publish player behavior to player reports. View details about player cheating, verbal abuse and offensive profiles.
  • Sanctions: Define and manage sanctions for your game. In the Developer Portal, you can view the details of all sanctions placed on a player.

Trust and Safety are EOS Game Services — players can connect to your game with an account from any supported identity provider. For details, see Epic Online Services (EOS) Overview > Type of Service.

About Kids Web Services (KWS)

Kids Web Services (KWS) is also available but is a separate service set from EOS. KWS provides parent verification so you can manage youth audiences at scale. KWS greatly reduces the complexity and cost of global verification and consent management. (Documentation: Kids Web Services (KWS))

EOS Fundamentals

The EOS Fundamentals interfaces are as follows:

  • Platform: The Platform Interface facilitates your game’s integration with all other EOS services. You use the Platform Interface to retrieve handles to access the other EOS interfaces. To use any EOS services, you must integrate the Platform Interface into your game.
  • Connect: Log players into your game using either a supported external identity provider (such as a Steam or PlayStation account, among many others) or an Epic Games account to access EOS Game Services. (Note that players do not need an Epic Games account to log-in through the Connect Interface and access EOS Game Services.)
  • Logging: Receive log messages about the EOS SDK services that run in your game. These log messages can help you diagnose technical issues, both while you develop your game and after you have shipped it.

EOS Fundamentals also has the following features:

  • Client & Client Policy: Define and manage the software-clients that can access EOS services in your game.
  • Identity Provider Management: Configure which identity provider accounts can participate in the EOS cross-platform features of your game.
  • Tools: Tools to help you configure and manage EOS services in your game, such as stats and achievements.

EOS Fundamentals are EOS Game Services — players can connect to your game with an account from any supported identity provider. For details, see Epic Online Services (EOS) Overview > Type of Service.

Coding Languages and Game Platforms

The EOS SDK is available in C, and also has a C# wrapper.

By focusing on C, we can provide stable application binary interfaces (ABI) to ensure integration functionality, regardless of compiler choice, implementation, calling conventions, data sizes, or alignments.

This also allows independent code patching for the EOS SDK to limit interruptions in your own development, and helps maintain the life of the EOS SDK without recompiling the application after distributing fixes and updates. Additionally, focusing on C APIs enforces a more deliberate exposure of the public API.

There are different types of EOS SDK download to use, depending on the game platform your game clients run on:

  • Windows, macOS, Linux — the EOS SDK in C, and the EOS SDK in C#.
  • Mobile — the EOS SDK for iOS, and the EOS SDK for Android.
  • Consoles — there are EOS SDK downloads for game consoles in C, and in C#.
    The EOS SDK downloads for consoles are only available to developers approved by the platform holders and approved by Epic Games.
    The platform holders are: Microsoft (Xbox One, Xbox Series), Sony (PlayStation 4, PlayStation 5), Nintendo (Switch and Switch 2).
    To get access to the EOS SDK downloads for consoles and associated documentation, you must apply for platform-holder approval. You can do this after you have set up an Epic Games account and organization in the Developer Portal. See the EOS Get Started Reference > Access the EOS SDK for Consoles documentation for more information on how to access the EOS SDKs for consoles and their associated documentation.

For details of which EOS SDK release versions support which game-client platform release versions, see the Platforms Supported documentation.

Release Versioning

EOS SDK versioning guarantees backwards compatibility with games using an older version of the EOS SDK, even with API changes.

Every interface, function, and data type has a version associated with it. When a new EOS SDK version is released, the new EOS SDK recognizes and supports games using older versions of the EOS SDK and reacts appropriately to data and function calls coming from them. This reaction might include calling the original version of the function internally, migrating the original input structures to newer forms, or setting up defaults.

If your game uses an older version of the EOS SDK, you do not need to update it to the latest version to continue to use Epic Online Services.
