Tool: Bulk Import / Export

How to manage large quantities of stats and achievements.

8 mins to read

You can use the Bulk Import / Export tool to manage your game’s stats and achievements in large quantities. The tool uses .zip archives containing .csv-formatted data, so you can view and edit your stats and achievements in a wide variety of existing programs or your own tools. The tool is a panel on the Developer Portal that you access from your game’s (known as “product” in the Developer Portal) Achievements page.

The Bulk Export panel has three steps, which are as follows:

  • Step 1: Back Up Your Achievements
    You can export existing achievements before you import any new ones. It is optional, but we recommend you do this.

  • Step 2: Prepare And Import Archived Achievements
    You bulk import achievements in this step. Ensure the .zip file you upload and the files in it are in the required format. See the following section of this page for guidance: File Format Requirements.

  • Step 3: Achievements And Stats Are Uploaded
    This step confirms the number of successful uploads.

Note: The Bulk Import / Export tool only affects the definitions of your stats and achievements, it does not add, delete, or change your players' progress. If you delete and recreate your stats or achievements definitions, your players' stats and achievement progression remain intact.

Before You Start

  • Download the import file bulk template to use as a guide to the .zip file format required by the Bulk Import tool. Download it from Epic’s AWS link: (amazonaws.com/~BulkTemplate.zip). (You can also download it as part of the three-step process, but we recommend you download and use it before you start.)
  • For a successful import, ensure the files in the .zip file are in the format specified in the File Format Requirements section on this page.

Access the Bulk Import / Export Tool

You access the tool from the Developer Portal; go to your game’s (known as “product” in the Developer Portal) Achievements page.

To do this:

  1. Sign in to the Developer Portal (dev.epicgames.com/portal).
  2. In the left navigation, under Your Products, click the name of your game.
  3. In the left navigation, click Epic Online Services.
  4. Under Player & Game Data, click Achievements.
  5. Between the search box and Create Achievement, click the three dots (...).
    This displays the Bulk Export panel and step 1 of the process: Back Up Your Achievements. This step lets you export existing achievements before you import any new ones.

Step 1: Back Up Your Achievements

The export process creates a .zip file and downloads it. This .zip file contains .csv and .png image files of all existing stats and achievements for your game. These files in .csv format are compatible with most spreadsheet software applications.

Notes:

  • You do not have to export existing achievements, but we recommend that you do not skip the export if you do not have a backup of your existing achievements.
  • The tool can only export image files in .png format.

To export:

  1. Access the tool: follow the steps under the section Access the Bulk Import / Export tool.
  2. In the Bulk Export panel and step 1 of the process: Back Up Your Achievements, click Export current EOS achievements.
    Note: If you only want to export your data, you can stop here and click Cancel to leave the panel.
  3. Click Next.
    This displays the Bulk Import panel and step 2 of the process: Prepare And Import Archived Achievements.

Step 2: Prepare and Import Archived Achievements

Notes:

  • Importing achievements and stats erases and overrides the current achievements and stats. Make sure you have a backup of your achievements and stats in case you need to revert your changes.
  • When you import to a live deployment, stats and achievements definitions might be in an incomplete state during the import. As a result, players might not be able to record stats or unlock achievements. To minimize disruption and unexpected behavior for your players, we recommend that you import data during your maintenance windows for live deployments.

You add multiple achievements at once by uploading a .zip file filled with the appropriate data. To do this, you must use the same format as the import file bulk template. The template is available from Epic’s AWS link: (amazonaws.com/~BulkTemplate.zip). You can also download it as part of this step.

After completing Step 1: Back Up Your Achievements, complete the following:

  1. Make sure your .csv and image files meet the requirements before you begin the import process: see the section on this page: File Format Requirements.
  2. You have the option to download the import file bulk template from this panel. It’s available under Before You Start on the panel: click Download EOS achievements ZIP template. This is the same import file bulk template available from Epic’s AWS link: if you have already downloaded it and used it as a template, you do not need to download it again.
  3. Next, upload achievements:
    • a. Click the checkbox next to I have read and understood the statements above.
    • b. Follow the on-screen prompt to add files to upload.
    • c. Click Next.
      When complete, the tool deletes all your existing stats and achievements, then replaces them with the ones in your .zip file. This includes caching any icons that the new achievements use.

Step 3: Upload and View Achievements and Stats

Step 3 of the process, the final Bulk Import panel, displays the number of uploaded achievements and stats. Click Close or X to exit.

File Names and Types

Your import .zip file must contain the following file names and contents:

Note: Make sure that the files are located in the root of the .zip file, and not inside a sub-directory.

File Name Contents
stats.csv A list of "name and type" pairs that define each stat
achievementDefinitions.csv A list of achievement names, along with the stats they reference
achievementLocalizations.csv Achievement Localization locale keys and the files names of their icons
One or more .png files The icons referenced in achievementDefinitions.csv

You can download the import file bulk template to use as a guide to the .zip file format required by the Bulk Import tool. Download it from Epic’s AWS link: (amazonaws.com/~BulkTemplate.zip). (You can also download it as part of the Bulk Import / Export tool's three-step process, but we recommend you download it before you start.)

CSV Format Requirements

To ensure that the .csv files you upload pass the validation check, use the data format listed below for each file type and avoid leaving any blank lines. All .csv files must be UTF-8 encoded.

stats.csv Format

The stats.csv file has two columns for each stat, these are:

  • The name of the stat.
  • The stat's aggregation type.

Supported values for aggregation type are SUM, MIN, MAX, or LATEST.

Stat names are in camel case, aggregation types are in all caps, and there are no spaces in each entire line.

achievementDefinitions.csv Format

The achievementsDefinitions.csv uses three columns to define each achievement and the requirements for unlocking it, these are:

  • Achievement name:
    • The achievement's internal name.
    • The name must be in camel case.
  • Hidden status:
    • A Boolean value indicating whether the achievement is hidden or not.
    • Use either TRUE (hidden) or FALSE (not hidden).
  • (Optional) Stats names and their thresholds:
    • If empty, the achievement can only be unlocked by an explicit command from the EOS SDK.
    • If present, list stats names in camel case with a colon (:) and threshold criteria. Divide stats names and their thresholds with semi-colons (;). For example: Stat1:Threshold1;Stat2:Threshold2;StatN:ThresholdN.

Note: There must be no spaces in each entire line.

achievementLocalizations.csv Format

Note: All user-visible information about achievements can be subject to localization.

The achievementLocalizations.csv sets up all the data that the service needs to describe each achievement to users in different locales. This includes the following data:

  • Internal name of the achievement and the locale.
  • Title and description when locked.
  • Title and description when unlocked.
  • Flavor text.
  • Locked and unlocked icons.

Icon Requirements

Icons you reference in achievementDefinitions.csv must be in the .zip file you import because all existing content is erased when you import your new files. All icons must be in .png format and be at the root level of the .zip file. Do not have any sub-directories in your .zip file.

Icon filenames must not include the following characters (these characters result in Developer Portal errors:) \ { ^ } % ` ] > [ ~ < # | & $ @ = ; : + , ? or spaces ' '

To eliminate redundant downloads for your users, achievements can share icons if they refer to the same icon file. Use this capability whenever multiple achievements use the same image, like the “locked” icon for hidden achievements.
