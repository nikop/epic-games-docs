EOS SDK and Your Unity Project on iOS

How to integrate the EOS SDK into your Unity project on iOS.

7 mins to read

To integrate the EOS SDK into your Unity project, we recommend that you use the EOS Plugin for Unity. For information, see documentation: Introduction (EOS SDK & Game Engines) > Unity.

Use this how-to guide only if you cannot use the EOS Plugin for Unity.

This guide shows you how to manually integrate the EOS SDK into your Unity project on iOS. The sample code in this guide is written in C#.

After you complete these steps, you will know how to:

  • Download and install the EOS SDK into your Unity project
  • Initialize the EOS SDK
  • Create the Platform Interface
  • Shut down the EOS SDK

Before You Begin

Read the How to Integrate the EOS SDK Into Your Unity Project > Introduction page before you begin. It includes information on limitations that the EOS SDK has in the Unity Editor that you should be aware of.

To integrate the EOS SDK into your Unity project, you must first set up your Epic Games account and organization in the Developer Portal.
If you have not already done this, follow the guidance in Guide: Get Started With EOS > 1. Set Up Your Account and Download the EOS SDK to set these up.

Integrate the EOS SDK into Your Project

To integrate the EOS SDK into your Unity project on Android you must complete these steps:

  1. Download and install the EOS SDK into your Unity project.
  2. In your game's code, initialize the EOS SDK when your game starts.
  3. Create the EOS Platform Interface.
  4. In your game's code, shut down the EOS SDK when your game closes.

Step 1: Download and Install the EOS SDK into Your Unity Project

To download the EOS SDK for iOS and install it into your Unity Project, follow these steps:

  1. Download the EOS SDK from the Developer Portal.

    • a. Sign in to the Developer Portal at (dev.epicgames.com/portal).
    • b. In the left navigation, click Dashboard if it isn't already selected.
    • c. On the Dashboard page, under the Your products heading, click Downloads & Release notes.
    • d. Select the EOS SDK tab.
    • e. In SDK Type, select SDK for iOS.
    • f. In SDK Version, select the most recent version.
    • g. Click Download.

  2. Unzip the EOS SDK download.

  3. Organize the EOS SDK files in your Unity project as follows:

    • a. Move all the files from /SDK/ into the Assets/ directory.

      Tip: Organize the SDK/ files into a subdirectory of your Assets/ directory to make them easier to manage.

    • b. Move the SDK/Bin/IOS/EOSSDK.framework directory into the Plugins/IOS directory in your Unity project.

  4. Verify that the binaries are configured to load for the correct platform.
    To do this, click the binary file and verify that the settings are for iOS.

    Note: It is safe to import binaries for different platforms into the same project, but you must make sure that they are configured to load on the proper platform. For more information, see Unity's documentation at docs.unity3d.com/~/plug-in-inspector.

Step 2: Initialize the EOS SDK

To use the EOS SDK in your game's code, you must initialize the EOS SDK. During initialization, do the following:

  • Identify your product details (for example, your product's name).
  • Configure platform-specific initialization options.

To initialize the EOS SDK, follow these steps:

  1. Create a EOSSDKManager class in your project to manage the EOS SDK:

    using System;using Epic.OnlineServices;using Epic.OnlineServices.Platform; public static class EOSSDKManager{    }

  2. Set up the class to track and retrieve the EOS Platform Interface instance only when the code is run in the Unity Editor (note the UNITY_EDITOR scripting symbol).
    You use the Platform Interface in the next section (Step 3: Create the EOS Platform Interface).

    using System; public static class EOSSDKManager{    static public PlatformInterface PlatformInterfaceHandle { private set; get; } = null;}

  3. In the EOSSDKManager class, add a method to initialize the EOS SDK and configure the initialization options for your platform:

    static public Epic.OnlineServices.Result InitializePlatformInterface(){    InitializeOptions initOptions = new InitializeOptions();     initOptions.ProductName = /*YOUR_PRODUCT_NAME*/;    initOptions.ProductVersion = /*YOUR_PRODUCT_VERSION*/;     initOptions.AllocateMemoryFunction = IntPtr.Zero;    initOptions.ReallocateMemoryFunction = IntPtr.Zero;    initOptions.ReleaseMemoryFunction = IntPtr.Zero;     var overrideThreadAffinity = new InitializeThreadAffinity();     // You might need to configure these thread affinity values, depending on your application's needs.    // Setting the values to Zero, which is the default in C#, lets you configure the priority through the EOS SDK.    overrideThreadAffinity.NetworkWork   = 0;    overrideThreadAffinity.StorageIo 	= 0;    overrideThreadAffinity.WebSocketIo   = 0;    overrideThreadAffinity.P2PIo     	= 0;    overrideThreadAffinity.HttpRequestIo = 0;    overrideThreadAffinity.RTCIo     	= 0;     initOptions.OverrideThreadAffinity = overrideThreadAffinity;     return PlatformInterface.Initialize(ref initOptions);}

    For more information, see the following documentation:

    • On the available initialization options, see EOS_InitializeOptions data structure API reference.
    • On thread affinity, see Conventions and Limitations > Thread Affinity.

  4. Create a new script and add the call to initialize the EOS SDK to the Awake() method.

    using UnityEngine;using Epic.OnlineServices; public class Game : MonoBehaviour{    void Awake()    {        Result result = EOSSDKManager.InitializePlatformInterface();        if (result != Result.Success)        {            Debug.LogError("Failed to initialize platform interface");            Debug.Break();        }    }}

Step 3: Create the EOS Platform Interface

After you initialize the EOS SDK, you must create the Platform Interface. This lets you do several things, including:

  • Retrieve handles to access the other EOS Interfaces.
  • Control the EOS SDK lifecycle (for example, shutdown the EOS SDK).
  • Keep the per-frame update code (known as ticking) running.

For more information on the EOS Platform Interface and its functionality, see the Platform Interface documentation.

To create the Platform Interface, follow these steps:

  1. In the EOSSDKManager class, add a method to create the Platform Interface:

    static public Result CreatePlatformInterface(){ }

  2. Modify the CreatePlatformInterface() method to include the platform options for your platform.

    var platformOptions = new Epic.OnlineServices.Platform.Options();    platformOptions.CacheDirectory = Application.temporaryCachePath;    platformOptions.IsServer = /*YOUR_IS_SERVER_VALUE*/; //For Title Storage and Player Data Storage    platformOptions.EncryptionKey = /*YOUR_ENCRYPTION_KEY*/;    platformOptions.OverrideCountryCode = null;    platformOptions.OverrideLocaleCode = null;    platformOptions.ProductId = /*YOUR_PRODUCT_ID*/;    platformOptions.SandboxId = /*YOUR_SANDBOX_ID*/;    platformOptions.DeploymentId = /*YOUR_DEPLOYMENT_ID*/;     platformOptions.TickBudgetInMilliseconds =/*YOUR_TICK_BUDGET*/; var clientCredentials = new Epic.OnlineServices.Platform.ClientCredentials    {            ClientId = /*YOUR_CLIENT_ID*/,            ClientSecret = /*YOUR_CLIENT_SECRET*/    };    platformOptions.ClientCredentials = clientCredentials;

    For more information on the available platform options, see the EOS_Platform_Options data structure API reference documentation.

    Note: You can find your product's credentials (ProductId, SandboxId, DeploymentId, ClientId, and ClientSecret in the code snippet) under the Product Settings page for your product in the Developer Portal.
    To do this:

    • a. In the Developer Portal (dev.epicgames.com/portal), in the left navigation, under Your products, click the name of your product.

    • b. In the left navigation, click Product Settings.

  3. Modify the CreatePlatformInterface() method to disable the EOS Overlay when you run the game in the Unity Editor.
    To do this, set the Flags platform option to Platformflags.LoadingInEditor.

    platformOptions.Flags =#if UNITY_EDITOR        PlatformFlags.LoadingInEditor;#else        PlatformFlags.None;#endif PlatformInterfaceHandle = PlatformInterface.Create(ref platformOptions); return Result.Success;

    Note: If you use the Player Data Storage Interface or the Title Data Storage Interface in your game, you must set the EncryptionKey platform option in the CreatePlatformInterface() method as well.
    For more information on the Player Data Storage Interface or the Title Data Storage Interface, see the following documentation:

    • Player Data Storage Interface
    • Title Storage Interface

  4. Modify Unity's Awake() method to include calls to initialize the EOS SDK and to create the Platform.

    Note: You must initialize the EOS SDK before you create the platform.

    public class Game : MonoBehaviour{    void Awake()    {        Result result = EOSSDKManager.InitializePlatformInterface();        if (result != Result.Success)        {            Debug.LogError("Failed to initialize platform interface");            Debug.Break();        }         result = EOSSDKManager.CreatePlatformInterface();        if (result != Result.Success)        {            Debug.LogError("Failed to create platform interface");            Debug.Break();        }                Debug.LogError("EOS SDK ready to be used!");    }    ...}

  5. Modify Unity's Update() method to include the call to tick the platform, so the per-frame code for EOS SDK runs correctly.

    public void Update(){    EOSSDKManager.PlatformInterfaceHandle?.Tick();}

    Note: For more information on ticking, see the following documentation: Guide: Get Started With EOS > 4. Next Steps > Set Up Ticking.

Step 4: Shut Down the EOS SDK

When you are ready to close your game, you must also shut down the EOS SDK. During shutdown, do the following:

  • Release the memory held by the Platform Interface
  • Release the global state held by the EOS SDK

To shut down the EOS SDK, follow these steps:

  1. Add a method to shut down the EOS SDK:

    static public void ShutDownEOSSDK(){ }

  2. Include a call to the Epic.OnlineServices.Platform.PlatformInterface.Release() method to release the EOS Platform Interface instance.

    static public void ShutDownEOSSDK(){    PlatformInterfaceHandle.Release();}

  3. Include a call to the Epic.OnlineServices.Platform.PlatformInterface.Shutdown() method to complete the process and shut down the EOS SDK.

    static public void ShutDownEOSSDK(){    PlatformInterfaceHandle.Release();    PlatformInterface.Shutdown();}

    Note: After you shut down the EOS SDK, you can't reinitialize the EOS SDK, and any further calls to it fail.

  4. Modify Unity's Update() method to call your ShutDownEOSSDK() method when you're ready to shut down your game. The example configuration below runs the shutdown code when timeToShutDownMyGame (not defined in this guide) is true.

    public void Update(){    EOSSDKManager.PlatformInterfaceHandle?.Tick();        if (timeToShutDownMyGame)    {        EOSSDKManager.ShutDownEOSSDK();    }}
