Guide: Add Achievements to Your Game — 2. Retrieve the Achievements for Your Game

Overview of how to add player achievements to your game that you can access through the EOS API.

30 mins to read

Previous section: 1. Set Up Achievements

This section of the guide is available in C++ and C#. The C++ version uses the EOS SDK API in C.

You can add code to your game to retrieve the achievements that you have defined for your game (product or other software application) after you have completed the precursor steps listed in Before You Start below.

To add code to your game to retrieve the achievements that you have defined for your game, you query the achievement definitions to save them to the local cache. Then you can copy the cached achievement definitions and access the data for each definition.

You can either copy the cached achievement definitions by achievement ID (for example, "Radioactive Hero") or copy them all. This guide shows how to copy all achievement definitions. For information on how to copy achievement definitions individually by achievement ID, see the EOS_Achievements_CopyAchievementDefinitionV2ById function API reference documentation.

Note: To access all the available data for a player achievement, you must query the achievement definitions for your game before you retrieve the player's achievements. To do that, follow this section of the guide. Then you can retrieve the player's achievements (Section in this guide: 3. Retrieve a Player's Achievement Progress).

The example code snippets in this guide are for guidance only. If you use the snippets, make sure you tailor them to the unique circumstances of your game.

Before You Start

Before you start, you must complete these steps:

  • Integrate the EOS SDK into your code. (Documentation: Guide: Get Started With EOS.)
  • Use the Connect Interface in your code to get the local player’s Product User ID. (Documentation: Guide: Access Game Services With the Connect Interface.)
  • Set up achievements in the Developer Portal. (Section in this guide: 1. Set Up Achievements.)

Note: This guide follows an order. However, only section 1. Set Up Achievements is a pre-requisite to provide achievements in your game. You can follow any section of this guide from section 2 onwards independently of each other and in any order.

Step 1: Create a Class to Manage EOS Achievements

Create a class to manage EOS Achievements in your game. Include a map to hold the copied achievement data for lookup.

AchievementsManager.h 

// AchievementsManager.h #pragma once #include <eos_achievements.h>#include <eos_init.h>#include <eos_common.h>#include <eos_sdk.h>#include <map>#include <string> /** A data structure to hold information copied from the queried achievement definitions. */struct AchievementDefinitionCopy{    /** The ID of the achievement, exactly as you wrote it in the Developer Portal. */    std::string AchievementId;     /** The display name of the achievement when it is locked. */    std::string LockedDisplayName;     /** The description of the achievement when it is locked. */    std::string LockedDescription;     /** The display name of the achievement when it is unlocked. */    std::string UnlockedDisplayName;     /** The description of the achievement when it is unlocked. */    std::string UnlockedDescription;}; class AchievementsManager{public:    /**     * Constructor     *     * @param InPlatformHandle - The handle for the platform interface obtained during platform setup.     *      * @param InLocalProductUserId - The ProductUserID of the local player obtained during login.     */    AchievementsManager(EOS_HPlatform InPlatformHandle, EOS_ProductUserId InLocalProductUserId);     /** Deconstructor */    ~AchievementsManager() {}     /**      * Getter for a read-only copy of the map.      *      * @return A read-only copy of the RetrievedDefinitions map.     */    const std::map<std::string, AchievementDefinitionCopy>& GetRetrievedDefinitions() const { return RetrievedDefinitions; }     /** Queries and then copies all achievement definitions. */    void RetrieveAchievementDefinitionsExample(); private:    /** The Platform Interface handle. */    EOS_HPlatform PlatformHandle = nullptr;     /** The Achievements Interface handle. */    EOS_HAchievements AchievementsHandle = nullptr;     /** The Product User ID of the local player. */    EOS_ProductUserId LocalProductUserId = nullptr;     /** Map to hold all the copied achievement definitions. */    std::map<std::string, AchievementDefinitionCopy> RetrievedDefinitions;            /**      * Callback called by the EOS SDK whenever an achievement definitions query is completed.     *     * @param Data - Information passed to the callback function by the EOS SDK.     */    static void EOS_CALL OnQueryAchievementDefinitionsComplete(const EOS_Achievements_OnQueryDefinitionsCompleteCallbackInfo* Data);     /** Copies all achievement definitions after a query */    void CopyAchievementDefinitionsExample();};

What's happening in the code?

The following sub-steps are a breakdown of the code example above.

  1. Create a data structure to hold the copied achievement definition data. This data structure can contain whichever definition data you need to copy for your game.

    struct AchievementDefinitionCopy{    std::string AchievementId;    std::string LockedDisplayName;    std::string LockedDescription;    std::string UnlockedDisplayName;    std::string UnlockedDescription;};

  2. Create a class to manage EOS Achievements for your players. In your achievements manager class, declare a public function to get read-only access to the achievement definitions map. (Note: The map itself is declared as a private variable and described in more detail in a step below.) In the example, it's called GetRetrievedDefinitions:

    const std::map<std::string, AchievementDefinitionCopy>& GetRetrievedDefinitions() const { return RetrievedDefinitions; }

  3. Declare a public function to query the achievement definitions for your game.

    void RetrieveAchievementDefinitionsExample();

  4. Declare two private variables to hold the two interface handles required for the EOS Achievements API calls (one for the Platform Interface, one for the Achievements Interface).
    Also, declare a private variable to hold the product user ID of the signed-in local player. You'll use the local player's product user ID to make API calls.

    EOS_HPlatform PlatformHandle = nullptr;EOS_HAchievements AchievementsHandle = nullptr;EOS_ProductUserId LocalProductUserId = nullptr;

  5. Declare a private map to hold pairs of achievement IDs and your achievement definition data structure for the achievement definitions that you copy. In the example, the map is called RetrievedDefinitions:

    std::map<std::string, AchievementDefinitionCopy> RetrievedDefinitions;

    Note: When you query definitions, the EOS SDK saves those definitions to the local cache.

    Tip: This example stores the achievement ID and its associated achievement definition in a map. This makes it easier to look up an achievement definition and retrieve its DefinitionV2 data structure when you need it.

  6. Declare a private static callback function to execute when the EOS_Achievements_QueryDefinitions() function completes. The function definition must match the EOS_Achievements_OnQueryDefinitionsCompleteCallback callback which receives a EOS_Achievements_OnQueryDefinitionsCompleteCallbackInfo data structure. In the example, it's called OnQueryAchievementDefinitionsComplete:

    static void EOS_CALL OnQueryAchievementDefinitionsComplete(const EOS_Achievements_OnQueryDefinitionsCompleteCallbackInfo* Data);

  7. Declare a private function to copy the queried achievement definitions from the local cache.

    void CopyAchievementDefinitionsExample();

  8. Define the constructor for the achievements manager class. In it, pass in the Platform Interface handle and the Product User ID. You can then assign the Achievements Interface handle as part of the achievements manager class constructor, because you need it to make EOS Achievements Interface API calls.

    #include "AchievementsManager.h"#include <iostream> AchievementsManager::AchievementsManager(EOS_HPlatform InPlatformHandle, EOS_ProductUserId InLocalProductUserId)    : PlatformHandle(InPlatformHandle)    , LocalProductUserId(InLocalProductUserId){    AchievementsHandle = EOS_Platform_GetAchievementsInterface(PlatformHandle);}

Step 2: Implement Your Retrieve Achievement Definitions Function

In your achievements manager class, implement the function to retrieve the achievement definitions for your game.

Example:

void AchievementsManager::RetrieveAchievementDefinitionsExample(){    EOS_Achievements_QueryDefinitionsOptions QueryDefinitionOptions = {};    QueryDefinitionOptions.ApiVersion = EOS_ACHIEVEMENTS_QUERYDEFINITIONS_API_LATEST;     // The Product User ID of the local player requesting the query.    QueryDefinitionOptions.LocalUserId = LocalProductUserId;     // Call the EOS SDK to query achievement definitions.    // The callback function will be called when the query is complete.     EOS_Achievements_QueryDefinitions(AchievementsHandle, &QueryDefinitionOptions, this, OnQueryAchievementDefinitionsComplete);}

What's happening in the code?

The following sub-steps are a breakdown of the code example above.

  1. In your achievements manager class, implement the function to query the achievement definitions:

    void AchievementsManager::RetrieveAchievementDefinitionsExample(){ }

  2. Create an instance of the EOS_Achievements_QueryDefinitionOptions data structure to hold the query options for the achievement definitions. In the example, it's called QueryDefinitionOptions:

    EOS_Achievements_QueryDefinitionsOptions QueryDefinitionOptions = {};QueryDefinitionOptions.ApiVersion = EOS_ACHIEVEMENTS_QUERYDEFINITIONS_API_LATEST;QueryDefinitionOptions.LocalUserId = LocalProductUserId;

    Notes:

    • Your client policy configuration determines how many definitions the local player can query at once. For more information, see the section in this guide: 1. Set Up Achievements > Step 1: Configure Your Game's Client Policy.
    • The EOS_Achievements_QueryDefinition function uses the QueryDefinitionOptions.LocalUserId to determine the player's locale. If the player has linked their Epic Account ID to their Epic Games account, the EOS SDK returns the achievement data in the player's locale.
    • You can override the locale of the player to return the achievement data in the locale of your choice. For more information, see the EOS API EOS_Platform_SetOverrideLocalCode function.

  3. Call the EOS API EOS_Achievements_QueryDefinitions() function. This function saves the achievement definitions to the local cache.

    The function takes the following arguments:

    • Achievements Interface handle
    • A reference to the query options for the achievement definitions.
    • (Optional) ClientData.
      In the example, we pass the achievements manager (this in the example) for
      the ClientData field, so we can access it in the callback.
      If you don't need to pass any additional data to the callback, pass a nullptr instead.
    • A callback function to receive the EOS_Achievements_OnQueryDefinitionsCompleteCallbackInfo data structure when the EOS Achievements service completes the achievement definitions query.
    EOS_Achievements_QueryDefinitions(AchievementsHandle, &QueryDefinitionOptions, this, OnQueryAchievementDefinitionsComplete);

Step 3: Implement Your Query Achievement Definitions Callback Function

Implement your query achievement definitions callback function.

Example:

void EOS_CALL AchievementsManager::OnQueryAchievementDefinitionsComplete(const EOS_Achievements_OnQueryDefinitionsCompleteCallbackInfo* Data){    if (Data->ResultCode == EOS_EResult::EOS_Success)    {        // If the code gets here, the achievement definitions were queried successfully.         // Retrieve the AchievementsManager pointer from the client data passed into the callback function.        AchievementsManager* Self = static_cast<AchievementsManager*>(Data->ClientData);         Self->CopyAchievementDefinitionsExample();    }    else if (EOS_EResult_IsOperationComplete(Data->ResultCode) == EOS_FALSE)    {        // If the code gets here, the operation is retrying and is not yet complete.        return;    }    else    {        // If the code gets here, there was an error.         // Handle this however you need for your game.        std::cerr << "Error querying achievement definitions! Error code: " << static_cast<int>(Data->ResultCode) << EOS_EResult_ToString(Data->ResultCode) << std::endl;    }}

What's happening in the code?

The following sub-steps are a breakdown of the code example above.

  1. Implement the callback function that executes when the EOS_Achievements_QueryDefinitions() function completes. The function definition must match the EOS_Achievements_OnQueryDefinitionsCompleteCallback callback which receives a EOS_Achievements_OnQueryDefinitionsCompleteCallbackInfo data structure. In the example, it's called OnQueryAchievementDefinitionsComplete:

    void EOS_CALL AchievementsManager::OnQueryAchievementDefinitionsComplete(const EOS_Achievements_OnQueryDefinitionsCompleteCallbackInfo* Data){    }

    Notes:

    • The EOS SDK calls this callback function asynchronously each time the EOS_Achievements_QueryDefinitions() function completes.
    • The EOS_CALL macro is part of the required definition.

  2. In your callback function, use the returned EOS_EResult Enum to confirm that the query is successful. If the query is successful, retrieve the achievements manager pointer from the client data and call your function to copy the achievement definitions:

    if (Data->ResultCode == EOS_EResult::EOS_Success){    AchievementsManager* Self = static_cast<AchievementsManager*>(Data->ClientData);    Self->CopyAchievementDefinitionsExample();}

  3. Use the EOS_EResult_IsOperationComplete function to check if the query is not complete yet. If the query is not complete, return so the operation can complete:

    else if (EOS_EResult_IsOperationComplete(Data->ResultCode) == EOS_FALSE){    return;}

  4. If the query is not successful, handle the errors:

    else{    std::cerr << "Error querying achievement definitions! Error code: " << static_cast<int>(Data->ResultCode) << EOS_EResult_ToString(Data->ResultCode) << std::endl;}

    Tip: Use the EOS_EResult_ToString() function to convert the E_EResult Enum to a string, which gives the name of the error type.

Step 4: Implement Your Copy Achievement Definitions Function

Implement your function to copy the achievement definitions for your game and save those definitions to a map for retrieval later on.

Example:

void AchievementsManager::CopyAchievementDefinitionsExample(){    EOS_Achievements_GetAchievementDefinitionCountOptions GetDefinitionCountOptions = {};    GetDefinitionCountOptions.ApiVersion = EOS_ACHIEVEMENTS_GETACHIEVEMENTDEFINITIONCOUNT_API_LATEST;     // Get the number of achievement definitions from the EOS SDK.    uint32_t DefinitionCount = EOS_Achievements_GetAchievementDefinitionCount(AchievementsHandle, &GetDefinitionCountOptions);     // Loop over each definition.    for (uint32_t DefinitionIndex = 0; DefinitionIndex < DefinitionCount; DefinitionIndex++)    {        EOS_Achievements_CopyAchievementDefinitionV2ByIndexOptions CopyDefinitionByIndexOptions = {};        CopyDefinitionByIndexOptions.ApiVersion = EOS_ACHIEVEMENTS_COPYACHIEVEMENTDEFINITIONV2BYINDEX_API_LATEST;         // The current definition index.        CopyDefinitionByIndexOptions.AchievementIndex = DefinitionIndex;         // Create a pointer to store the definition info.        EOS_Achievements_DefinitionV2* Definition = nullptr;         // Copy the definition data from the cache into the definition pointer.        EOS_EResult CopyDefinitionByIndexResult = EOS_Achievements_CopyAchievementDefinitionV2ByIndex(AchievementsHandle, &CopyDefinitionByIndexOptions, &Definition);         if (CopyDefinitionByIndexResult == EOS_EResult::EOS_Success)        {            // Copy the definition data to the map.            AchievementDefinitionCopy& Entry = RetrievedDefinitions[Definition->AchievementId];            Entry.AchievementId = Definition->AchievementId;            Entry.LockedDescription = Definition->LockedDescription;            Entry.LockedDisplayName = Definition->LockedDisplayName;            Entry.UnlockedDescription = Definition->UnlockedDescription;            Entry.UnlockedDisplayName = Definition->UnlockedDisplayName;             std::cout << "Definition copied: " << Entry.UnlockedDisplayName << "/" << Entry.LockedDisplayName << std::endl;             // Release the memory for the EOS API data structure when you're done with it.            EOS_Achievements_DefinitionV2_Release(Definition);        }        else        {            // If the code gets here, there was an error.            // Handle this however you need for your game.	            std::cerr << "Error copying achievement definitions! Error code: " << static_cast<int>(CopyDefinitionByIndexResult) << EOS_EResult_ToString(CopyDefinitionByIndexResult) << std::endl;        }    }}

What's happening in the code?

The following sub-steps are a breakdown of the code example above.

  1. Implement the function to copy the achievement definitions for your game and save those definitions to a map for retrieval later on:

    void AchievementsManager::CopyAchievementDefinitionsExample(){ }

  2. In your copy function, create an instance of the EOS_Achievements_GetAchievementDefinitionCountOptions data structure to hold the count options for your achievement definitions. You will use these options to get the total number of achievement definitions that are cached locally. In the example, it's called GetDefinitionCountOptions:

    EOS_Achievements_GetAchievementDefinitionCountOptions GetDefinitionCountOptions = {};GetDefinitionCountOptions.ApiVersion = EOS_ACHIEVEMENTS_GETACHIEVEMENTDEFINITIONCOUNT_API_LATEST;

  3. Call the EOS API EOS_Achievements_GetAchievementDefinitionCount() function to get the number of achievement definitions stored in the local cache, and assign the value to a variable to hold the returned count.

    The function takes the following arguments:

    • Achievements Interface handle.
    • A reference to the count options for the achievement definitions.
    uint32_t DefinitionCount = EOS_Achievements_GetAchievementDefinitionCount(AchievementsHandle, &GetDefinitionCountOptions);

  4. Use the definition count to iterate through the list of queried achievement definitions that you want to copy:

    for (uint32_t DefinitionIndex = 0; DefinitionIndex < DefinitionCount; DefinitionIndex++){ }

  5. In the for loop, create an instance of the EOS_Achievements_CopyAchievementDefinitionV2ByIndexOptions data structure to hold the copy options for your achievement definitions. In the example, it's called CopyDefinitionByIndexOptions:

    EOS_Achievements_CopyAchievementDefinitionV2ByIndexOptions CopyDefinitionByIndexOptions = {};CopyDefinitionByIndexOptions.ApiVersion = EOS_ACHIEVEMENTS_COPYACHIEVEMENTDEFINITIONV2BYINDEX_API_LATEST;CopyDefinitionByIndexOptions.AchievementIndex = DefinitionIndex;

  6. Define a pointer to temporarily store the copied achievement definition data. In the example, it's called Definition:

    EOS_Achievements_DefinitionV2* Definition = nullptr;

  7. Call the EOS API EOS_Achievements_CopyAchievementDefinitionV2ByIndex() function to copy the achievement definitions from the local cache.

    The function takes the following arguments:

    • Achievements Interface handle.
    • A reference to the copy options for the achievement definitions.
    • A reference to the definition pointer to hold the returned achievement definition data.
    EOS_EResult CopyDefinitionByIndexResult = EOS_Achievements_CopyAchievementDefinitionV2ByIndex(AchievementsHandle, &CopyDefinitionByIndexOptions, &Definition);

  8. If the EOS_Achievements_CopyAchievementDefinitionV2ByIndex() function call is successful, retrieve data for the achievement definition from the definition pointer variable that you passed in, and save the achievement ID and achievement definition data structure pair to the definitions map. Also, call the EOS API EOS_Achievements_DefinitionV2_Release function on the definition pointer to free its memory:

    if (CopyDefinitionByIndexResult == EOS_EResult::EOS_Success){    AchievementDefinitionCopy& Entry = RetrievedDefinitions[Definition->AchievementId];    Entry.AchievementId = Definition->AchievementId;    Entry.LockedDescription = Definition->LockedDescription;    Entry.LockedDisplayName = Definition->LockedDisplayName;    Entry.UnlockedDescription = Definition->UnlockedDescription;    Entry.UnlockedDisplayName = Definition->UnlockedDisplayName;     std::cout << "Definition copied: " << Entry.UnlockedDisplayName << "/" << Entry.LockedDisplayName << std::endl;     EOS_Achievements_DefinitionV2_Release(Definition);}

  9. If the EOS_Achievements_CopyAchievementDefinitionV2ByIndex() function call is not successful, handle any errors:

    else{    std::cerr << "Error copying achievement definitions! Error code: " << static_cast<int>(CopyDefinitionByIndexResult) << EOS_EResult_ToString(CopyDefinitionByIndexResult) << std::endl;}

Results

After you call the EOS_Achievements_CopyAchievementDefinitionV2ByIndex() function, on success, you can access the EOS_Achievements_DefinitionV2 data structure through the achievement definition pointer that you passed in the EOS_Achievements_CopyAchievementDefinitionV2ByIndex() function call.

You can also call the AchievementsManager::GetRetrievedDefinitions() function to access the achievement definitions that you copied to the definitions map. Make sure there are no definition queries in progress before you call GetRetrievedDefinitions. If there are queries in progress, the definitions you retrieve might not include the latest updates from the active query and will therefore be outdated.

Notes

To access all the available data for a player achievement, you must query the achievement definitions for your game before you retrieve the player's achievements. To do that, follow this section of the guide. Then you can retrieve the player's achievements (Section in this guide: 3. Retrieve a Player's Achievement Progress).

Your client policy configuration determines how many definitions the local player can query at once. For more information, see the section in this guide: 1. Set Up Achievements > Step 1: Configure Your Game's Client Policy.

The EOS_Achievements_QueryDefinition function uses the QueryDefinitionOptions.LocalUserId to determine the player's locale. If the player has linked their Epic Account ID to their Epic Games account, the EOS SDK returns the achievement data in the player's locale.

You can override the locale of the player to return the achievement data in the locale of your choice. For more information, see the EOS API EOS_Platform_SetOverrideLocalCode function.
