Guide: Add Stats to Your Game — 2. Update Values for Stats

Step-by-step guide on how to set values for player stats in your game code.

19 mins to read

Previous section: 1. Set Up Stats

This section of the guide is available in C++ and C#. The C++ version uses the EOS SDK API in C.

You can add code to your game to set the values for a player's stats after you have completed the precursor steps listed in Before You Start, below.

To set the values for a player's stats, you call the EOS API EOS_Stats_IngestStat() function to ingest the values into the EOS Stats service. For example, you could ingest a player's stats and use those stats for achievements, leaderboards, or any custom functionality you choose.

Note: You cannot retrieve a player's stats until after you have ingested the player's stats.

The example code snippets in this guide are for guidance only. If you use the snippets, make sure you tailor them to the unique circumstances of your game.

Before You Start

Before you start, you must complete these steps:

  • Integrate the EOS SDK into your code. (Documentation: Guide: Get Started With EOS).
  • Use the Connect Interface in your code to get the local player’s Product User ID. (Documentation: Guide: Access EOS Game Services With the Connect Interface.)
  • Create stats in the Developer Portal. (Section in this guide: 1. Set Up Stats).

Set the Values for a Player's Stats

Complete the following steps to set the values for a player's stats:

  • Step 1: Create a Class to Manage EOS Stats

Step 1: Create a Class to Manage EOS Stats

Create a class to manage EOS Stats in your game.

Example:

StatsManager.h 

// StatsManager.h #pragma once #include <eos_stats.h>#include <eos_init.h>#include <eos_common.h>#include <eos_sdk.h> class StatsManager{public:    /**      * Constructor     *     * @param InPlatformHandle - The handle for the platform interface obtained during platform setup.     *      * @param InLocalProductUserId - The ProductUserId of the local player obtained during login.     */    StatsManager(EOS_HPlatform InPlatformHandle, EOS_ProductUserId InLocalProductUserId);     /** Destructor */    ~StatsManager() {}     /**      * Function to manage ingesting stats.      *     * @param IngestData - The address for the array of data to ingest.     *     * @param IngestDataCount - The number of entries in the data array.     */    void IngestStatsExample(EOS_Stats_IngestData* IngestData, int IngestDataCount); private:    /** The Platform Interface handle. */    EOS_HPlatform PlatformHandle = nullptr;     /** The Stats Interface handle. */    EOS_HStats StatsHandle = nullptr;     /** The Product User ID of the local player. */    EOS_ProductUserId LocalProductUserId = nullptr;        /**     * Callback function that executes when the stats ingest completes.      *     * @param Data - Information passed to the callback function by the EOS SDK.     */    static void EOS_CALL OnIngestStatsComplete(const EOS_Stats_IngestStatCompleteCallbackInfo* Data);};

StatsManager.cpp 

// StatsManager.cpp #include "StatsManager.h"#include <iostream> // ConstructorStatsManager::StatsManager(EOS_HPlatform InPlatformHandle, EOS_ProductUserId InLocalProductUserId)    : PlatformHandle(InPlatformHandle)    , LocalProductUserId(InLocalProductUserId){    // Get and save the handle to the Stats interface.    StatsHandle = EOS_Platform_GetStatsInterface(PlatformHandle);}

Note: How to sign in the player is outside the scope of this guide. For more information, see the following documentation:

  • Auth Interface
  • Connect Interface

What's happening in the code?

The following sub-steps are a breakdown of the code example above.

  1. In your stats manager's .h file (StatsManager.h in the example above), declare a public function to ingest the player's stats.
    The example function includes the following parameters:

    • An array of EOS_Stats_IngestData data structures.
    • An integer for the number of different types of stat you want to ingest. (For example, AmountOfGammaCollected, LongestJumpDistance, and NumberOfCarsSmashed would be three different types of stat.)
    void IngestStatsExample(EOS_Stats_IngestData* IngestData, int IngestDataCount);

  2. Declare two private variables to hold the two interface handles required for the EOS Stats API calls (one for the Platform Interface, one for the Stats Interface).
    Also, declare a private variable to hold the Product User ID of the signed-in player. You'll use the player's Product User ID to make API calls.

    EOS_HPlatform PlatformHandle = nullptr;EOS_HStats StatsHandle = nullptr;EOS_ProductUserId LocalProductUserId = nullptr;

  3. Declare a private callback function to execute after the ingest completes. The function definition must match the EOS_Stats_OnIngestStatCompleteCallback callback. In the example, it's called OnIngestStatsComplete:

    static void EOS_CALL OnIngestStatsComplete(const EOS_Stats_IngestStatCompleteCallbackInfo* Data);

  4. In your stats manager's .cpp file (StatsManager.cpp in the example above), define the constructor for the stats manager class. In it, pass the Platform Interface handle and the Product User ID.
    Also assign the Stats Interface handle as part of the stats manager class constructor; you need it to make EOS Stats Interface API calls.

    #include "StatsManager.h"#include <iostream> StatsManager::StatsManager(EOS_HPlatform InPlatformHandle, EOS_ProductUserId InLocalProductUserId)    : PlatformHandle(InPlatformHandle)    , LocalProductUserId(InLocalProductUserId){    StatsHandle = EOS_Platform_GetStatsInterface(PlatformHandle);}

Step 2: Implement Your Ingest Stats Function

In your stats manager class, implement the function to ingest the player's stats.

Example:

// StatsManager.cpp void StatsManager::IngestStatsExample(EOS_Stats_IngestData* IngestData, int IngestDataCount){    // Create a data structure to hold the options to ingest stats.    EOS_Stats_IngestStatOptions IngestStatOptions = {};    IngestStatOptions.ApiVersion = EOS_STATS_INGESTSTAT_API_LATEST;     // The Product User ID of the local player requesting the ingest.    IngestStatOptions.LocalUserId = LocalProductUserId;     // The Product User ID for the player whose stat you want to ingest.    IngestStatOptions.TargetUserId = LocalProductUserId;     // The array of stats to ingest.    IngestStatOptions.Stats = IngestData;     // The size of the array of stats to ingest.    IngestStatOptions.StatsCount = IngestDataCount;     // Call the EOS SDK to ingest your stats.    // The callback function executes when the `EOS_Stats_IngestStat` function completes.    EOS_Stats_IngestStat(StatsHandle, &IngestStatOptions, nullptr, OnIngestStatsComplete);}

What's happening in the code?

The following sub-steps are a breakdown of the code example above.

  1. In your stats manager class, implement the function to ingest the player's stats.
    The example function includes the following parameters:

    • An array of EOS_Stats_IngestData data structures.
    • An integer for the number of different types of stat you want to ingest. (For example, AmountOfGammaCollected, LongestJumpDistance, and NumberOfCarsSmashed would be three different types of stat.)
    void StatsManager::IngestStatsExample(EOS_Stats_IngestData* IngestData, int IngestDataCount){ }

  2. In your ingest function, create an instance of the EOS_Stats_IngestStatOptions data structure to hold the ingest options for the player's stats. In the example, it's called IngestStatOptions:

    EOS_Stats_IngestStatOptions IngestStatOptions = {};IngestStatOptions.ApiVersion = EOS_STATS_INGESTSTAT_API_LATEST;IngestStatOptions.LocalUserId = LocalProductUserId;IngestStatOptions.TargetUserId = LocalProductUserId;IngestStatOptions.Stats = IngestData;IngestStatOptions.StatsCount = IngestDataCount;

    Note: The LocalProductUserId value is assigned outside of this function, when the player signs in successfully.

  3. Call the EOS API EOS_Stats_IngestStat() function to ingest the stats.
    The function takes the following arguments:

    • Stats Interface handle.
    • A reference to the ingest options.
    • (Optional) ClientData - an argument must be present but it can be a nullptr.
      In the example, we pass a nullptr because we don't need to pass any additional data to the callback.
    • A callback function to receive the EOS_Stats_IngestStatCompleteCallbackInfo data structure when the EOS Stats service completes the stats ingest.
    EOS_Stats_IngestStat(StatsHandle, &IngestStatOptions, nullptr, OnIngestStatsComplete);

Step 3: Implement Your Ingest Stats Callback Function

Implement your ingest stats callback function.

Example:

void EOS_CALL StatsManager::OnIngestStatsComplete(const EOS_Stats_IngestStatCompleteCallbackInfo* Data){    if (Data->ResultCode == EOS_EResult::EOS_Success)    {        // If the code gets here, the stats were ingested successfully.        // Handle this however you need to for your game.        std::cout << "Stats were ingested successfully" << std::endl;    }    else if (EOS_EResult_IsOperationComplete(Data->ResultCode) == EOS_FALSE)    {        // If the code gets here, the operation is retrying and is not yet complete.        return;    }    else    {        // If the code gets here, there was an error.        // Handle this however you need to for your game.        std::cerr << "Error ingesting stats! Error code: " << static_cast<int>(Data->ResultCode) << " - " << EOS_EResult_ToString(Data->ResultCode) << std::endl;    }}

What's happening in the code?

The following sub-steps are a breakdown of the code example above.

  1. Implement the callback function that executes when the EOS_Stats_IngestStat() function completes. The function definition must match the EOS_Stats_OnIngestStatCompleteCallback callback which receives a EOS_Stats_IngestStatCompleteCallbackInfo data structure. In the example, it's called OnIngestStatsComplete:

    void EOS_CALL StatsManager::OnIngestStatsComplete(const EOS_Stats_IngestStatCompleteCallbackInfo* Data){ }

    Notes:

    • The EOS SDK calls this callback function asynchronously each time the EOS_Stats_IngestStat() function completes.
    • The EOS_CALL macro is part of the required callback function definition.

  2. In your callback function, use the returned EOS_EResult Enum to confirm that the ingest is successful:

    if (Data->ResultCode == EOS_EResult::EOS_Success){    std::cout << "Stats were ingested successfully" << std::endl;}

  3. Use the EOS_EResult_IsOperationComplete function to check if the stats ingest is not complete yet. If the stats ingest isn't complete, return so the operation can complete:

    else if (EOS_EResult_IsOperationComplete(Data->ResultCode) == EOS_FALSE){    return;}

  4. If the stats ingest is not successful, handle the errors:

    else{    std::cerr << "Error ingesting stats! Error code: " << static_cast<int>(Data->ResultCode) << " - " << EOS_EResult_ToString(Data->ResultCode) << std::endl;}

    Tip: Use the EOS_EResult_ToString() function to convert the E_EResult Enum to a string, which gives the name of the error type.

Results

After you call the EOS_Stats_IngestStat() function, the EOS_Stats_IngestStatCompletecallbackInfo data structure contains one of the following values:

  • EOS_Success: the stats have been successfully submitted for processing.
  • EOS_InvalidParameters: one or more options is invalid.
  • Any other result. See the following API reference documentation for a full list of possible results: EOS_EResult enum.

On success, the EOS SDK submits the stat values to the EOS Stats service to process them.

You can ingest stats for a player in your game code through the StatsManager::IngestStatsExample function in the example code.
In the function call, pass an array of EOS_Stats_IngestData data structures, one for each type of stat that you want to ingest for the player. (For example, AmountOfGammaCollected, LongestJumpDistance, and NumberOfCarsSmashed are three types of stat.) Each data structure must include the following:

  • The API version.
  • The stat name, exactly as you wrote it in the Developer Portal.
  • The value to ingest for the stat.

Example:

// Instantiate the stats manager.StatsManager* StatsManagerInstance = new StatsManager(PlatformHandle, LocalProductUserId); // Create an array of EOS_Stats_IngestData data structures, one for each stat.EOS_Stats_IngestData IngestData[] ={    { EOS_STATS_INGESTDATA_API_LATEST, "AmountOfGammaCollected", 30 },    { EOS_STATS_INGESTDATA_API_LATEST, "LongestJumpDistance", 2000 },    { EOS_STATS_INGESTDATA_API_LATEST, "NumberOfCarsSmashed", 60 },    { EOS_STATS_INGESTDATA_API_LATEST, "NumberOfEnemiesDefeated", 500 },    { EOS_STATS_INGESTDATA_API_LATEST, "LongestTransformation", 6000 }}; StatsManagerInstance->IngestStatsExample(IngestData, std::size(IngestData));

Note: The example specifies the API version _LATEST. We recommend that you use this so you don't have to update your code with release versions.

Notes

  • New stat values might not take effect immediately.
    • It might take some minutes to submit stat values and for the EOS service to process them.
    • Achievements that use stats might also take some minutes to unlock.
  • Known issue: When the EOS service returns success, it means that the service has ingested the stat value successfully. It does not mean that the service processed the stat values successfully.
    • For example, if you provide an incorrect stat name in the ingest call, processing might fail, even if the ingest was successful.
  • You must call EOS_Platform_Tick regularly for the EOS SDK to operate.
    • You don't have to make these calls every frame, but you should make them fairly often; one call every 100 milliseconds is considered reasonable, but you can adjust the exact frequency to your needs.
    • EOS SDK callbacks can only run when you call EOS_Platform_Tick, so all of your asynchronous operations depend on it.
