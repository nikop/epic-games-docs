Parent Verification Service Flow

How you can use Parent Verification Service.

6 mins to read

The verification flow has two parts. These are as follows:

  • Flow and UI built by you.
  • Flow and UI provided by the Parent Verification (PV) Service.

The two integration options below determine how the verification flow is triggered:

  • In a KWS-managed integration, KWS sends an email to the parent or guardian containing a button that triggers the verification flow when clicked.
  • In a Developer-managed integration, you trigger the verification flow directly from your own emails and product screens and do not need to send an additional KWS email to the parent or guardian.
    • Note: You are required to verify the ownership and authenticity of the parent or guardian's email address before passing it to KWS.

The following documentation describes a KWS-managed integration. If you would like more information about Developer-managed integrations, reach out to your Technical Account Manager or send an email to kws-support@kidswebservices.com.

The Parent Verification Service uses the KWS AgeGraph, a database of hashed email addresses of parents or guardians who have completed the parent verification process. The AgeGraph enables KWS to determine if a parent or guardian has been pre-verified the next time they encounter the PV Service.

Note: The Parent Verification Service has not been designed to obtain consent from verified parents or guardians or to address direct notice requirements when required by applicable law (such as COPPA). Instead, it enables you to verify that the parents or guardians of your product's users are adults. The Parent Verification Service is usually used in combination with an internal consent management solution. Consult your Legal Team to ensure that the services you have selected meet your needs. You can also contact your Technical Account Manager for information about the Consent Management Service, which handles parent verification and consent in a single flow.

Set Up Your Product's User Interface

The user interface for your product (game or other software application) must capture the required user details and trigger the PV flow.

You must set up your product's user interface as follows:

  1. To begin the verification process and allow the parent or guardian to complete the parent verification flow, configure your product's user interface to collect the following information:

    • The parent or guardian's email address.
      • Note: We recommend validating the email domain before submitting the email address to KWS.
    • The parent or guardian's language that KWS uses for emails and verification Web UI screens. For a complete list of supported languages, see documentation: Localization in Kids Web Services.
    • The child’s location. This can be either:
      • A two-letter country code using the ISO 3166-1 alpha-2 format (Wikipedia: ISO_3166-1_alpha-2). For example, 'US', 'GB', 'CA'.
      • A region code using the ISO 31660-2 subdivision format (Wikipedia: ISO_3166-2). For example, 'US-NY', 'GB-ENG', 'CA-BC'.

  2. To trigger the PV flow, submit the parent or guardian's email address to KWS using an authenticated call to the send-email API endpoint.

First-Time Verification

If either of the following situations applies, the Parent Verification (PV) Service follows the first-time verification steps below:

  • KWS has never verified the parent or guardian.
  • KWS has verified the parent or guardian, but they opted out of allowing KWS to keep their hashed email address in AgeGraph.

The steps are as follows:

  1. You pass the parent or guardian's email address to KWS (after confirming that the email address uses a valid email address format).

  2. KWS sends an email asking the parent or guardian to verify they are an adult:

Pre-Verified Parents or Guardians

KWS follows the pre-verified parent or guardian flow when the parent or guardian's hashed email address exists in the AgeGraph. This means KWS has already verified the parent or guardian through the PV Service or Age Verification (AV) Service using a verification method enabled for the current product.

Pre-verified parents or guardians don’t need to provide their verification credentials again, reducing friction for parents and benefiting completion rates. The completion rate refers to the percentage of parents or guardians who complete the parent verification flow out of the total number of parents or guardians who initiate the flow.

For pre-verified parents or guardians, the PV flow is as follows:

  1. Your product (game or other software application) passes a parent or guardian's email address to KWS.

  2. KWS checks to see if the AgeGraph includes a hash of the parent or guardian's email address.

  3. If the parent or guardian is pre-verified, they don’t receive a verification request. Instead, they will see a Web UI screen that informs them they have already verified with KWS.
