Guide: Sanction Players — 3. Allow Players to Appeal Sanctions

Step-by-step guide on how to allow your players to submit appeals against sanctions.

17 mins to read

Previous section: 2. Retrieve Sanctions

This section of the guide is available in C++ and C#. The C++ version uses the EOS SDK API in C.

You can add code to your game to let a player create a sanction appeal. This guide covers how to create sanction appeals through the EOS API.

Note: The following limitations apply to sanction appeals created with the EOS API:

  • Only a player can create their own sanction appeal with the EOS API.
  • A server cannot create a sanction appeal for a player with the EOS API.

The following alternative methods are also available to appeal sanctions:

  • Your players can create sanction appeals with the Sanctions Web API. For more information on creating sanction appeals with the Sanctions Web API, see Sanctions Web APIs > Creating Sanction Appeals.
  • You can appeal a sanction for a player, in the Developer Portal. (Section of this guide: 4. Manage Sanctions and Sanction Appeals.)
  • You can enable a feature to let your players appeal sanctions through a form that Epic provides (See the Notes section below.)

The example code snippets in this guide are for guidance only. If you use the snippets, make sure you tailor them to the unique circumstances of your game.

Before You Start

Before you start, you must complete these steps:

  • Integrate the EOS SDK into your code. (Documentation: Get Started Steps.)
  • Set up and apply sanctions in the Developer Portal. (Section in this guide: 1. Set Up and Apply Epic Online Services (EOS) Sanctions.)
  • Retrieve the reference ID for the sanction that you want to appeal.
    • You can get the sanction's reference ID through either the active sanction on the Sanctions page of the Developer Portal or from the EOS API EOS_Sanctions_CopyPlayerSanctionByIndex() function. For more information, see the following documentation:
      • For Developer Portal instructions, see the following section of this guide: 4. Manage Sanctions and Sanction Appeals.
      • For EOS API function instructions, see the following section of this guide: 2. Retrieve Sanctions.

Modify your sanctions manager class to include the necessary variables for sanctions appeals.

// SanctionsManager.h ... class SanctionsManager{public:...     /**      * Create a sanction appeal for the local player.     *      * @param AppealReason - The reason that the local player wants to appeal the sanction.     *      * @param SanctionReferenceId - The Reference ID for the sanction that the player is appealing.     */    void CreateSanctionAppealExample(EOS_ESanctionAppealReason AppealReason, const char* SanctionReferenceId);  private:...     /**     * Callback function that executes when the sanction appeal is created.     *      * @param Data - Information passed to the callback function by the EOS SDK.     */    static void EOS_CALL OnCreatePlayerSanctionAppealComplete(const EOS_Sanctions_CreatePlayerSanctionAppealCallbackInfo* Data); };

Step B: Implement Your Create Sanction Appeal Function

In your .cpp file, in your sanctions manager class, implement the function to create the sanction appeal for the player.

Example:

void SanctionsManager::CreateSanctionAppealExample(EOS_ESanctionAppealReason AppealReason, const char* SanctionReferenceId){    EOS_Sanctions_CreatePlayerSanctionAppealOptions CreateAppealOptions = {};    CreateAppealOptions.ApiVersion = EOS_SANCTIONS_CREATEPLAYERSANCTIONAPPEAL_API_LATEST;     // The Product User ID of the local player who is sending the sanction appeal.    CreateAppealOptions.LocalUserId = LocalProductUserId;     // The reason that the local player is appealing the sanction.    CreateAppealOptions.Reason = AppealReason;     // The Reference ID of the sanction to appeal.    CreateAppealOptions.ReferenceId = SanctionReferenceId;     // Call the EOS SDK to create a sanction appeal.    // The callback function will be called when the sanction appeal is sent.    EOS_Sanctions_CreatePlayerSanctionAppeal(SanctionsHandle, &CreateAppealOptions, nullptr, OnCreatePlayerSanctionAppealComplete);}

What's happening in the code?

The following sub-steps are a breakdown of the code example above.

  1. In your sanctions manager class, implement the function to appeal a sanction for the player. In the example, it's called CreateSanctionAppealExample:

    void SanctionsManager::CreateSanctionAppealExample(EOS_ESanctionAppealReason AppealReason, const char* SanctionReferenceId){ }

  2. Create an instance of the EOS_Sanctions_CreatePlayerSanctionAppealOptions data structure to hold the appeal options for one of the player's active sanctions. In the example, it's called CreateAppealOptions:

    EOS_Sanctions_CreatePlayerSanctionAppealOptions CreateAppealOptions = {}; CreateAppealOptions.ApiVersion = EOS_SANCTIONS_CREATEPLAYERSANCTIONAPPEAL_API_LATEST;CreateAppealOptions.LocalUserId = LocalProductUserId;CreateAppealOptions.Reason = AppealReason;CreateAppealOptions.ReferenceId = SanctionReferenceId;

    Note: To create a sanction appeal for the player's active sanction through the EOS API, you must have the reference ID for the player's sanction that you want to appeal. To get the reference ID for the player's sanction, do one of the following:

    • Copy the reference ID from the EOS_Sanctions_PlayerSanction data structure that the EOS_Sanctions_CopyPlayerSanctionByIndex() function returns.
      • For more information, see the following section of this guide: 2. Retrieve Sanctions.
    • Copy the reference ID from the Developer Portal. To get this ID, go to the Sanctions page in the Developer Portal and look in the Reference ID, status & issued date column of the sanction.
      • For More information, see the following section of this guide: 4. Manage Sanctions and Sanction Appeals.

  3. Call the EOS API EOS_Sanctions_CreatePlayerSanctionAppeal() function. This function creates an appeal for the active sanction with the reference ID you specify.
    The function takes the following arguments:

    • Sanctions Interface handle.
    • A reference to the create appeal options for the active sanction.
    • (Optional) ClientData.
      In the example, we pass nullptr because we don't need to pass any additional data to the callback.
    • A callback function to receive the EOS_Sanctions_CreatePlayerSanctionAppealCallbackInfo data structure when the EOS Sanctions service completes the sanction appeal.
    EOS_Sanctions_CreatePlayerSanctionAppeal(SanctionsHandle, &CreateAppealOptions, nullptr, OnCreatePlayerSanctionAppealComplete);

Step C: Implement Your Create Sanction Appeal Callback Function

Implement your create sanction appeal callback function.

Example:

void EOS_CALL SanctionsManager::OnCreatePlayerSanctionAppealComplete(const EOS_Sanctions_CreatePlayerSanctionAppealCallbackInfo* Data){    if (Data->ResultCode == EOS_EResult::EOS_Success)    {        // If the code gets here, the sanction appeal was successfully created.        std::cout << "Created sanction appeal for sanction with ID: "            << Data->ReferenceId << std::endl;    }    else if (EOS_EResult_IsOperationComplete(Data->ResultCode) == EOS_FALSE)    {        // If the code gets here, the operation is retrying and is not yet complete.        return;    }    else    {        // If the code gets here, there was an error.        // Handle this however you need for your game.        std::cerr << "Error creating sanction appeal! Error code: "            << static_cast<int>(Data->ResultCode) << " - " << EOS_EResult_ToString(Data->ResultCode) << std::endl;    }}

What's happening in the code?

The following sub-steps are a breakdown of the code example above.

  1. Implement the callback function that executes when the EOS_Sanctions_CreatePlayerSanctionAppeal function completes. The function definition must match the EOS_Sanctions_CreatePlayerSanctionAppealCallback callback that receives a EOS_Sanctions_CreatePlayerSanctionAppealCallbackInfo data structure. In the example, it's called OnCreatePlayerSanctionAppealComplete:

    void EOS_CALL SanctionsManager::OnCreatePlayerSanctionAppealComplete(const EOS_Sanctions_CreatePlayerSanctionAppealCallbackInfo* Data){

    Note:

    • The EOS SDK calls this callback function asynchronously each time the EOS_Sanctions_CreatePlayerSanctionAppeal() function completes.
    • The EOS_CALL macro is part of the required definition.

  2. In your callback function, use the returned EOS_EResult Enum to confirm that the appeal is successful. If the appeal is successful, notify the player. In the example, the console prints that the EOS SDK created a sanction appeal for the specified reference ID:

    if (Data->ResultCode == EOS_EResult::EOS_Success){    std::cout << "Created sanction appeal for sanction with ID: " << Data->ReferenceId << std::endl;}

  3. Use the EOS_EResult_IsOperationComplete function to check if the create sanction appeal operation is not complete yet. If the create sanction appeal operation is not complete, return. The callback is called again when the operation is complete:

    else if (EOS_EResult_IsOperationComplete(Data->ResultCode) == EOS_FALSE){    return;}

  4. If the create sanction appeal operation is not successful, handle the errors:

    else{    std::cerr << "Error creating sanction appeal! Error code: " << static_cast<int>(Data->ResultCode) << " - " << EOS_EResult_ToString(Data->ResultCode) << std::endl;}

    Tip: Use the EOS_EResult_ToString() function to convert the E_EResult Enum to a string, which gives the name of the error type.

Results

You can submit the appeal for the sanction on behalf of the player.

Note: A successfully submitted sanction appeal does not mean the appeal is approved. You must approve or deny the sanction appeal in the Developer Portal (section of this guide: 4. Manage Sanctions and Sanction Appeals).

Notes

You can enable a feature to let your players appeal sanctions through a form that Epic provides. To do this:

  • a. Go to the Developer Portal at dev.epicgames.com/portal.
  • b. In the left navigation, under Your Products, click the name of your product.
  • c. In the left navigation, click Epic Online Services
  • d. In the Trust and Safety section, click Sanctions.
  • e. Use the Allow users to appeal sanction by reference id toggle to enable sanction appeals through the appeal form.
    • After you have enabled this feature, your players can submit sanction appeals through the form at https://easy.ac/~/appeal.
    • Note: You must provide the reference ID for the sanction that the player wants to appeal. You can do this through your game code or a support request. This guide does not cover this process.
