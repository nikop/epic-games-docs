Age Verification Service API Reference

An overview of the Age Verification Service API.

Under 1 min to read

The Age Verification (AV) Service uses a REST API over HTTPS.

  • All Age Verification Service API requests must include a user-agent header containing a non-empty string identifying their client or HTTP library. Failure to do so results in a 403 Request blocked response code.
  • Rate limiting is fixed to ten requests per hour per unique user email address in both the test and production environments.
