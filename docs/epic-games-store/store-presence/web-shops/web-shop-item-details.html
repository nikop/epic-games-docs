Web Shop Item Details

Understand the details that you can configure on your web shop items.

5 mins to read

This page describes the details that you can set on a web shop item. For information on how to create or edit a web shop item, see documentation: Manage Web Shop Items.

Note: Some of these details are mandatory, and some are optional. The Developer Portal displays the web shop item details in sections called Required Information and Optional Information. This varies, depending on the type of web shop item.

General Details

For information on how to create and edit General Details for a web shop item, see documentation: Manage Web Shop Items.

You can set the following general details for a web shop item:

  • Name: The name of the web shop item. This is displayed to users on the storefront.
  • Short Description: A simple description of your product that appears throughout the storefront as well as in the SEO and sharing settings.
  • Metadata: General information about your web shop item, such as your developer and publisher names. This information is visible on the storefront, and helps Epic Games Store users find and understand your web shop item.
    • If you have metadata set on your product that you want to use for this item, you can import it. To import this information from your product’s Store Settings, click Use Product Metadata. (Documentation: Configure Store Settings.)
  • Promotional Content: If your web shop item promotes your own (or someone else's) brand, product, or business, then you must select Yes. If you select Yes, the web shop item is labeled on the Epic Games Store as promotional content. (Documentation: Requirements Overview > Promotional Content.)

Dates

For information on how to create and edit Date details for a web shop item, see documentation: Manage Web Shop Items.

Use dates to control when your web shop item is available to buy on the Epic Games Store.

Note — updating the dates on existing web shop items: You can update the expiry dates for an existing web shop item at any time. However, the process is slightly different depending on which sandbox the web shop item is currently in. (Documentation: Update Web Shop Item Dates).

The available date settings are as follows:

  • Available date: You must provide a specific available date and time for the web shop item. This is the date and time when it becomes available to buy.
  • Expiration date: Select one of the following expiration date types:
    • No Expiration Date: This web shop item is always discoverable and purchasable on the Epic Games Store.
    • Schedule expiration date: The date that the web shop item is no longer available to users on the Epic Games Store. Expired web shop items are no longer discoverable or purchasable on the Epic Games Store. However, they remain accessible to users who previously purchased them.
    • Expire web shop item in the next 30 minutes: When you click this, you set a 30 minute expiry date for your web shop item. Use this option to test your web shop item in the Dev sandbox.

Price

In the Base Price panel, in Price tier select the price you want to charge for the web shop item. Select the base price in USD. (Documentation: Pricing Overview > Pricing Restrictions.)

When you select the price, the Regional pricing section displays the equivalent prices in the local currency for each available region. These are the prices that Epic Games Store users will pay when they buy the web shop item. These prices are fixed at the time you create the web shop item, and do not automatically change to match changes in currency value.

You can create your own custom price tiers to determine your own regional pricing, instead of the Epic Games Store price tiers. (Documentation: Create Custom Price Tiers.)

There are some limitations on pricing, including when you can change the price for a web shop item. (Documentation: Pricing Overview > Pricing Restrictions.)

Images

You can add images to personalize your web shop and web shop items on the storefront. For web shop items, you can add images in landscape and portrait orientations. Images for mobile devices can appear in both orientations and web shop item images appear in portrait orientation for bigger screens, such as PC (Windows, macOS) screens. For information on how to edit image details for a web shop item, see documentation: Manage Your Web Shop Items.

Regions

The Regions page inherits the regions from your product’s Store Settings. Select the regions where you distribute your web shop items. For information on how to create and edit Region details for a web shop item, see documentation: Manage Your Web Shop Items).

Note:

  • If you want to set the regional availability for the entire product across all platforms, use the product's store settings.
  • You must set age ratings at a product level on the Store Settings page.

Social Preview

The social preview image is displayed when you share the web shop item URL in a social network post. If you don't have a social preview image, the product home image is shown instead. This image is not directly displayed on the web shop.

To add a social preview image to your web shop item:

  1. In the Developer Portal, go to the Web Shop page. To do this:

    • a. Sign in to the Developer Portal (dev.epicgames.com/portal).

    • b. Select the correct organization for your product.

      (To check, see Organization at the top of the left navigation. To change organization, click Organization and follow the on-screen instructions.)

    • c. In the left navigation, under Your products, click the name of your product.

    • d. In the left navigation, click Epic Games Store > Web Shop.

  2. Click the web shop item you want to add a social preview image.
  3. In the Web Shop Item Details panel, click Social Preview.
  4. Follow the on-screen instructions.
  5. Click Save changes.

Manage Localization

Localize your web shop content to best reach global Epic Games Store users. You must localize content from the Localization page. You can go to the Localization page from the web shop item details panel.

To localize your web shop content:

  1. In the Developer Portal, go to the Web Shop page. To do this:

    • a. Sign in to the Developer Portal (dev.epicgames.com/portal).

    • b. Select the correct organization for your product.

      (To check, see Organization at the top of the left navigation. To change organization, click Organization and follow the on-screen instructions.)

    • c. In the left navigation, under Your products, click the name of your product.

    • d. In the left navigation, click Epic Games Store > Web Shop.

  2. Click the web shop item you want to localize.
  3. In the Web Shop Item details panel, click View Localization.

To localize your web shop to new languages, see documentation: Localize your Store Presence.
