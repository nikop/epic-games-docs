Guide: Sanction Players — Introduction

Overview of how to sanction players in your game.

2 mins to read

Type of service : This interface is an EOS Game Service — authenticate players with the Connect Interface.

You can apply a sanction to players who violate the rules and community guidelines of your game. It prevents these players from using certain features or participating in certain game activities. For example, if a player mistreats other players in voice chat, you could apply a sanction against them that restricts them from being able to use voice chat. Use the Epic Online Services (EOS) Sanctions service to retrieve active sanctions against a player and create sanction appeals for players of your game.

Note:

  • The EOS Sanctions service only stores information about sanctions.
  • You are responsible for implementing the actual consequences of a sanction that you have defined.
  • You can make a sanction last a specific number of days, or you can make it permanent.
  • The EOS Sessions service provides the following predefined sanctions that you can use out of the box. For more information, see the following section of this guide: 1. Set Up and Apply Sanctions > Step B. Apply Sanctions to Players.
    • RESTRICT_GAME_ACCESS
    • RESTRICT_MATCHMAKING

Some examples of sanctions include:

  • A ban from joining a session to play your game.
  • A communications ban.

Note: The Sanctions service is also available as a Web API. See the Sanctions Web APIs documentation for more information. This guide does not cover how to use the Sanctions Web APIs.

You can use the Sanctions service by itself in your game, but we recommend that you combine it with related EOS services. For example, combine it with the Reports service so you can use the information from player reports to determine whether to enact restrictions against a player. You can also combine it with the Sessions service to enforce matchmaking restrictions against a player when they try to join a session.

For more information, see the following documentation:

  • Reports Interface
  • Sessions Interface
