Notify Epic Games About Your Product Releases

Declare a product release to Epic Games for an Unreal Engine product.

9 mins to read

This page applies if your product (game or other software application) uses Unreal Engine.

As part of the Unreal Engine royalty reporting requirement, when you publicly release your product (game or other software application), you must notify Epic Games. To do this, you submit a Release Form in the Epic Games Developer Portal.

When to Submit a Release Form

  • You must submit a Release Form before you distribute your product.
  • After you submit a Release Form, you can view the form at any time. For more information, see View or Edit a Submitted Release Form on this page.
  • You can edit the form with the following restrictions:
    • You can edit the form until you submit your first Royalty Report for the product. After you submit this report, you have three business days in which you can edit the form. You cannot edit the form after this time window. For more information, see View or Edit a Submitted Release Form on this page.
    • If you need to change a Release Form after the time window described above, open a private support request at this link: eoshelp.epicgames.com~.
  • For more information on royalty reporting requirements, see Royalty Reporting for Products that Use Unreal Engine—Introduction.

If you no longer distribute your product, you can retire the product. This means that you no longer need to report revenue for the product after the end of the current calendar quarter. To do so, see documentation: Retire a Product.

About the Developer Portal

The Epic Games Developer Portal is a browser-based tool that you can use to submit your Release Form.

If you haven't used the Developer Portal before, you must set up a user account, organization, and product. However, you don't need to do that ahead of time. You can do that as part of the Release Form process described on this page.

Note:

  • If you already use the Developer Portal, you have an organization set up, and a role in that organization. In this situation, you can only create a Release Form if you have one of the following roles for your organization: Owner, Admin, or Financial, or any custom role with the UE Royalties permission. For information on how to manage user roles, see documentation: Organizations.
  • If you don't use the Developer Portal yet, you set up an organization as part of the process below, and you are assigned the Owner role. This lets you complete a Release Form.

Before You Begin

Make sure you have the following information about your product before you start the release form:

  • Contact details for your organization (name, address, email address).
  • A list of the platforms your product supports.
  • A release date, or estimated release date, for your product.
  • Whether your product contains in-app purchases.

Start the Release Form Process

Epic Games Store Submission Fees

If you don't plan to publish your product on the Epic Games Store, you don't have to pay the Epic Games Store submission fee. To notify Epic Games about your product release, follow the steps below.

You can start the Release Form process in any of the following ways:

  • Method 1 — from a link in an email notification from Epic Games:
    • Follow the instructions in Stage 1: Create/Select Product below.
  • Method 2 — on the Unreal Engine commercial game deployment guidelines page:
      1. Go to the Unreal Engine commercial game deployment guidelines page: (unrealengine.com/…/release).
      1. In the Notification of Release panel, click Release form.
      1. Follow the instructions in Stage 1: Create/Select Product below.
  • Method 3 — in the Developer Portal:
    • Note: You need a Developer Portal account to use this method.
      1. Sign in to the Developer Portal (dev.epicgames.com/portal).

      1. Select the correct organization for your product.

        (To check, see Organization at the top of the left navigation. To change organization, click Organization and follow the on-screen instructions.)

      1. In the left navigation, under Your products, click the name of your product.
      1. Scroll down to the Unreal Engine panel.
      1. Click Release form.
        • If the button is green and has a checkmark, then you have already submitted a Release Form for this product, and you cannot click the button.
        • Note: Because you've just selected an organization and product, you don't need to complete stage 1 below. Go to Stage 2: Licensing & legacy.

Navigation in the Release Form Process

The submission process consists of five stages, each displayed on a separate page. You can navigate between the stages as follows:

  • Use the Next and Previous buttons to move forwards and backwards between the stages.
  • If you want to take a break and finish the Release Form later, click Save & Exit.

Stage 1: Create/Select Product

During this stage, you must select an organization and product in the Developer Portal. However, if you don't have either of these yet, you can create them during this stage.

  1. If you are not yet signed in, sign in to your Epic Games account.
    • If you don't have an Epic Games account yet, click Create account and follow the on-screen instructions.
  2. Select your organization.
    • If you don't have an organization in the Developer Portal yet, click Create organization and follow the on-screen instructions.
  3. Select your product.
    • If your product is not in the list, that means it is not set up in the Developer Portal. Click Create Product and follow the on-screen instructions.
    • If your product is in the list and grayed out, this means that you have already submitted a Release Form for the product. You don't need to follow the rest of this process.

Stage 2: Licensing & Legacy

This stage displays a link to the Unreal Engine End User License Agreement (EULA). If you are not familiar with the EULA, we recommend you open and read through it before you proceed.

If you already submitted a Release Form for this product before January 1, 2025, you must declare that you did so. To do so, select This product was released prior to Jan 1, 2025. The rest of the options in this stage apply only if you select this option.

If you did not submit a Release Form for this product before January 1 2025, skip to Stage 3: Product Checklist.

If you already submitted a Release Form for this product before January 1, 2025, do the following:

  1. Select I've already submitted my release notification using the legacy form.
  2. In the Lifetime Revenue to Date section, fill out the options as follows:
    • Advances received: Funds you have received to date for future sales of the product, such as pre-orders and recoupable publisher advances.
      • Do not include advances received in the current quarter.
      • For more guidance, in the Lifetime Revenue to Date section click the Advanced received dropdown.
    • Product gross revenue: Revenue you have received to date for the product. This includes revenue for the following:
      • Downloadable content
      • In-app purchases
      • Microtransactions
      • Virtual currency redemption
      • Subscription fees
      • Kickstarter funds related to game access or content (but not Kickstarter funds related to non-gameplay physical or digital goods offered as backer rewards)
      • Revenue from in-app advertising and affiliate programs
      • Note:
        • Do not include revenue received in the current quarter.
        • For more guidance, in the Lifetime Revenue to Date section click the Product gross revenue dropdown.
    • Units sold: The number of units of the product you have sold to date.
      • Do not include units sold in the current quarter.
  3. If the product was in the Launch Everywhere with Epic program, select This was a 'Launch Everywhere with Epic' release.
    • For information on Launch Everywhere with Epic, see the on-screen text.
  4. At the bottom of the form, check that the details (such as organization name, address, and email) are correct, and update them if necessary.
  5. Click Submit.
    • You can skip the rest of the stages of this process.

Stage 3: Product Checklist

This stage displays information on several steps that we recommend you take before you release your product. You can continue with the Release Form. You don't have to do these tasks right now.

When you are ready to continue with the Release Form, click Next.

Stage 4: Launch Everywhere with Epic

In this stage, choose whether you want to opt your product into the Launch Everywhere with Epic program.

The Launch Everywhere with Epic program gives you a preferred rate of 3.5% for your royalty payments, instead of the standard rate of 5%.

If you want to opt in, your product must meet the conditions of the program. These conditions are displayed on screen. Read them carefully to ensure that your product meets these conditions.

If you want to enroll in the program, select the checkbox.

Stage 5: Release Notification

This stage displays the Release Form itself. Follow the on-screen guidance to complete the form.

When you have completed the form, click Submit.

Note: After you submit your Release Form, you can edit it at any time until you submit your first Royalty Report. After this, you have three business days in which you can edit the Release Form. For information on how to do this, see View or Edit a Submitted Release Form on this page.

After this time window, you cannot make changes to the contents of the form, and you cannot change any options that you selected in the other stages of the process. If you need to notify Epic Games of any changes to your product release (such as a release delay) after you submit the form, open a private support request at this link: eoshelp.epicgames.com.

View or Edit a Submitted Release Form

After you submit a Release Form, you can view what you submitted at any time.

Time Limit on Edits

You can edit a Release Form at any time until you submit your first Royalty Report (for more information, see documentation: Submit and Manage Unreal Engine Royalties). After this, you have three business days in which you can edit the Release Form. To do this, use the procedure below.

In some situations, you might need to change the contents of the form after the three-day time window. For example, you might need to notify Epic Games of changes to your product release (such as a release delay). To do so, open a private support request at this link: eoshelp.epicgames.com.

Note: You can only view or edit Release Forms if you have one of the following roles for your Developer Portal organization: Owner, Admin, or Financial, or any custom role with the UE Royalties permission. For information on how to manage user roles, see documentation: Organizations.

To view or edit a submitted Release Form:

  1. Sign in to the Developer Portal (dev.epicgames.com/portal).
  2. Select the correct organization for your product.
  3. In the left navigation, under Your products, click the name of your product.
  4. Scroll down to the Unreal Engine panel.
  5. Click Release form.
  6. To edit the Release Form:
    • Important: see the note above about the time limit on edits. This procedure applies to editing within the time limit.
    • a. At the bottom of the form, click Edit Release Form.
    • b. Make edits to the Release Form as required.
      • Follow the same process that you followed when you first filled out the form. For more information, see the instructions on this page from Stage 2: Licensing & Legacy onwards.
