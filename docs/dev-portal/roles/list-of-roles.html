Available Roles in the Developer Portal (Developer Portal Access Permissions)

A description of each role and the associated access rights.

4 mins to read

This page describes the predefined roles in the Developer Portal and the associated access rights. For an overview of roles, see Manage Roles.

You can also create custom roles for the members of your organization. Custom roles can have any combination of access rights. For more information, see Manage Roles > Create a Custom Role.

In addition to viewing the information on this page, you can view details of the available roles in the Developer Portal interface. See View Role Details in the Developer Portal on this page.

Roles

Role Name Role Description Access Rights for this Role
Owner Has all of the access rights of the other roles, as described below. In addition, they can transfer the Owner role to another user in the organization. An organization always has exactly one Owner. The Owner has all of the access rights described below for Admin. In addition, they can transfer ownership of the Organization to another member.
Admin Has access to the full set of Developer Portal functionality. This includes the ability to manage seats for Epic Games services and to manage purchases and to sign agreements with Epic Games. Note: Admin users cannot transfer ownership of the organization to another user. Only owners can do this. Product Management

  • Epic for Indies
    View and manage Epic Games resources for Indie Developers, to take advantage of various development and promotional opportunities. These resources include Epic MegaGrants, opportunities to showcase games at events, and interviews by Epic Games.

  • Product Settings
    View SDK credentials, and configure product settings, sandboxes, identify providers, client permissions, and player groups.

  • Product Image and Name Editing
    Change a product's image and name.

Game Services

  • Leaderboards
    Query how your product's players rank against their friends and the broader gaming community.

  • Lobbies
    Search for and view lobbies created by game players. Note: Lobbies are an extension of the EOS Matchmaking Service. They run on the same deployments.

  • Game Services Metrics
    Interact with a game's usage data and use the Game Analytics dashboard in the Developer Portal.

  • Stats
    Manage game players' stats for an application. Use stats to determine when a product unlocks achievements and ranks users in leaderboards.

  • Achievements
    Retrieve data about a player's achievements and unlock achievements for players in products.

  • Title Storage
    Upload game data in the Developer Portal, accessible by any player, without updating an entire game. A product can use the EOS SDK to retrieve the data.

  • Player Ticketing
    Track and manage submitted tickets. Generate and view the web API key used to integrate ticketing in a product.

  • Voice Metrics
    View and manage voice metrics. Voice metrics include data about the following:

    • Connected users per platform. This shows the number of players using the voice service within a selected time-frame.
    • Voice user status, which provides a breakdown of connection states such as Connected, Error, and Disconnected.
    • Overall user join error rates.
    • Detailed join room errors.
    • Room size distribution across platforms.
    • Comprehensive error reports with their occurrence rates.

  • Player Profile – Anti-Cheat
    Configure and monitor the results of the organization’s anti-cheat service for a specific player’s profile.

  • Sessions
    Set up game sessions for individual players or predetermined groups.

  • Sanctions and Appeals
    Manage punitive actions taken against a user. This includes temporary and permanent bans from gameplay or communication.

  • Anti-Cheat – Cheater Reports
    Identify in-game infractions, like cheating and abusive communications. Filter, search, and view detailed player reports to manage and address in-game behavior effectively.

  • Anti-Cheat – Detections
    Use cheat detection services that identify and address accounts using specialized methods to manipulate the game. The free service covers detections for common cheating tools. Game-specific cheat detection is available through a paid enterprise agreement with Epic Games' analysts.

  • Anti-Cheat – Settings
    Configure how the Anti-Cheat service behaves when cheaters are detected.

  • Player Reports
    Query user reports to view the details of reported user behaviors. Use the sanctions interface to conduct any punitive actions.

  • Player Data Storage
    View user-specific data and storage quotas for troubleshooting and debugging.

Epic Account Services

  • Application Configuration
    Configure the product as an Epic Account Services application. Configure brand settings, permissions, and linked clients.

  • Localized Presence
    Localize a product's rich presence messages. For more information, see Localize Your Game's Rich Presence Messages.

Epic Tools

  • Downloads
    Review and download files for Unreal Engine, Twinmotion and RealityScan. Download Unreal Engine, Twinmotion and RealityScan. This can be from the launcher (recommended) or, if required by your organization, from the offline installer files.

  • Unreal Engine Royalties
    Submit Release Forms, submit quarterly royalty reports, and view previous release form and royalty form submissions.

  • KWS Developer
    Access all Kids Web Services features, except for the ability to initialize Kids Web Services and the ability to accept Kids Web Services agreements.

  • Unreal Engine Trademarks
    Use Unreal Engine trademarks in a product's branding. For more information, see Request Approval to Use the Unreal Engine Logo.

  • Seat Management
    Organize and manage access and permissions for team members in their organization. This ensures all team members can access the appropriate Epic Games tools and resources.

Organization

  • Tax and Payment Provider
    Manage details of the organisation's tax information and payment providers that are shared with Epic Games.

  • Profile Settings
    View and manage an organization’s profile. This includes updating profile and cover images, editing the organization’s biography, and managing linked social media profiles.

  • Team Management
    Remove or change the access rights of other members of the organization.

  • Purchases
    View payment details, transactions, and billing details.

  • Agreements Management
    View an organization’s Epic Online Services, Epic Games Store agreements and addenda. Review these agreements and addenda, and accept them as needed.

Community

  • Game Analytics
    View game analytics, including player count and engagement statistics.

  • Player Search and User Data
    Search for players by PUID and Player Account ID. View user data for Epic Online Services, linked player accounts, audit logs of player account linking. Export or delete product data for players.

Store

  • Release Management
    View and manage each stage of the publishing process for a product. Dev is a private sandbox where team members can make configuration changes and test. Stage is a private sandbox where team members can test and submit the product for review. Live is a public sandbox. Team members can push items to Live that have been approved after the submission process. Items in Live are indexable on the web.

  • Artifacts Live Update
    Publish an artifact without putting it through review by the Epic Games Store team (bug fixes only).

  • Offers Live Update
    Update an offer live without requiring review by the Epic team. All of the following criteria must apply:

    • The artifact has previously been pushed to the Live sandbox.
    • The artifact has the "Ready for Stage" status in the Dev sandbox.

  • Store Settings
    Manage the store settings for a product. This includes product specs, social media accounts, and regions and ratings.

  • Pages
    Manage a product's storefront pages. This includes the Product Home page, from the Product dashboard and the Pages tab.

  • Artifacts and Binaries
    View and manage artifacts or patch notes for the product from each of the available Sandboxes.

  • Analytics
    Use analytics to get insight into the performance of a product and integrated services.

  • Marketing Assets
    Feature selected products, games, promotional sales, and updates on the Epic Games Store and social media channels. Promotional items are displayed on the Epic Games Store main page, and subsequent landing pages on the storefront, such as Epic Games' Sales & Specials and Free Games destinations.

  • Reports
    View and analyze sales, payout, and payment reports for the organization’s products in the Epic Games Store.

  • Mods
    Use the Mods Interface. This allows integration with the organization’s game or software application to utilize the Epic Online Services (EOS) Mods service. This interface allows users to manage mods but is limited to those available on the Mod Marketplace of the Epic Games Store.

  • Payout
    Use Hyperwallet to view and manage payouts in an organization.

  • Localization
    Use tools to localize a product's store presence on the Epic Games Store.

  • Offers
    View, manage, and create offers for a product in any of the available sandboxes.

  • Discounting
    View, manage, and create offers for The Beacon from any of the available sandboxes.

  • Access Keys
    Request access keys for a product. Access keys allow users to access games, offers, and more.

  • Custom Price Tiers
    Create custom price tiers for a product.

  • Publishing Dashboard
    Access the main product dashboard. Configure permissions.

  • Webshop Management
    Manage a product's web shop. For more information, see Manage Your Web Shop.

  • Webshop Webhook Management
    Manage a product's webshop webhooks. For more information, see Manage Webhooks.

View Role Details in the Developer Portal

To view details of the available roles in the Developer Portal:

  1. Sign in to the Developer Portal (dev.epicgames.com/portal).
  2. Select your organization.
  3. In the left navigation, click Organization.
  4. Click the Roles tab.
  5. To view more detail for a specific role, on the row for that role click View.
