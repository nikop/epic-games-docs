EOS Get Started Reference

Reference for getting started with Epic Online Services (EOS).

3 mins to read

Epic Online Services (EOS) is a free*, modular set of services that streamline implementing common game functionality. EOS services are scalable, so you can use them in your game (or other software application) whether you are an indie developer or a AAA studio. EOS services are game-engine-agnostic and available for PC (Windows, macOS, Linux), consoles, and mobile (iOS, Android).

You can integrate EOS services with your game using the EOS interfaces, whatever game engine you use, or if you use no game engine at all. If you use Unreal Engine or Unity, the EOS plugins are an optional alternative to using the EOS interfaces. (For more information: EOS SDK and Game Engines Introduction.)

The EOS interfaces are available in C and C# and consist of two types of service: EOS Game Services and EOS Epic Account Services. (More information: EOS Overview.)

This document provides reference information for specific use cases. For instructions to get started with EOS, see: Guide: Get Started with Epic Online Services.

*The anti-cheat service, like all other services, is free. However, additional anti-cheat support and features are available with a paid enterprise agreement. (More information: Anti-Cheat Interfaces.)

The how-to guides provide information on how to integrate EOS services with your game. They provide step-by-step instructions for both C++ and C#. For a list of the available guides, see the How-To Guides page.

EOS SDK Reference

EOS SDK Download Types

Note: If you use Unreal Engine, you do not need to download the EOS SDK. The EOS SDK is included with Unreal Engine by default.

Select a version of the EOS SDK for the platform your game client runs on. The EOS SDK is available for the following platforms:

  • Windows, macOS, Linux
    The EOS SDK in C and the EOS SDK in C#.

  • Mobile
    The EOS SDK for iOS and the EOS SDK for Android.

  • Consoles
    To download the EOS SDK for game consoles, you must be a developer approved by both the platform holders and by Epic Games. The SDK is available in C and C#.
    The platform holders are Microsoft (Xbox One, Xbox Series), Sony (PlayStation 4, PlayStation 5), and Nintendo (Switch, Switch 2).

For information about requesting approval, see the Access the EOS SDK for Consoles section below.

Access the EOS SDK for Consoles

There are EOS SDK downloads for game consoles in C, and in C#.
Only developers approved by the platform holders and by Epic Games can download the SDK for consoles. The platform holders are Microsoft (Xbox One, Xbox Series), Sony (PlayStation 4, PlayStation 5), and Nintendo (Switch and Switch 2).

You request access to the EOS SDK downloads for consoles and the associated documentation in the Developer Portal. To do this:

  1. Go to the Developer Portal at dev.epicgames.com/portal.
  2. In the left navigation, click Dashboard if it isn't already selected.
  3. On the Dashboard page, under the Your products heading, click Downloads & Release notes.
  4. Select the EOS SDK tab.
  5. To request access, scroll down and click Request access. This takes you to guidance on how to apply for console developer access from the platform holders.

After you have platform-holder approval, you can apply for Epic Games approval. To apply for Epic Games approval, complete the Console Developer Request for Epic Online Services form at eoshelp.epicgames.com.

EOS SDK Download Contents

The EOS SDK download has the following directories:

Directory Content
/Samples Sample projects implementations demonstrating how the EOS SDK works.
/SDK The libraries and header files you use in your game code to integrate the EOS SDK with your game so your game can use EOS services.
/ThirdPartyNotices Legal information about libraries that support EOS.

We recommend that you review the samples in the /Samples directory because they demonstrate some of the platform's features. There is a list of the documentation which accompanies each sample on the EOS SDK Samples page.
