Known Issues

Known issues with the Epic Games Store publishing tools.

Under 1 min to read

For issues impacting the Epic Games Store storefront, such as outages, visit status.epicgames.com.

If you have any questions, go to the Epic Developer Community website’s Epic Games Store section at dev.epicgames.com/~/epic-games-store.

Known Issues

The Epic Games Store team is aware of the following issues impacting the publishing tools:

  • Push to Stage: Promotion to the Stage sandbox might take several minutes after you have made any change, including small changes. If the submission is still processing after 10 minutes, create a private discussion with Epic Games Support, using this support website: eoshelp.epicgames.com.
  • Not Sellable/Bundle Only option: If you enable this option for an offer users cannot purchase it. However the offer remains visible in the storefront. Any user who attempts to purchase the offer experiences an error during checkout and cannot complete the purchase.
  • Localization template: Before you upload localization content, you must remove any columns for languages you have not translated. Inclusion of empty columns results in an error when you upload the template.
  • Display Name field: The name you enter when you create a product in the Developer Portal is only used within the Developer Portal. It is not used on the Epic Games Store storefront.
  • Agreements: You cannot use a screen magnifier or operating system dictation feature to assist you when you view an agreement.
