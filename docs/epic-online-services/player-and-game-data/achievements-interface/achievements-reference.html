Achievements Interface Reference

Reference for the Achievements Interface.

5 mins to read

Note: You can display achievements in the Social Overlay. However, the Social Overlay does not support achievements for the following platforms: macOS, Linux, Linux ARM64, Android, and iOS.
Players must sign in with their Epic Games account to use the Social Overlay.

Use the Epic Online Services (EOS) Achievements service to track player achievements in your game (or other software application). EOS Achievements are platform agnostic. This means that you can award the same achievements to players in your game with the EOS Achievements service, no matter which storefront those players purchase your game from or which platform they choose to play your game on.

Achievements can be anything you want. Here are some examples:

  • Track how much gamma radiation a player collects in your game through a stat and automatically unlock a "Radioactive Hero" achievement when the player collects 1000 units of gamma radiation.
  • Track the distance the player has traveled in your game through your game code, and also track the number of postcards the player has collected from all the areas in your game through your game code. Manually unlock a "World Traveler" achievement through the EOS SDK API when the player has travelled 1000 miles and collected 100 postcards.

If you publish your game on the Epic Games Store, you can enhance your game's user experience further with Epic Games Store achievements. Epic Games Store achievements extend EOS achievements by rewarding your users with experience points (XP) and other benefits in their Epic Games accounts. For more information on Epic Games Store achievements, see the documentation: Epic Games Store Achievements > Achievements Overview.

See the Achievements Interface guide and Achievements Interface API documentation for details on how to integrate the service into your game (or software application).

Change in Support for the LATEST Aggregation Type

To retrieve data about Epic Online Services achievements or manually unlock them, you must first define your Epic Online Services achievements in the Developer Portal. For more information, see the Achievements Guide > 1. Set Up Achievements documentation.

We no longer support the LATEST aggregation type in Epic Online Services achievement definitions.

The following rules apply for the aggregation type LATEST:

  • You can create a stat that uses the aggregation type LATEST.
  • You can still edit an existing Epic Online Services achievement if it already references a stat that uses the LATEST aggregation type.
  • You cannot create a new Epic Online Services achievement that references a stat that uses the aggregation type LATEST.

Troubleshooting EOS Achievements in the Social Overlay

If you use the Social Overlay in your game and your players experience issues with EOS achievements in the Social Overlay, here are some possible troubleshooting solutions.

Issue Possible Solution
Players can’t view their EOS achievements in the Social Overlay. You must call the EOS API EOS_Connect_CreateUser function as part of your initialization flow for new players.
  • This ensures that new players are assigned a Product User ID. (Documentation: Guide: Access Game Services With the Connect Interface.)
EOS achievement icons load slowly in the Social Overlay. Reduce the image size of your achievement icons and use .JPG images.
EOS achievements that players unlock don’t display as unlocked in the Social Overlay. Complete the following checks for any errors or typos:
  • If the achievement is based on stat progression, verify that the name of the stat that is being ingested is correct in both the Developer Portal and your code.
  • Verify that the name of the achievement that is being unlocked is correct in both the Developer Portal and your code.
  • Check the logs for any warning or error messages that might indicate the cause of the issue. (Documentation: Logging Interface.)
Players don’t receive notifications in the Social Overlay for EOS achievements that they unlock. Complete the following checks to verify that you are initializing the Social Overlay properly:
  • Verify that you have initialized the Social Overlay in your code.
  • Check the logs for the message Social Overlay: Load Success in the LogEOSUI category.
  • Try to open the Social Overlay with the keyboard shortcut: SHIFT+F3.
  • If the Social Overlay does not successfully initialize or open, check for warning or error logs in the LogEOSUI, LogEOSAnalytics, or LogEOSOverlay categories that might indicate the cause of the issue.

Usage Limitations

For general information about throttling, usage quotas, and best practices, see the documentation on service usage limitations: EOS SDK Conventions and Limitations > Service Usage Limitations.

The following limits apply to a deployment's overall use of Epic Online Services achievements:

Feature Limitation
Total number of achievements 1000
Stats per achievement 3
Achievement ID length 256 characters
Localized text variations per achievement 22. Note: the EOS Overlay supports only 16 languages.
Localized text length 256 characters
Achievement icon file size 1.02 MB
Achievement icon resolution (maximum) 1024x1024 pixels
Achievement icon resolution (recommended) 192x192 pixels
Achievement icon file types PNG, JPG, BMP, and GIF (not animated)

Note: When you define an Epic Online Services achievement you cannot use the following symbols in the AchievementId parameter of EOS_Achievements_DefinitionV2:

, { ^ } % ` ] > [ ~ < # | & $ @ = ; : + ? ! \ ( ) * /

There are also usage-rate limitations that apply on a per-user or per-deployment basis. Per-user limitations apply to individual users playing games and interacting with existing achievements, while per-deployment limitations apply to calls that set up the achievements that players can see and unlock.

Feature Per-User Limitation Per-Deployment Limitation
Get all achievement definitions 10 requests per minute -
Get one achievement definition 100 requests per minute -
Get a player's achievements 100 requests per minute -
Unlock achievement 100 requests per minute -
Create achievement - 100 requests per minute
Delete achievement - 100 requests per minute

Test your Epic Online Services achievements

If your Epic Online Services (EOS) achievements unlock based on stat progression, you can test your EOS achievements in a sandbox as long as you include your stats in a deployment to that sandbox. Do this before you deploy to your live environment. This allows you to check for errors in the achievement definition and make sure that players can unlock EOS achievements successfully.

For more information on creating a test sandbox for your product, see the documentation on Product, Sandbox, and Deployment IDs.
