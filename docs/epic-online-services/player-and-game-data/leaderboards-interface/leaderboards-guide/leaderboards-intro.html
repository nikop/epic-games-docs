Guide: Add Leaderboards to Your Game — Introduction

Overview of how to add leaderboards to your game.

Under 1 min to read

Type of service : This interface is an EOS Game Service — authenticate players with the Connect Interface.

Use the EOS Leaderboards service to track and rank player stats in your game (or other software application).

Leaderboards rank your players by score for selected stats over a period of time that you specify. This lets your players compete with their friends or other players worldwide for the top ranking. Some examples of leaderboards include:

  • Rank all global players by the total number of enemies defeated.
  • Rank players by how much gamma radiation they have collected during a special timed event.
  • Offer players a way to compare who has the longest jump distance between friends.

To add leaderboards to your game, you must first have stats set up in your game. For information on stats and how to set them up, see the documentation: Stats Interface.

This guide consists of the following sections:

    1. Set Up Leaderboards
    1. Retrieve Leaderboards for Your Game
    1. Retrieve Records for a Leaderboard

Note: This guide follows an order. However, only section 1. Set Up Leaderboards is a prerequisite to provide leaderboards in your game. You can follow any section of this guide from section 2 onwards independently of each other and in any order.

This section of the guide is available in C++ and C#. The C++ version uses the EOS SDK API in C.
