Friends Interface

Enable players to invite friends to join a game-play session. Retrieve and display friend information to players.

6 mins to read

Type of service : This interface is an EOS Epic Account Service — authenticate players with the Auth Interface.

Use the Epic Online Services (EOS) Friends Interface to retrieve, manage, and subscribe to events for the friends list of a signed-in player of your game (or user of a software application).

Notes:

  • To use the Friends Interface in your game, you must first create an Epic Account Services application for your product in the Developer Portal. See the EOS Epic Account Services documentation for more information.
  • You must obtain user consent (see documentation: Data Privacy and Visibility) from your players to access their friends list data.
  • Before you can use all the features of the Friends Interface, you must first retrieve the friends list of the player and cache it. See the Retrieve and Cache the Friends List section for details.

Retrieve and Cache the Friends List

To retrieve and cache the player's friends list, you must complete a two-step process:

  1. Acquire a Friends Interface handle.
  2. Query the friends list.

Step 1: Acquire a Friends Interface Handle

To retrieve a player's friends list, you must obtain an EOS_HFriends handle. Friends Interface functions require this handle to access the player's friends list. Call the Platform Interface function EOS_Platform_GetFriendsInterface to get the handle.

Step 2: Query the Friends List

After you obtain the EOS_HFriends handle, you can retrieve the player's friends list. To do this, call EOS_Friends_QueryFriends and pass the following information in it:

  • The Friends Interface handle.
  • An EOS_Friends_QueryFriendsOptions structure.
  • Your callback information.

The EOS_Friends_QueryFriendsOptions data structure must have the following information:

Property Value
ApiVersion EOS_FRIENDS_QUERYFRIENDS_API_LATEST
LocalUserId The EOS_EpicAccountId of the player whose friends list you want to retrieve.

When you call EOS_Friends_QueryFriends, it downloads the most up-to-date version of the player's friends list, including blocked players, into the local cache. The cached friend’s list does not separate blocked players from non-blocked players. If you want to get only the blocked players from the player’s friend’s list, you must query for the blocked players. For more information, see the section on: Query for Blocked Friends.

The callback you provided runs when EOS_Friends_QueryFriends finishes.

Note: For callbacks to trigger when requests complete, you must ensure that the EOS_HPlatform handle is ticking. (Documentation: Platform Interface).

Check if the EOS_Friends_QueryFriends call succeeded. To do this, when your callback executes, check the ResultCode field of the EOS_Friends_QueryFriendsCallbackInfo structure. If your callback returns a success code this means the SDK now has a cache of the latest data from the server. You can get information about the cached friends list data at any time. For more information, see the section on: Get Information About the Friends List.

Notes:

  • EOS_Friends_QueryFriends only returns friends who have played the game at least once and have given their consent to allow your game to use their Friends List data.
    • A friend gives their consent when either they purchase the game or when they use Epic Account Services to sign in to an application and allow Epic Account Services to access their Epic Games account data.
  • Your game does not need and should not call EOS_Friends_QueryFriends more than once per sign in of a player. However, after a player signs out, you must query their friends list again when they sign in, to get the latest friends list.
  • Friends lists can change at any time. For example, a player might add a new friend after they meet a new player in-game. Or they might add a new friend when they modify the account from a separate system. To keep a game's local copy of the friends list up to date, subscribe to friend status update notifications. For more information, see the section on: Subscribe and Unsubscribe to Friend Status Updates.

Perform Functions on the Cached Friends List

After you retrieve and cache the friends list (see the section on: Retrieve and Cache the Friends List), you can perform these functions on the cached friends list:

  • Get Information About the Friends List
  • Subscribe and Unsubscribe to Friend Status Updates
  • Manage the Friends List
  • Query for Blocked Friends

Get Information About the Friends List

To get information about the player's friends list, use the functions below:

  • EOS_Friends_GetFriendsCount : Get the number of friends.
  • EOS_Friends_GetFriendAtIndex : Get the EOS_EpicAccountId of each friend.
    • Note: You can get additional information about the friend with the EOS_EpicAccountId that the function EOS_Friends_GetFriendAtIndex returns. To do this, pass the EOS_EpicAccountId to the User Info Interface. See the User Info Interface documentation for more information.
  • EOS_Friends_GetStatus : Get the current status of the social relationship between the player and one of their friends.
    • Note: By default, the function GetStatus returns whether a player is a friend (EOS_FS_Friends) or whether a player is not a friend (EOS_FS_NotFriends). The Social Overlay handles pending invites for you, which includes additional statuses for when an invite is sent (EOS_FS_InviteSent) or when an invite is received (EOS_FS_InviteReceived).

Subscribe and Unsubscribe to Friend Status Updates

Subscribe to Friend Status Updates

You can subscribe to friend status updates to receive a notification when the status changes of any of the friends on the player's friends list. To do this, call EOS_Friends_AddNotifyFriendsUpdate with the following parameters:

Parameter Description
Options An EOS_Friends_AddNotifyFriendsUpdateOptions structure, with ApiVersion as its only parameter.
Callback The callback function EOS_Friends_OnFriendsUpdateCallback that the EOS SDK calls when a friend's status changes.

The EOS SDK calls the callback function when a friend's status changes. The callback receives an EOS_Friends_OnFriendsUpdateInfo structure with the following parameters:

Parameter Description
LocalUserId The EOS_EpicAccountId of the player who receives the update about their friends.
TargetUserId The EOS_EpicAccountId of the player's friend whose status changed.
PreviousStatus The previous value of the friend's status.
CurrentStatus The new value of the friend's status.

Unsubscribe to Friend Status Updates

EOS_Friends_AddNotifyFriendsUpdate returns an EOS_NotificationId handle. You must use the handle to unsubscribe from notifications when you no longer need them. To unsubscribe from friend status updates, call the function EOS_Friends_RemoveNotifyFriendsUpdate and pass the EOS_NotificationId handle. If the call to EOS_Friends_AddNotifyFriendsUpdate fails, it returns a result code of EOS_INVALID_NOTIFICATIONID.

Manage the Friends List

This section describes the available APIs that you can use to manage the friends list in your game. For information on how to manage the friends list through the Social Overlay, see the documentation: Social Overlay Tabs: Friends.

Note: The friends list management APIs described in this section are only available for games on Windows PC and Nintendo Switch, PlayStation, and Xbox console platforms. Support for macOS, Linux, Android and iOS is planned.

You can manage invites in your game with the following functions:

Function Description
EOS_Friends_SendInvite Send a friend request from one player to another player. For more information, click the function to see the API documentation.
EOS_Friends_AcceptInvite Accept a friend request from one player to another player. For more information, click the function to see the API documentation.
EOS_Friends_RejectInvite Reject a friend request from one player to another player. For more information, click the function to see the API documentation.

Note: These functions return EOS_NotImplemented for platforms on which the functionality is not yet available.

Query for Blocked Friends

You can query for blocked friends of one of your players with the following functions:

Function Description
EOS_Friends_GetBlockedUsersCount Retrieve the number of blocked players on the blocklist. For more information, click the function to see the API documentation.
EOS_Friends_GetBlockedUserAtIndex Retrieve the Epic Account ID of an entry from the blocklist. For more information, click the function to see the API documentation.
EOS_Friends_AddNotifyBlockedUsersUpdate Listen for changes to the blocklist for a particular account. For more information, click the function to see the API documentation.
EOS_Friends_RemoveNotifyBlockedUsersUpdate Stop listening for blocklist changes on a previously bound handler. For more information, click the function to see the API documentation.

For more information on how a player can block another player on their friends list, see the documentation: Social Overlay Tabs: Profile.
