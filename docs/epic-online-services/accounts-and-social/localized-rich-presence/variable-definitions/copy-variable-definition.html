Copy a Variable Definition to Another Deployment (Localized Rich Presence)

How to copy a localized rich presence variable definition from one deployment to another.

1 min to read

Use localized rich presence variables to display dynamic content in your rich presence messages, such as the map that a player is currently on. Create variable definitions to ensure that only valid content can appear in your presence messages. For more information, see Variable Definitions for Localized Rich Presence Messages — Introduction.

Every variable is specific to a deployment, but you can copy variable definitions between deployments.

Note: If you want the variable definition to be different in the target deployment, you can edit it in the target deployment. This does not affect the variable definition in the original deployment because the original and the copy are completely separate.

To copy a variable definition to another deployment:

  1. In the Developer Portal, go to the Localized Presence page. To do this:
    a. Sign in to the Developer Portal (dev.epicgames.com/portal).
    b. Select the correct organization for your product.
    c. In the left navigation, under Your products, click the name of your product.
    d. In the left navigation, click Epic Online Services.
    e. In the left navigation, under Accounts and Social, click Localized Presence.
  2. Click the Variable Definitions tab:
  1. In Deployment, select the appropriate deployment.
  2. In the list of variable definitions, locate the variable definition you want to copy.
    • You can search the list. See documentation: Find a Specific Variable Definition.
  3. For that variable definition, click the three dots ( … ).
  4. Click Copy to another deployment.
  5. In Deployment, select the deployment you want to copy to.
    • Note: If there is a variable definition with the same name in the destination deployment, then the variable definition you copy overwrites the variable definition in the destination deployment.
  6. Click Copy.
