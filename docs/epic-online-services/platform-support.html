Platforms Supported

Lists the platforms and platform versions which the Epic Online Services (EOS) SDK supports.

2 mins to read

These subsections list the platforms and platform versions which the Epic Online Services (EOS) SDK supports. See the System Requirements documentation for a lists of the operating systems and supporting software required to develop and ship your game on each supported platform.

Tip: You can call the EOS_GetVersion function to get the EOS SDK version and the version of the platform that your game is compiled against.

There are two levels of supported platform:

  • Fully-Supported: Platforms With Technical Support and Documentation
  • Compatible-Only: Platforms Without Technical Support or Documentation

Fully-Supported: Platforms With Technical Support and Documentation

These platforms are compatible with the EOS SDK. Epic Games tests the EOS SDK on them and provides support and written documentation for them.

PC

Windows

The table below lists the Windows release version which each EOS SDK release version supports:

EOS SDK Release Version Windows Release Version
EOS SDK 1.19.1.2-CL53289219 supports Windows 10 or higher and Windows on Arm
Any release version supports Windows 10 or higher

See the EOS SDK for Windows documentation for more information on how to use the EOS SDK for Windows.

MacOS

The table below lists the macOS release version which each EOS SDK release version supports:

EOS SDK Release Version MacOS Release Version
EOS SDK 1.14.1 - 1.19.1.2-CL53289219 supports macOS 10.12 or higher
EOS SDK 1.10.2 - 1.14 supports macOS 10.14 or higher

See the EOS SDK for Mac documentation for more information on how to use the EOS SDK for macOS.

Linux

All EOS SDK release versions support any modern Linux version that uses glibc version 2.17 or higher. The table below lists the Linux toolchain version which each EOS SDK release version supports:

EOS SDK Release Version Linux Toolchain Version
EOS SDK 1.16.4-CL36651368 - 1.19.1.2-CL53289219 supports v19_clang-11.0.1-centos7 or higher and Linux ARM64
EOS SDK 1.11 - 1.16.3-CL35276460 supports v19_clang-11.0.1-centos7 or higher
EOS SDK 1.10.2 - 1.10.3 supports v16_clang-9.0.1-centos7 or higher

See the EOS SDK for Linux documentation for more information on how to use the EOS SDK for Linux.

Mobile

iOS

The table below lists the iOS release version which each EOS SDK release version supports:

EOS SDK Release Version iOS Release Version
EOS SDK 1.17.0-CL43712763 - 1.19.1.2-CL53289219 supports iOS 12 and 18
EOS SDK 1.16.4-CL36651368 - 1.17.0-CL39599718 supports iOS 12 or higher
EOS SDK 1.10.2 - 1.16.3-CL35276460 supports iOS 11 or higher

See the EOS SDK for iOS documentation for more information on how to use the EOS SDK for iOS.

Android

The table below lists the Android release version which each EOS SDK release version supports:

EOS SDK Release Version Android Release Version
EOS SDK 1.19.1.2-CL53289219 supports API level 26 (Android 8.0)
EOS SDK 1.10.2 - 1.19.0.7-CL52449437 supports API level 23 (Android 6.0)

The table below lists the Android architecture version which each EOS SDK release version supports:

EOS SDK Release Version Android Architecture Version
EOS SDK 1.19.0.7-CL52449437 - 1.19.1.2-CL53289219 supports
  • arm64-v8a
  • x86_64
EOS SDK 1.10.2 - EOS SDK 1.18.1.2-CL47370208 supports
  • armeabi-v7a
  • arm64-v8a
  • x86
  • x86_64

See the EOS SDK for Android documentation for more information on how to use the EOS SDK for Android.

Consoles

For a list of the console release versions that each EOS SDK release version supports, see the the documentation for each console. You can find this under the EOS SDK for Platforms section of this manual.

You can only access console documentation if you have the appropriate permissions. See the EOS Get Started Reference > Access the EOS SDK for Consoles documentation for more information on how to access the EOS SDKs for consoles and their associated documentation.

Compatible-Only: Platforms Without Technical Support or Documentation

Use the following platforms at your own risk.

These platforms are compatible with the EOS SDK, but Epic Games does not test the EOS SDK on them, and does not provide technical support or documentation for them.

Steam Deck

This platform is compatible with the EOS SDK, but Epic Games does not test the EOS SDK on it, and does not provide technical support or documentation for it.

Note: The EOS Overlay does not work correctly on OLED Steam Decks.
