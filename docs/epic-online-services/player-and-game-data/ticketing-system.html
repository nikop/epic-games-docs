Ticketing System (Player Ticketing)

Manage support for your players with a pre-assigned email address and public web API key.

5 mins to read

Epic Online Services (EOS) provides a ticketing system for you to manage support for your game's players. The EOS ticketing system, known as "Player Ticketing", provides a centralized location for your player support: it provides an automatically generated, pre-assigned email address and a public web API key.

You manage the ticketing system in the Player Ticketing page of the Developer Portal. It provides you with the following functions:

  • You can tracking open, in-progress, and closed tickets.
  • You can merging related tickets.
  • You can reply to players who have submitted a ticket and want to receive replies.

Set Up The Ticketing System With Your Game

To manage player ticketing for your game, go to the Player Ticketing page of the Developer Portal.

To go to the Player Ticketing page of the Developer Portal:

  1. Go to your game's product page in the Developer Portal:
    • In the Developer Portal (dev.epicgames.com/portal), in the left navigation, under Your Products, click the name of your game. (Note that in the Developer Portal, your game is usually known as a "product".)
      • Note: You might have to click Back to organization before you can do this.
  2. In the left navigation, click Epic Online Services.
  3. In the Player & Game Data section, click Player Ticketing.

On the Player Ticketing page, do the following to set up player ticketing:

  1. Click Integrate APIs.
    Note: The first time you use player ticketing for a game, there is an Integrate APIs button. You must click Integrate APIs before you can use player ticketing with your game. You only need to do this once for a game. After you have clicked it, the Developer Portal replaces it with Show API key.
  2. Click Show API key and follow the onscreen instructions to view the public web API key for the game.
    You use this key to implement the API. Each game has its own public web API key, but the ticketing system uses the same email address for all your games.

Note: The Player Ticketing page in the Developer Portal is also where you see your players' support tickets. You use this page to track and manage the tickets.

How to Use the API

The ticketing system sends emails from your players to your dedicated mailbox. To trigger this process do the following:

  • Send a POST request to https://dev.epicgames.com/portal/api/v1/services/tickets/submit.
  • Include your game's API key in the HTTP authorization field and the information that you want to report.

The ticketing system supports the following fields:

Field Name Required Description
subject Yes One of the following:
  • open-question
  • technical-support
message Yes The email text, written by the player.
sender_email Yes The player's email address.
sender_name No The player's name.
guid No Your game's unique identifier for the player (for example, the productUserId). Note: Any type of unique identifier works, there are no restrictions enforced regarding the guid.
error_code No An error code for technical support emails.
system_os No The player's operating system.
system_antimalware No The player's anti-malware system.
system_other No Other information about the player's system.

Export Player Data

To export a player’s data, for example to fulfill a GDPR request, do the following actions:

  • Send a GET request to https://dev.epicgames.com/portal/api/v1/services/tickets/datarights/{email} (where {email} is a player's email address).
  • Include your game's API key in the HTTP authorization field.
  • In the URL path, include the email address for the player you wish to export the data for.

Usage Patterns, Restrictions, and Limitations

When you make requests through the ticketing system, observe the following limitations:

  • Requests must come from websites or the game client.
  • All requests must contain written material from the player.
  • The number of requests produced in a day must not exceed 10,000, or 5 per 100 Daily Active Players.
  • Player data in the ticketing system is separate from player data associated with your game that you manage through EOS Player Search. You cannot export or delete player data in the ticketing system through EOS Player Search. (For information on EOS Player Search, see documentation: Player Search.)
