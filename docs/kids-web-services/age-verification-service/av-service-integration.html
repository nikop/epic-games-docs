Integrate the Age Verification Service API

How to call the API to trigger Age Verification flow.

4 mins to read

You require several important credentials for the Age Verification (AV) Service related to API integration and authentication. These credentials are in the Developer Portal. The steps to obtain them are as follows:

API Integration

In the Developer Portal, you receive credentials in the form of two codes you use to verify the authenticity of the calls from KWS. They are:

  • Webhook secret
  • Verification secret

Note: Your test and production environments use different sets of credentials. Ensure that you are using the correct set.

Authentication

To call the Age Verification Service API, you must first generate a Developer Access Token to authenticate your product (game or other software application). To do this, use the OAuth token endpoint (see the section: Obtain a Token on this page).

You find the two credentials to generate the token from the Developer Portal. The credentials are:

  • KWS organization ID — The KWS ID for your product.
  • KWS client ID — Used for authentication.
  • API key — The client secret required to generate the Developer Access Token.
  • Service API host URL — The AV Service is located at this URL. You make API queries against this URL.

Note: Your test and production environments use different sets of credentials. Ensure that you are using the correct set.

You can find the credentials in two ways. Either:

  • Option A — For all the products in your organization.
  • Option B — For an individual product.

For more information about these options, see the documentation: Choose to Set Up KWS for Your Organization or Product.

For both options, you can get the credentials in the Developer Portal, on the Age Verification page’s Integration Information tab, but the way you access the tab depends on which option you use.

To get the credentials, follow the steps below:

Step 1 — Go to the Age Verification Page

Option A: For all the products in your organization

  1. Sign in to the Developer Portal at dev.epicgames.com/portal.

  2. In the left navigation, click Kids Web Services.

  3. In the left navigation, click Age Verification.

Option B: For an individual product

  1. Sign in to the Developer Portal at dev.epicgames.com/portal.

  2. In the left navigation under Your Products, select the name of the product you want to configure.

    • Note: If you can’t see the product you want, make sure you are working in the correct organization.

  3. In the left navigation, click Kids Web Services.

  4. In the left navigation, click Age Verification.

Step 2 — Configure the Verification Response

  • On the Age Verification page, click the Integration Information tab.

This endpoint returns an access token from the KWS authentication service with a client_credentials OAuth grant.

Note: Keep these credentials and tokens confidential. Do not pass them to client apps.

Response Parameters

  • access_token: You must include this in the Authorization header when you call the Age Verification (AV) Service API.
  • expires_in: The time (in seconds) the token remains valid.

Access Token Expiry

Developer Access Tokens expire after a short time, which can change depending on your product's (game or other software application) usage patterns. When the token expires, API calls return 401 Unauthorized response codes. In this situation, obtain a new Developer Access Token and retry your request.

API Call Retry Behavior

Any system integrating the AV Service API should implement a retry mechanism for API calls. If the status code indicates a failure, the call retry mechanism must perform exponential backoff, which means periodically retrying the call with increasing delays between requests up to a maximum length of time.

The status code indicates a failure if it is any value other than 200 to 299.

Call the Age Verification Service API Endpoint

To trigger the KWS age verification flow, send the user details collected by your product's user interface to KWS. An authenticated call to the generate-verification-url API endpoint triggers the KWS flow.

For more information, see the following documentation:

  • Set up your product's user interface (see documentation: Set Up Your Product's User Interface)
  • Age Verification Service API reference (see documentation: Age Verification Service API Reference)

User Details

The user details you send with the generate-verification-url API correspond to the parameters as follows:

Parameter Necessity Value
email Required The user's email address.
location Required The child’s location. The value must be:
  • A two-letter country code using the ISO 3166-1 alpha 2 format (Wikipedia: ISO_3166-1_alpha-2). For example, ‘US’, ‘GB’, ‘CA’.
  • A region code using the ISO 31660-2 subdivision format (Wikipedia: ISO_3166-2). For example, ‘US-NY’, ‘GB-ENG’, ‘CA-BC’.
language Required The user's language. The default is en.
This is the language that KWS uses for emails and verification Web UI screens presented to the user. For a complete list of supported languages, see: Localization in KWS.
externalPayload Optional A value you pass when initiating a verification that must be a JSON or UTF-8 string no longer than 250 characters.
userContext Required Must be set to adult.
