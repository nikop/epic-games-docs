Manage Your Web Shop

Create and manage your product's web shop.

5 mins to read

On the Epic Games Store, a web shop is a virtual marketplace that lets Epic Games Store users view and purchase web shop items for your product. Each product can have one web shop. For each web shop, you can manage web shop items (for example, virtual currency or skins) sold on the Epic Games Store. A web shop is an alternative to selling your items in your product. Your users can view and purchase content for your product directly from the Epic Games Store, without the need to open additional software.

The Epic Games Store has multiple requirements and guidelines for all products distributed on the storefront. In addition to the Epic Games Store requirements, web shops must follow specific guidelines and requirements.

Note: To use web shops, you must have an organization, a product with early store discovery enabled, and a functional webhook.

Enable Web Shop for a Product

You manage web shops and web shop items in the Web Shop page of the Developer Portal. To access a web shop, you must have an organization and release a product with early store discovery. (Documentation: Get Started Steps > Onboarding.) If this is the first time you use web shops for your product, you must enable the feature.

As part of the process to enable web shops, you must sign the Epic Games Store Web Shop Agreement. Only members of your organization with an owner or signatory role, or with a custom role with the "agreement management" access right, can sign agreements. Other roles cannot sign agreements and cannot enable web shops.

To enable web shops:

  1. In the Developer Portal, go to the Web Shop page. To do this:

    • a. Sign in to the Developer Portal (dev.epicgames.com/portal).

    • b. Select the correct organization for your product.

      (To check, see Organization at the top of the left navigation. To change organization, click Organization and follow the on-screen instructions.)

    • c. In the left navigation, under Your products, click the name of your product.

    • d. In the left navigation, click Epic Games Store > Web Shop.

  2. Click Review & accept.
    • You must sign the Epic Games Store Web Shop Agreement in order to use a web shop. To read and sign the agreement, a member of your organization with a role of owner or signatory, or with a custom role with the "agreement management" access right, must do the next step.
  3. Review the Epic Games Store Web Shop Agreement and click Accept.
  4. In the left navigation, click Web Shop.
  5. Click Enable now.

Edit Web Shop Details

This page describes the details that you can set for the web shop. For information on how to create or edit items for sale or download in the web shop, see documentation: Manage Web Shop Item.

To view or edit the details of your web shop:

  1. In the Developer Portal, go to the Web Shop page. To do this:

    • a. Sign in to the Developer Portal (dev.epicgames.com/portal).

    • b. Select the correct organization for your product.

      (To check, see Organization at the top of the left navigation. To change organization, click Organization and follow the on-screen instructions.)

    • c. In the left navigation, under Your products, click the name of your product.

    • d. In the left navigation, click Epic Games Store > Web Shop.

  2. Find the Web shop details section and click Edit.

You can view or set the following details on a web shop:

  • Web shop URL: A URL where you can view a preview of your web shop in the Dev or Stage sandbox so you can see what your web shop looks like on the Epic Games Store.
  • Player ID linking instructions: Instructions that let Epic Games Store users know where to find their Player ID in your product. These instructions can include an image. Users type their Player ID to link the web shop item purchase to the user's account.

Manage Store Settings

You can go to the Store Settings page from the web shop details panel. You manage your product's configuration and regions and ratings settings from this page.

To go to the Store Settings page from the web shop details panel:

  1. In the Developer Portal, go to the Web Shop page. To do this:

    • a. Sign in to the Developer Portal (dev.epicgames.com/portal).

    • b. Select the correct organization for your product.

      (To check, see Organization at the top of the left navigation. To change organization, click Organization and follow the on-screen instructions.)

    • c. In the left navigation, under Your products, click the name of your product.

    • d. In the left navigation, click Epic Games Store > Web Shop.

  2. Find the Web shop details section and click Edit.
  3. In the Web Shop Details panel, click View Store Settings.

To configure your store settings, see documentation: Configure Store Settings.

Manage Localization

Localize your web shop content to best reach global Epic Games Store users. You localize content from the Localization page. You can go to the Localization page from the web shop details panel.

To localize your web shop content:

  1. In the Developer Portal, go to the Web Shop page. To do this:

    • a. Sign in to the Developer Portal (dev.epicgames.com/portal).

    • b. Select the correct organization for your product.

      (To check, see Organization at the top of the left navigation. To change organization, click Organization and follow the on-screen instructions.)

    • c. In the left navigation, under Your products, click the name of your product.

    • d. In the left navigation, click Epic Games Store > Web Shop.

  2. Find the Web shop details section and click Edit.
  3. In the Web Shop Details panel, click View Localization.
  4. To localize your web shop to new languages, see documentation: Localize your Store Presence.

Publish a Web Shop

To publish a web shop, you need to do the following:

  1. Push the web shop, web shop items, and item display list to the Stage sandbox.
  2. Submit the web shop for review.
  3. Push the web shop, web shop items, and item display list to the Live sandbox.

For more information on this process, see Publishing Tools Workflow.
