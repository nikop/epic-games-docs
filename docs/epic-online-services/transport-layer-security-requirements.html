Transport Layer Security (TLS) Requirements

A list of the Transport Layer Security (TLS) versions that the EOS SDK supports for each platform.

Under 1 min to read

For your reference, the EOS SDK uses the following HTTP Transport Layer Security (TLS) versions to communicate with EOS services:

Platform Transport Layer Security (TLS) Version
Windows Libcurl version 7.55.1
macOS An NSUrlConnection that uses Apple's default security policy. See Apple's documentation at support.apple.com for details.
Linux Libcurl version 7.65.3
iOS An NSUrlConnection that uses Apple's default security policy. See Apple's documentation at support.apple.com for details.
Android Libcurl version 7.75.0
Sony PlayStation SceHttp for TLS version 1.3.
Microsoft Xbox WinHttp version 1.3
Nintendo Switch A Nintendo provided Libcurl version.

Note: the EOS SDK prioritizes the highest supported TLS version on our servers, which at the time of this writing is TLS 1.3.
