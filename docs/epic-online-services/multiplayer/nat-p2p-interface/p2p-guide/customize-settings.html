Guide: Add Peer-to-Peer to Your Game — 3. Customize Peer-to-Peer Settings With EOS P2P

Overview of how to customize the P2P settings for your game.

54 mins to read

Previous section: 2. Establish Peer-to-Peer Connections With EOS P2P

This section of the guide is available in C++ and C#. The C++ version uses the EOS SDK API in C.

You can customize settings for P2P to meet the requirements of your game.

Note that when this guide refers to "player" connections, data sharing, and notifications, it means connections, data sharing, and notifications between each player’s game client.

The example code snippets in this guide are for guidance only. If you use the snippets, make sure you tailor them to the unique circumstances of your game.

Before You Start

Before you start, you must complete the following steps:

  • Complete the prerequisites listed in the Introduction section of this guide.
  • Register for P2P notifications. (Section of this guide: 1. Notify Players About P2P Connections.)
  • Establish a connection between players. (Section of this guide: 2. Establish Peer-to-Peer Connections With EOS P2P.)

Step C: Find NAT Type

Under certain circumstances (for example, to obtain metadata for matchmaking), you might need to identify your players' NAT type. You can call the P2P Interface's EOS_P2P_QueryNATType function to retrieve the NAT type of the local player's current connection. This function asynchronously sends multiple packets of data to remote servers, and those servers respond with the IP address and ports the local player uses for your game.

Note: If you call EOS_P2P_QueryNATType while a request is already in progress, the EOS SDK groups additional calls into the first request. It does not start a new request.

Query NAT Type

In your P2PManager.cpp file, implement the function to retrieve the player's NAT type.

Example:

void P2PManager::RetrieveNATTypeExample(){	// Set the options for querying the NAT type.	EOS_P2P_QueryNATTypeOptions QueryNATTypeOptions = {};	QueryNATTypeOptions.ApiVersion = EOS_P2P_QUERYNATTYPE_API_LATEST; 	// Call the EOS SDK to query the NAT type of the local player.	// The callback function will be called when the query is complete.	EOS_P2P_QueryNATType(P2PHandle, &QueryNATTypeOptions, this, OnQueryNATTypeComplete);}

Step E: Set Relay Control

The P2P Interface's relay control setting determines if the P2P Interface uses relays to establish the peer-to-peer connection. If the P2P Interface cannot connect with NAT traversal (Wikipedia: NAT traversal), it uses a secure relay to transfer data between players. For more information about the relay control options, see the documentation: Reference: Peer-to-Peer Interface > Relay Control.
